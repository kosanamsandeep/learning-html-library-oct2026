Topological Sort (Kahn's Algorithm): Process nodes with 0 in-degree first, then decrement in-degree of their dependents. This guarantees dependencies load before dependents. If we can't process all nodes, there's a circular dependency!

Key Design Decisions

1. Inversion of Control

The core doesn't call plugins directly. Instead, it defines hooks (extension points) and triggers them at the right time. Plugins register themselves — the core doesn't know what plugins exist.

2. Priority-Based Ordering

Multiple plugins can hook into the same point. Priority (lower = earlier) controls execution order. This is critical for filter chains where order matters (emoji substitution must happen before profanity check).

3. Dependency Declaration

Plugins declare what they depend on in metadata. The manager resolves this with topological sort (Kahn's algorithm), ensuring correct activation order and detecting circular dependencies.
