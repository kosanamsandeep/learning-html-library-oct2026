Middleware Chain

graph LR REQ[Request] --> AUTH[Auth Middleware] AUTH -->|valid key| RL[Rate Limiter] AUTH -->|no key| R401[401 Unauthorized] RL -->|tokens available| LOG[Logging] RL -->|bucket empty| R429[429 Too Many Requests] LOG --> ROUTER[Router] ROUTER -->|match| HANDLER[Route Handler] ROUTER -->|no match| R404[404 Not Found] HANDLER --> RESP[Response]

Token Bucket Algorithm

graph TD A[Request arrives] --> B{Refill tokens} B --> C[tokens += elapsed * rate] C --> D[tokens = min tokens, capacity] D --> E{tokens >= 1?} E -->|Yes| F[tokens -= 1] F --> G[ALLOW request] E -->|No| H[DENY 429]

Class Diagram

classDiagram class Middleware { <<abstract>> -_next: Middleware +set_next(middleware) Middleware +handle(request) Response +process(request)* Response } class AuthMiddleware { -_valid_keys: dict +process(request) Response } class RateLimiterMiddleware { -_buckets: dict +process(request) Response } class LoggingMiddleware { +access_log: list +process(request) Response } class Router { -_routes: dict +register(method, path, handler) +process(request) Response } class TokenBucket { +capacity: int +refill_rate: float +tokens: float +consume(n) bool } Middleware <|-- AuthMiddleware Middleware <|-- RateLimiterMiddleware Middleware <|-- LoggingMiddleware Middleware <|-- Router RateLimiterMiddleware --> TokenBucket
