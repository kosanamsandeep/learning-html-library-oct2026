🆚 Event vs Task

Aspect Event Task
Meaning "Something happened" "Do this work"
Direction Broadcast (1 → many) Targeted (1 → 1 worker)
Retryable No (facts are immutable) Yes (work can be retried)
Ordering Chronological Priority-based
Example "order.placed" "send_email"
