Same projects as the Go track, ported to Rust. The first three feel slow — you'll fight the borrow checker. By project five it'll click. By project ten you'll find Python errors confusing because they don't tell you about ownership failures up front.

Common Rust idioms you'll see across all 10

  • struct + impl blocks — data and behaviour are separate.
  • Result<T, E> + ? operator — errors as values, propagated explicitly.
  • Option<T> — replaces None; match forces you to handle both arms.
  • & and &mut borrows — pass references instead of moving values when you don't need ownership.
  • #[derive(Debug, Clone)] — auto-derive common trait implementations.
  • No dependencies on first reading. Every project here uses only the standard library so you can cargo run offline.
