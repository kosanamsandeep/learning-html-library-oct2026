Inventory — Repository trait + a decorator implementation

Like the Go version, the service depends on a trait Repository. To show how powerful traits get, this version adds a CountingRepo that wraps any other implementation and counts saves — Python's "decorator" pattern, in Rust.

Decorator pattern in 8 lines

struct CountingRepo {
    inner: Box<dyn Repository>,
    saves: u64,
}

impl Repository for CountingRepo {
    fn save(&mut self, it: Item) { self.saves += 1; self.inner.save(it); }
    fn get(&self, sku: &str) -> Option<&Item> { self.inner.get(sku) }
    fn all(&self) -> Vec<&Item> { self.inner.all() }
}

CountingRepo is a Repository, and it has a Repository inside. You can stack: Counting(Logging(Caching(Memory(...)))). This is composition over inheritance, taken seriously.
