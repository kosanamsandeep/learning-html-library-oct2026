Hospital Management — composition all the way down

Hospital → Department → Doctor → Appointment. The data is naturally nested, and Go encourages that: structs containing structs, slices of pointers to keep mutations visible.

Three Go specifics worth noting

  1. Pointer vs value semantics for collections. Doctors []*Doctor (slice of pointers) means appending an appointment via one reference is visible everywhere. []Doctor (slice of values) would copy on each access.
  2. The "exists?" idiom. FindDoctor returns (*Doctor, bool) — Go's clean way to express "maybe-found". Python uses None.
  3. Wrapped errors with context. fmt.Errorf("no such department: %s", dept) mirrors Python's f-string in a raise ValueError(...).
