Go · 10 projects parallel to Python p1-p10

Re-build the first 10 learning projects in Go

Each project below mirrors the same-numbered Python project. Read the Python README first, then jump to the Go version. The point is not to learn Go from scratch — the bootcamp does that — it's to feel how each Python pattern translates.

How each project is structured

p<n>_<name>/
├── README.html      ← what's different from Python; key Go idioms shown
├── go.mod           ← module declaration
└── main.go          ← single-file runnable demo

Run any project with: cd go_projects/p1_student_management; go run .

Common Go idioms you'll see across all 10

  • type X struct { … } + methods declared as func (x *X) Method().
  • Errors as values: (T, error) returns and if err != nil { return err } on every call site.
  • Interfaces are tiny — usually 1-3 methods. Big interfaces are an anti-pattern.
  • Capitalisation = visibility. SaveOrder is exported; saveOrder is package-private.
  • Tests live next to the code in *_test.go files.
