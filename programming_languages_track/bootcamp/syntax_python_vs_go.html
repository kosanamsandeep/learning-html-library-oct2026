Bootcamp · 2 of 5 · Go

Python ↔ Go syntax in 20 minutes

Read one row at a time. Each row shows the same idea in Python and in Go. By the end you should be able to read 80% of the Go code in this track without a reference.

1 · Hello world

Python

print("hello")

Go

package main
import "fmt"

func main() {
    fmt.Println("hello")
}

What's new

Every Go file declares a package. Imports are explicit. main() is the entry point of package main.

2 · Variables and types

Python

name = "Ada"
age: int = 36
pi = 3.14

Go

name := "Ada"        // inferred string
var age int = 36     // explicit
pi := 3.14           // inferred float64

What's new

:= declares + assigns with inferred type. var x T = … is the explicit form. Types are static — you can't reassign name to an int.

3 · Functions

Python

def add(a: int, b: int) -> int:
    return a + b

Go

func add(a, b int) int {
    return a + b
}

What's new

Type comes after the name. Same-typed parameters share the type (a, b int). Return type goes after ).

4 · Multiple return values + errors

Python

def divide(a, b):
    if b == 0:
        raise ValueError("zero")
    return a / b

try:
    r = divide(10, 0)
except ValueError as e:
    print(e)

Go

func divide(a, b float64) (float64, error) {
    if b == 0 {
        return 0, fmt.Errorf("zero")
    }
    return a / b, nil
}

r, err := divide(10, 0)
if err != nil {
    fmt.Println(err)
}

What's new

Go has no exceptions. Functions return (value, error). Callers check if err != nil. This pattern repeats everywhere.

5 · Structs (Go's "classes" — no inheritance)

Python

from dataclasses import dataclass

@dataclass
class Student:
    id: int
    name: str

    def greet(self):
        print(f"hi {self.name}")

Go

type Student struct {
    ID   int
    Name string
}

func (s Student) Greet() {
    fmt.Println("hi", s.Name)
}

What's new

Methods are declared outside the struct: func (s Student) Greet(). Capitalised names are exported (public); lowercase are package-private. No classes, no inheritance.

6 · Slices and maps

Python

names = ["Ada", "Bob"]
names.append("Cy")

scores = {"ada": 91, "bob": 88}
scores["cy"] = 79

Go

names := []string{"Ada", "Bob"}
names = append(names, "Cy")

scores := map[string]int{
    "ada": 91, "bob": 88,
}
scores["cy"] = 79

What's new

[]T is a slice (Go's list). append returns a new slice — always reassign. map[K]V is the dict.

7 · Loops + range

Python

for i, name in enumerate(names):
    print(i, name)

for k, v in scores.items():
    print(k, v)

Go

for i, name := range names {
    fmt.Println(i, name)
}

for k, v := range scores {
    fmt.Println(k, v)
}

What's new

Only one loop keyword: for. range over a slice yields (index, value); over a map yields (key, value).

8 · Interfaces (duck typing, but checked at compile time)

Python

class Notifier(Protocol):
    def send(self, msg: str) -> None: ...

class Email:
    def send(self, msg): print("email:", msg)

def notify(n: Notifier, m): n.send(m)

Go

type Notifier interface {
    Send(msg string)
}

type Email struct{}
func (Email) Send(msg string) { fmt.Println("email:", msg) }

func Notify(n Notifier, m string) { n.Send(m) }

What's new

You don't declare that Email implements Notifier. If it has the methods, it satisfies the interface. Implicit, but checked.

9 · Concurrency — goroutines + channels

Python (asyncio)

import asyncio

async def work(x):
    await asyncio.sleep(0.1)
    return x * 2

async def main():
    results = await asyncio.gather(
        work(1), work(2), work(3)
    )
    print(results)

asyncio.run(main())

Go

func work(x int, out chan<- int) {
    time.Sleep(100 * time.Millisecond)
    out <- x * 2
}

func main() {
    out := make(chan int, 3)
    for _, x := range []int{1, 2, 3} {
        go work(x, out)
    }
    for i := 0; i < 3; i++ {
        fmt.Println(<-out)
    }
}

What's new

go f() launches a goroutine — cheap (KB-sized stack). Channels (chan T) coordinate them. No event loop, no await: the runtime schedules goroutines onto OS threads automatically.

10 · Pointers (light touch)

Python

# Mutation through reference is implicit:
def add_score(s, n):
    s["total"] += n

state = {"total": 0}
add_score(state, 5)

Go

func addScore(s *Stats, n int) {
    s.total += n
}

stats := &Stats{}
addScore(stats, 5)

What's new

*T is a pointer to T; &x takes its address. Use a pointer when a method must mutate the receiver. No pointer arithmetic — Go pointers are safe.

11 · Standard project layout

myapp/
├── go.mod          # module name + Go version + dependencies
├── go.sum          # hashes
├── main.go         # entry point (package main)
└── internal/       # internal packages (not importable outside this module)
    └── orders/
        └── orders.go

Initialise with go mod init github.com/you/myapp. Run with go run .. Build with go build -o myapp — produces a single static binary.
