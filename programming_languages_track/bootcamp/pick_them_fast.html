Bootcamp · 5 of 5

Pick them fast — install, hello world, build, test in 30 minutes each

A no-nonsense starter for both languages. Run every command in this page and you'll have a working Go and Rust dev loop on Windows by the end of lunch.

Install

Go (Windows)

# Option A: official MSI
# https://go.dev/dl/   →  download the .msi  →  install

# Option B: winget
winget install GoLang.Go

# Verify
go version

Rust (Windows)

# Use rustup — the official installer
# https://rustup.rs/   →  run rustup-init.exe

# Or winget
winget install Rustlang.Rustup

# Verify
rustc --version
cargo --version
VS Code extensions: install golang.go for Go, and rust-lang.rust-analyzer for Rust. Both give you LSP, formatter, debugger out of the box.

Hello world

Go

mkdir hello-go
cd hello-go
go mod init example.com/hello
@'
package main
import "fmt"
func main() { fmt.Println("hello, go") }
'@ | Set-Content main.go
go run .

Rust

cargo new hello-rust
cd hello-rust
cargo run
# Cargo created src/main.rs with println!("Hello, world!");

The dev loop

Action Go Rust
Run during dev go run . cargo run
Format gofmt -w . (or auto-saved) cargo fmt
Lint / vet go vet ./... cargo clippy
Test go test ./... cargo test
Build release go build -o app.exe cargo build --release
Add a dependency go get github.com/x/y cargo add y

Tiny test (so the loop feels real)

Go — main_test.go

package main

import "testing"

func add(a, b int) int { return a + b }

func TestAdd(t *testing.T) {
    if got := add(2, 3); got != 5 {
        t.Fatalf("got %d, want 5", got)
    }
}

Run with go test -v.

Rust — src/lib.rs (or bottom of main.rs)

pub fn add(a: i64, b: i64) -> i64 { a + b }

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn add_works() {
        assert_eq!(add(2, 3), 5);
    }
}

Run with cargo test.

The 30-minute starter day

  1. Install both toolchains (above). 5 min.
  2. Run hello world in each. 5 min.
  3. Add a tiny test, watch it pass, change the implementation, watch it fail, fix it. 10 min.
  4. Open go_projects/p1 and rust_projects/p1 and read both. 10 min.

By the end you'll have written your first Go and Rust code and seen how the same project translates between three languages.

Common gotchas (Windows)

  • Go: if go: command not found in a new PowerShell, restart the terminal so PATH refreshes.
  • Rust: the first build downloads the registry index — that's normal, it takes ~1 minute once and then never again.
  • Rust: if linking fails on Windows, install "Build Tools for Visual Studio" (C++ workload). rustup usually warns you when this is missing.
  • Editor: save once before cargo run — rust-analyzer uses on-disk state.
