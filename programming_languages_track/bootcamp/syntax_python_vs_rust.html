Bootcamp · 3 of 5 · Rust

Python ↔ Rust syntax in 25 minutes

Rust is more to learn than Go because it has three big ideas you've never met in Python: ownership, traits, and rich pattern matching. Read each row carefully. The first 30 minutes feel like a wall — by minute 60 you'll find Python errors more confusing than Rust ones.

1 · Hello world

Python

print("hello")

Rust

fn main() {
    println!("hello");
}

What's new

println! is a macro (note the !) — it expands at compile time. Statements end with ;; the last expression of a block is its return value if there is no ;.

2 · Variables and immutability by default

Python

name = "Ada"
name = "Bob"          # ok, same name reassigned

Rust

let name = "Ada";
// name = "Bob";       // ERROR: name is not mut

let mut counter = 0;
counter += 1;          // ok

What's new

Variables are immutable unless you say mut. The compiler will refuse to compile any accidental mutation. This is annoying for a day, then permanent muscle memory.

3 · Functions and types

Python

def add(a: int, b: int) -> int:
    return a + b

Rust

fn add(a: i64, b: i64) -> i64 {
    a + b   // last expression — note: no `;`
}

What's new

Types are explicit on parameters and the return value. Numeric types name their width (i32, i64, u32, f64). The last expression of a function body is the return.

4 · Result<T, E> — errors as values

Python

def divide(a, b):
    if b == 0:
        raise ValueError("zero")
    return a / b

try:
    r = divide(10, 0)
except ValueError as e:
    print(e)

Rust

fn divide(a: f64, b: f64) -> Result<f64, String> {
    if b == 0.0 {
        Err("zero".to_string())
    } else {
        Ok(a / b)
    }
}

match divide(10.0, 0.0) {
    Ok(r)  => println!("{r}"),
    Err(e) => println!("{e}"),
}

What's new

No exceptions. Result<T, E> is an enum with two variants: Ok(T) and Err(E). match forces you to handle both. The ? operator is shorthand for "if Err, return it now".

5 · Structs + impl blocks (Rust's "classes")

Python

from dataclasses import dataclass

@dataclass
class Student:
    id: int
    name: str

    def greet(self):
        print(f"hi {self.name}")

Rust

struct Student {
    id: u64,
    name: String,
}

impl Student {
    fn new(id: u64, name: &str) -> Self {
        Self { id, name: name.to_string() }
    }
    fn greet(&self) {
        println!("hi {}", self.name);
    }
}

What's new

Data lives in a struct; behaviour lives in an impl block. &self is a shared borrow of the receiver (read-only). &mut self would allow mutation. Self with capital S means "the current type".

6 · Traits (interfaces with super-powers)

Python

from typing import Protocol

class Notifier(Protocol):
    def send(self, msg: str) -> None: ...

class Email:
    def send(self, msg): print("email:", msg)

Rust

trait Notifier {
    fn send(&self, msg: &str);
}

struct Email;

impl Notifier for Email {
    fn send(&self, msg: &str) {
        println!("email: {msg}");
    }
}

fn notify<N: Notifier>(n: &N, m: &str) {
    n.send(m);
}

What's new

Traits = interfaces. You declare implementation explicitly: impl Notifier for Email. Generic functions (fn notify<N: Notifier>) get monomorphised at compile time — zero runtime cost.

7 · Vec, HashMap — collections

Python

names = ["Ada", "Bob"]
names.append("Cy")

scores = {"ada": 91}
scores["bob"] = 88

Rust

let mut names: Vec<String> = vec![
    "Ada".into(), "Bob".into()
];
names.push("Cy".into());

use std::collections::HashMap;
let mut scores: HashMap<String, i32> = HashMap::new();
scores.insert("ada".into(), 91);
scores.insert("bob".into(), 88);

What's new

Vec<T> = list, HashMap<K, V> = dict. Both must be mut to insert/push. "x".into() converts &str to String when needed.

8 · Ownership — the one new idea

Rust replaces both garbage collection and manual free() with ownership. Three rules:

  1. Every value has a single owner.
  2. When the owner goes out of scope, the value is dropped.
  3. You can borrow a value (& or &mut) without taking ownership.
let s = String::from("hello");

// move:
let s2 = s;
// println!("{s}");  // ERROR — s was moved into s2

// borrow:
let s3 = String::from("hi");
print_str(&s3);     // borrow, s3 still owned
println!("{s3}");   // ok
Why this exists: the compiler proves at compile time that no two parts of your program are mutating the same memory simultaneously. That's how Rust eliminates data races and use-after-free without a GC.

9 · Enums + pattern matching (the killer feature)

Python

def find_user(id):
    if id in users:
        return users[id]
    return None

u = find_user(7)
if u is None:
    ...
else:
    ...

Rust

fn find_user(id: u64) -> Option<User> {
    users.get(&id).cloned()
}

match find_user(7) {
    Some(u) => println!("found {}", u.name),
    None    => println!("missing"),
}

What's new

Option<T> replaces None. match is exhaustive — forget the None arm and the compiler refuses to build. Whole categories of "I forgot the null check" bugs vanish.

10 · Iterators (zero-cost lazy chains)

Python

nums = [1, 2, 3, 4, 5]
total = sum(n * n for n in nums if n % 2 == 0)

Rust

let nums = [1, 2, 3, 4, 5];
let total: i32 = nums.iter()
    .filter(|n| *n % 2 == 0)
    .map(|n| n * n)
    .sum();

What's new

Iterators are lazy and chainable like Python generators — but they compile down to a tight loop with no heap allocation. This is what "zero-cost abstraction" means in practice.

11 · Async (when you need it)

Python

import asyncio, aiohttp

async def fetch(url):
    async with aiohttp.ClientSession() as s:
        async with s.get(url) as r:
            return await r.text()

asyncio.run(fetch("http://x"))

Rust (Tokio)

#[tokio::main]
async fn main() -> Result<(), reqwest::Error> {
    let body = reqwest::get("http://x")
        .await?
        .text()
        .await?;
    println!("{body}");
    Ok(())
}

What's new

async fn + .await mirror Python. The runtime is not built-in — you pick one (Tokio is the dominant choice). The ? operator propagates errors.

12 · Standard project layout (Cargo)

myapp/
├── Cargo.toml      # package name, version, dependencies
├── Cargo.lock      # locked deps
└── src/
    ├── main.go     # for binaries: src/main.rs
    └── lib.rs      # for libraries

Create with cargo new myapp. Run with cargo run. Build with cargo build --release. Test with cargo test.
