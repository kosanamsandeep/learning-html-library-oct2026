Python vs JavaScript, side by side

Read the Python column, then glance right. You will notice most of the difference is punctuation: { } blocks instead of indentation, semicolons, and camelCase instead of snake_case. The ideas are the same.

The big-picture differences

Aspect Python JavaScript
Blocks Indentation (whitespace matters) Curly braces { }; indentation is cosmetic
Statement end Newline Semicolon ; (mostly optional, but use them)
Naming convention snake_case camelCase
Typing Dynamic, optional hints Dynamic; add TypeScript for real types
Runs where Interpreter (server, scripts, notebooks) Browser and Node.js (server)
Equality == compares values Use === (strict); avoid ==
Null-ish None null and undefined (two of them)
Package manager pip / uv npm / pnpm / yarn

Variables

Python

name = "Ada"
count = 3
PI = 3.14159   # convention: constant
count += 1

JavaScript

let name = "Ada";
let count = 3;
const PI = 3.14159;  // truly constant
count += 1;
Rule: use const by default, let when you must reassign. Never use the old var.

Functions

Python

def greet(name):
    return f"Hi {name}"

# lambda
double = lambda x: x * 2

JavaScript

function greet(name) {
  return `Hi ${name}`;
}

// arrow function
const double = (x) => x * 2;

Note the backticks `...` for f-string-style interpolation, and ${ } where Python uses { }.

Lists / Arrays

Python — list

nums = [1, 2, 3]
nums.append(4)
doubled = [n * 2 for n in nums]
total = sum(nums)

JavaScript — array

const nums = [1, 2, 3];
nums.push(4);
const doubled = nums.map(n => n * 2);
const total = nums.reduce((a, b) => a + b, 0);
Comprehension → methods: Python list comprehensions become .map(), .filter(), and .reduce() chains in JavaScript.

Dicts / Objects

Python — dict

user = {"name": "Ada", "age": 36}
user["age"] = 37
for key, val in user.items():
    print(key, val)

JavaScript — object

const user = { name: "Ada", age: 36 };
user.age = 37;
for (const [key, val] of Object.entries(user)) {
  console.log(key, val);
}

In JS, keys usually have no quotes, and you read them with dot notation: user.name.

Loops and conditionals

Python

for i in range(3):
    print(i)

if count > 0:
    print("positive")
elif count == 0:
    print("zero")
else:
    print("negative")

JavaScript

for (let i = 0; i < 3; i++) {
  console.log(i);
}

if (count > 0) {
  console.log("positive");
} else if (count === 0) {
  console.log("zero");
} else {
  console.log("negative");
}

Classes

Python

class Dog:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return f"{self.name} barks"

d = Dog("Rex")

JavaScript

class Dog {
  constructor(name) {
    this.name = name;
  }
  speak() {
    return `${this.name} barks`;
  }
}
const d = new Dog("Rex");

self becomes this, __init__ becomes constructor, and you need the new keyword.

Async / await

Python

import httpx

async def get_user(id):
    async with httpx.AsyncClient() as c:
        r = await c.get(f"/users/{id}")
        return r.json()

JavaScript

async function getUser(id) {
  const r = await fetch(`/users/${id}`);
  return await r.json();
}
Good news: async/await works almost identically. If you understand it in Python, you already understand it in JavaScript.
