JavaScript vs TypeScript

TypeScript is not a different language you have to relearn. It is JavaScript — with a type checker bolted on. Every valid JavaScript file is already valid TypeScript. You opt into as much safety as you want.

The one-sentence definition

TypeScript = JavaScript + types, checked before the code runs. The browser cannot run TypeScript directly — a build step compiles it down to plain JavaScript first. The types exist only to catch your mistakes; they vanish at runtime.

The same code, both ways

JavaScript

function total(items) {
  return items
    .map(i => i.price * i.qty)
    .reduce((a, b) => a + b, 0);
}

// Nothing stops this bug:
total("oops");  // crashes at runtime

TypeScript

type Item = { price: number; qty: number };

function total(items: Item[]): number {
  return items
    .map(i => i.price * i.qty)
    .reduce((a, b) => a + b, 0);
}

total("oops"); // caught before running

The logic is identical. TypeScript just adds : Item[] and : number so the editor and compiler catch wrong usage instantly.

Coming from Python type hints

If you have written def total(items: list[Item]) -> float: in Python, TypeScript will feel familiar — just stricter and actually enforced by the build.

Python hints (optional)

from dataclasses import dataclass

@dataclass
class Item:
    price: float
    qty: int

def total(items: list[Item]) -> float:
    return sum(i.price * i.qty for i in items)

TypeScript (enforced)

interface Item {
  price: number;
  qty: number;
}

function total(items: Item[]): number {
  return items.reduce(
    (sum, i) => sum + i.price * i.qty, 0);
}
Key difference: In Python, hints are optional and ignored at runtime unless you run mypy. In TypeScript, the type check is a required build step — bad types stop the build.

What types buy you

Benefit What it means day to day
Autocomplete Your editor knows every field and method. You type less and guess nothing.
Catch bugs early Typos, wrong arguments, and undefined access are flagged as you type.
Safe refactoring Rename a field and the compiler shows every place that must change.
Living documentation The types are the contract. New teammates read them instead of guessing.

What types cost

  • A build/compile step (though modern tools make this near-instant).
  • A bit more typing up front — you declare shapes like interface.
  • A small learning curve for advanced types (generics, unions). You do not need these on day one.
