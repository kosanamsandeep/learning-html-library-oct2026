You already think like a programmer. Now borrow the browser's language.

You know Python. That means 80% of JavaScript is already familiar — variables, loops, functions, objects. What is genuinely new is where the code runs (the browser), how it talks to a live page (the DOM), and the safety net you bolt on top (TypeScript). This mini-track is designed to build interest before you commit to a full bootcamp.

The one-line mental model

Thing What it actually is Python analogy
JavaScript The programming language the browser can run natively. Like Python, but the "standard runtime" is a web page.
TypeScript JavaScript plus a compile-time type checker. Strips down to plain JS to run. Like Python type hints + mypy, but stricter and mandatory-ish.
React A library for building UIs as reusable components that re-render on data change. Like a templating engine that updates itself when your data changes.
DOM The live, in-memory tree the browser builds from your HTML. JS edits this tree. Like an object tree you mutate — except the screen redraws when you do.
Node.js JavaScript running outside the browser (servers, tools, scripts). No DOM here. Like running python script.py — just node script.js.

How to use this before a bootcamp

  2. Skim Python vs JS — you will recognise almost everything.
