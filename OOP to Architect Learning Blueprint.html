OOP → SOLID → Architecture Mastery Through 10 Projects

Purpose: This document is designed for both a human learner and an Agentic AI. The AI should generate each project end-to-end while explaining architecture decisions, patterns, folder structure, UML, SOLID principles, debugging exercises, and refactoring opportunities.

  • Observe architecture evolution.
  • Refactor bad code into good code.

Instructions For Agentic AI

For EVERY project generate:

  1. Problem Statement
  2. Business Use Cases
  3. Requirements
  4. UML Diagram
  5. Class Diagram
  6. Sequence Diagram
  7. Folder Structure
  8. Complete Source Code
  9. Type Hints Everywhere
  10. DTO Layer
  11. Service Layer
  12. Repository Layer (where applicable)
  13. Unit Tests
  14. Debugging Exercises
  15. Intentional Bugs
  16. Refactoring Exercises
  17. SOLID Violations and Fixes
  18. Architect Notes

For every class explain:

Why does this class exist?
Why not place this logic elsewhere?
What SOLID principle is being applied?
How does this help scale the system?
