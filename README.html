Learning Path

Self-paced curriculum across ML concepts, system design, data structures, side projects, and end-to-end builds. Folders are numbered in suggested reading order — but every track is independent.

The tracks

01 · CONCEPTS

ML / AI concept library

Activation functions, transformers, RAG, evaluation, vision, MCP, Docker / kubectl cheatsheets — 50+ pages.

 02 · COMPARISONS

Cross-platform comparisons

LLM providers, agent dev kits, agentic frameworks, RAG strategies — side-by-side.

 04 · SYSTEM DESIGN

LLD + HLD, beginner → pro

OOP, SOLID, design patterns, UML, scalability, DBs, distributed systems, famous case studies. Includes the database selection guide.

 05 · DATA STRUCTURES

DSA — beginner → advanced

Big-O through trees, graphs, tries, DP, interview patterns. 60-day roadmap.

 06 · SIDE PROJECTS

Applied project tracks

FastAPI service builds and LangGraph agent workflows, organized by technology under one side-projects hub.

 07 · LEARNING PROJECTS

Python OOP → architect

p1–p20: from student management CRUD to RAG platform, event-driven queue, API gateway.

 SYSTEM DESIGN ACADEMY

15 hands-on builds from the systemdesign42 curriculum

Fundamentals (rate limiter, consistent hashing, bloom filter, idempotency, URL shortener), case studies (distributed counter, leaderboard, presence, saga, geo lookup), and AI engineering (agentic patterns, multi-agent, memory, context, knowledge Q&A with eval).

 INDUSTRY STANDARDS

How the major AI providers say to build agents, design tools, package skills, and integrate Claude Code / Codex into your SDLC. Two runnable sample projects + a stay-updated guide, every claim cited to the official source.

 PROGRAMMING LANGUAGES TRACK

Go & Rust bootcamp (advantages, syntax vs Python, why they're fast, how to pick them up) plus 20 single-file parallel projects mirroring the Python learning_projects. Now also a Web track — JavaScript → TypeScript → React — with Python/JS comparisons and a mermaid DOM explainer.

Suggested reading order

  1. Skim 01_concepts for the topic you're curious about.
  2. For a real Python career path, follow 07_learning_projects top to bottom.
  3. To prep for product-company interviews, do 04_system_design + 05_data_structures in parallel (30 + 60 days).
  4. To get hands-on with modern Python APIs, build fastapi_projects P1 → P6 in order.
  5. Use langgraph_projects when you need agent orchestration.
  6. To learn testing properly (pytest, fixtures, mocks, integration, E2E, TDD), work through testing_projects P1 → P10.
  7. To learn async Python concurrency, follow asyncio_projects P1 → P5.
  8. To turn famous system-design patterns into running code, walk through system_design_academy — fundamentals, case studies, and AI engineering, 15 projects total.
  9. To level-up on official best practices for agents/tools/skills and to wire Claude Code or Codex into your day job, read industry_standards — five guides + two runnable sample projects + a stay-updated playbook.
  10. To pick up Go and Rust quickly using the Python work you already know, run through programming_languages_track — bootcamp pages first, then read each Python pn alongside its Go and Rust twins, and use the JS/TS/React web track to prep for a JavaScript bootcamp.
