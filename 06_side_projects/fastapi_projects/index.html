6 hands-on projects · Beginner → Production

FastAPI, learned by building things that get progressively harder

This track teaches FastAPI the same way ../langgraph_projects/ folder teaches LangGraph: one project per concept, each project's README.html explains what problem we're solving, how FastAPI solves it, and what goes wrong if you don't use these patterns.

Along the way you'll learn: FastAPI vs Flask, async/await, Pydantic validation, dependency injection, Swagger / OpenAPI, httpx for upstream calls, JWT auth, and the operational patterns you need before going to production.

The 6 projects Build these in order

P1 · BEGINNER

Hello FastAPI

3-route app. See auto-generated Swagger. Compare line-by-line with the same Flask app. The "wow" moment.

 P2 · BEGINNER

Todo CRUD with Pydantic + DI

Full REST CRUD. Pydantic models for validation. Dependency injection to swap storage backends without touching routes.

 P3 · INTERMEDIATE

Async DB with SQLAlchemy

Move from in-memory to a real database using async SQLAlchemy. See why blocking calls in an async route ruin throughput.

 P4 · INTERMEDIATE

FastAPI + httpx aggregator

Call 3 upstream APIs concurrently and merge the results. Demonstrates async's real superpower vs the sequential / threaded version.

 P5 · ADVANCED

JWT auth + protected routes

OAuth2 password flow, bcrypt password hashing, JWT issue + verify, role-based access via dependencies.

 P6 · PRODUCTION

Production-grade service

Settings via pydantic-settings, structured logging, request IDs, global error handlers, lifespan, background tasks, health checks, tests.

How to run any project

cd 06_side_projects/fastapi_projects/p1_hello_fastapi    # or any other project
python -m venv .venv
.venv\Scripts\activate               # Windows
pip install -r requirements.txt
uvicorn main:app --reload

# Open the interactive Swagger UI
# http://127.0.0.1:8000/docs
# Open the alternative ReDoc UI
# http://127.0.0.1:8000/redoc

Every project uses uvicorn as the ASGI server and ships a requirements.txt. You only need Python 3.11+ — no Docker, no DB server for projects 1, 2, 4, 5 (project 3 uses SQLite, project 6 uses SQLite by default).
