Build 01 · Beginner

Your first AutoGen agent

One AssistantAgent wrapping a model client. This is the atom of every AutoGen system — get this running and everything else is composition.

What this build does

Create a model client (the connection to an LLM), wrap it in an AssistantAgent, and run a single task. AutoGen is async-first, so everything happens inside asyncio.

Beginner AssistantAgent OpenAIChatCompletionClient async

The structure

flowchart LR
    task["task: 'Say hello'"] --> agent["AssistantAgent"]
    agent --> client["model client
(OpenAI / Azure / local)"]
    client --> llm["LLM"]
    llm --> reply["TextMessage reply"]
    reply --> agent

The agent is a thin, reusable wrapper around a model client.

The code

import asyncio
from autogen_agentchat.agents import AssistantAgent
from autogen_ext.models.openai import OpenAIChatCompletionClient

async def main() -> None:
    # 1) A model client = your connection to an LLM.
    model_client = OpenAIChatCompletionClient(model="gpt-4o")

    # 2) An agent = LLM + a name + (optionally) a system message.
    agent = AssistantAgent(
        name="assistant",
        model_client=model_client,
        system_message="You are a concise, helpful assistant.",
    )

    # 3) Run a task. result.messages is the full exchange.
    result = await agent.run(task="Explain AutoGen in one sentence.")
    print(result.messages[-1].content)

    await model_client.close()

asyncio.run(main())

Streaming to the console

For a live, token-by-token experience, stream the agent's run into the built-in Console UI. 

from autogen_agentchat.ui import Console

async def main():
    model_client = OpenAIChatCompletionClient(model="gpt-4o")
    agent = AssistantAgent("assistant", model_client=model_client)

    # run_stream yields events; Console renders them nicely.
    await Console(agent.run_stream(task="Write a haiku about Python."))
    await model_client.close()

Swapping models — the client is the only thing that changes

Provider Client
OpenAI OpenAIChatCompletionClient(model="gpt-4o")
Azure OpenAI AzureOpenAIChatCompletionClient(...)
Anthropic AnthropicChatCompletionClient(model="claude-3-5-sonnet")
Local / Ollama OpenAIChatCompletionClient(model="llama3", base_url=...)
Key idea: agents are model-agnostic. You write the agent once and switch the model client to move between providers or run locally.

Best practices

  • Always await model_client.close() (or use it as an async context manager) to release connections.
  • Give every agent a clear system_message. It defines the agent's role — critical once you have several.
  • Keep secrets in env vars (OPENAI_API_KEY), never in code.
