Two agents that collaborate until done

A writer drafts, a critic reviews, and they loop in a RoundRobinGroupChat until a termination condition fires. This is the core AutoGen pattern: agents converse, a rule decides when to stop.

What this build does

Two agents take turns. The writer produces a draft; the critic gives feedback. The writer revises. When the critic is satisfied it says APPROVE, and a TextMentionTermination ends the conversation.

Beginner+ RoundRobinGroupChat TextMentionTermination MaxMessageTermination

The conversation loop

sequenceDiagram
    participant T as Team (RoundRobin)
    participant W as writer
    participant C as critic
    T->>W: task "Write a tagline"
    W-->>T: draft v1
    T->>C: review draft v1
    C-->>T: "too long, cut it"
    T->>W: feedback
    W-->>T: draft v2
    T->>C: review draft v2
    C-->>T: "APPROVE"
    Note over T: TextMentionTermination("APPROVE") -> STOP

Round-robin = fixed turn order. The termination condition is what prevents an infinite back-and-forth.

The code

import asyncio
from autogen_agentchat.agents import AssistantAgent
from autogen_agentchat.teams import RoundRobinGroupChat
from autogen_agentchat.conditions import TextMentionTermination, MaxMessageTermination
from autogen_agentchat.ui import Console
from autogen_ext.models.openai import OpenAIChatCompletionClient

async def main():
    client = OpenAIChatCompletionClient(model="gpt-4o")

    writer = AssistantAgent(
        "writer", model_client=client,
        system_message="You write short marketing taglines. Revise based on feedback.",
    )
    critic = AssistantAgent(
        "critic", model_client=client,
        system_message=(
            "Critique the tagline in one line. "
            "When it is excellent, reply with the single word APPROVE."
        ),
    )

    # Stop when the critic says APPROVE, OR after 10 messages (safety net).
    termination = TextMentionTermination("APPROVE") | MaxMessageTermination(10)

    team = RoundRobinGroupChat([writer, critic], termination_condition=termination)

    await Console(team.run_stream(task="Tagline for a coffee brand for developers."))
    await client.close()

asyncio.run(main())
Composable termination: conditions combine with | (OR) and & (AND). TextMentionTermination("APPROVE") | MaxMessageTermination(10) means "stop on approval, but never run more than 10 messages" — always add a cap.

Termination conditions you'll use

Condition Stops when…
TextMentionTermination("APPROVE") A message contains that text.
MaxMessageTermination(n) n messages have been sent (hard cap).
TokenUsageTermination(n) Token budget is reached (cost control).
HandoffTermination(target) An agent hands off to a target (e.g. a human).
ExternalTermination() You call .set() from outside (UI stop button).

RoundRobin vs Selector — who speaks next?

RoundRobinGroupChat

Fixed rotation: writer → critic → writer → … Predictable, great for pipelines and reviewer loops.

SelectorGroupChat

An LLM "manager" picks the best next speaker each turn based on the conversation. Better for dynamic teams (covered in build 04).

Best practices

  • Always pair a goal condition with a cap. "APPROVE OR max 10" prevents runaway loops and runaway bills.
  • Make roles distinct. If the writer and critic have similar prompts, the conversation stalls. Sharp, different system messages drive progress.
  • Use one shared model client across agents to reuse the connection.
