Microsoft AutoGen v0.4 · AgentChat

💬 AutoGen — agents that converse

AutoGen models a system as conversational agents running on an async actor runtime. Four incremental builds: a single assistant, a two-agent team, tool use, and multi-agent group chat with termination and observability.

The AutoGen mental model

Everything is a message-passing agent. An AssistantAgent wraps an LLM. A team (like RoundRobinGroupChat) coordinates several agents that take turns until a termination condition is met. You run a team with run() or stream it to a Console.

v0.4 is a full rewrite. The library is now layered: autogen-core (the actor runtime), autogen-agentchat (the easy agent/team API used here), and autogen-ext (model clients, tools, integrations).
