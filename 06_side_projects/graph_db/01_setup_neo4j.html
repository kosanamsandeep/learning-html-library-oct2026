Chapter 01 · Setup

Install a free graph database on your machine

We'll use Neo4j — the most popular graph database, with the best free tooling and the Cypher query language you'll master here. Pick one of three free options below. Beginners: choose Option A (Neo4j Desktop).

Which free option should I pick?

Option Best for Cost Effort
A · Neo4j Desktop Beginners on Windows/Mac — GUI, one-click DBs, bundled Browser Free 🟢 Easiest
B · Docker (Community) Devs who like containers / reproducible setups Free (Community Edition) 🟡 One command
C · Neo4j Aura Free No install at all — a small cloud DB in the browser Free tier 🟢 Sign-up only
Recommendation: Option A or B run fully on your machine (the request was "free in my local machine"). Aura is the zero-install fallback. All three give you the same Neo4j Browser and Cypher — the rest of this track works identically.

Option A · Neo4j Desktop (recommended for beginners)

Download Neo4j Desktop

Go to neo4j.com/download, download Neo4j Desktop for your OS, and run the installer. On first launch it gives you a free activation key — paste the one shown on the site.

Create a project + local DBMS

Click New → Create project. Inside the project click Add → Local DBMS. Give it a name (e.g. learning), set a password you'll remember (e.g. test1234), and pick the latest version.

Start the database

Hover the DBMS and press Start. When the dot turns green, it's running locally on bolt://localhost:7687.

Open Neo4j Browser

Click Open (it launches Neo4j Browser). This is your query console — you'll type Cypher here for the rest of the track.

Run your first query

Paste this and press Ctrl+Enter:

RETURN 'Hello, Graph!' AS greeting;

Option B · Docker (Neo4j Community Edition, free)

If you have Docker Desktop, one command gives you a clean, isolated Neo4j with the Browser on port 7474.

# Run Neo4j Community Edition (free). APOC plugin enabled for later chapters.
docker run --name neo4j-learning -d \
  -p 7474:7474 -p 7687:7687 \
  -e NEO4J_AUTH=neo4j/test1234 \
  -e NEO4J_PLUGINS='["apoc"]' \
  neo4j:latest
# Windows PowerShell (single line, ^ is for cmd; use backtick or one line in PS)
docker run --name neo4j-learning -d -p 7474:7474 -p 7687:7687 -e NEO4J_AUTH=neo4j/test1234 -e NEO4J_PLUGINS=[\"apoc\"] neo4j:latest

Open the Browser

Visit http://localhost:7474 in your browser.

Connect

Connection URL bolt://localhost:7687, user neo4j, password test1234.

Stop / start later

docker stop neo4j-learning
docker start neo4j-learning
Data persistence: the container above keeps data inside itself. To survive a container delete, add a volume: -v $HOME/neo4j/data:/data (use an absolute Windows path like -v C:\neo4j\data:/data).

Option C · Neo4j Aura Free (zero install)

Sign up

Go to neo4j.com/cloud/aura-free and create a free account.

Create a free instance

Choose the AuraDB Free tier. Important: it shows the generated password once — save it.

Open Query / Browser

Use the built-in Query editor in the Aura console — same Cypher, nothing to install.

Optional: connect from Python

You'll mostly use the Browser, but here's how apps talk to Neo4j — handy later.

# pip install neo4j
from neo4j import GraphDatabase

driver = GraphDatabase.driver("bolt://localhost:7687",
                              auth=("neo4j", "test1234"))

with driver.session() as session:
    result = session.run("RETURN 'Hello, Graph!' AS greeting")
    for record in result:
        print(record["greeting"])

driver.close()

Sanity checklist before moving on

  • ✅ Neo4j is running (green dot / container up / Aura instance ready).
  • ✅ You opened Neo4j Browser (or Aura Query).
  • ✅ RETURN 'Hello, Graph!' returned a result.
  • ✅ You remember your password.
Pro tip: in Neo4j Browser type :help for commands, and :play start for the built-in guide. Commands starting with : are Browser commands, not Cypher.
