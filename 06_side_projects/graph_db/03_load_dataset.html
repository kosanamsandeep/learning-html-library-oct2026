Chapter 03 · Data

Load a dataset to learn on

Practice needs data. You'll get two ready-made graphs: Neo4j's built-in Movies dataset (one command) and a custom social + e-commerce graph you paste in a single block. Every later chapter queries these.

Dataset A · The built-in Movies graph (fastest start)

Neo4j ships a guided Movies dataset. In Neo4j Browser, run:

:guide movie-graph

Step through the guide and click the CREATE block it shows (or paste the official seed). It builds :Person and :Movie nodes linked by :ACTED_IN, :DIRECTED, :REVIEWED, etc. Verify it loaded: 

MATCH (n) RETURN labels(n) AS label, count(*) AS count
ORDER BY count DESC;
Note: on some versions the command is :play movies instead of :guide movie-graph. Either opens the same guided seed. If your edition lacks it, just use Dataset B below — it's self-contained.

Dataset B · Social + e-commerce (paste this whole block)

This is our main practice dataset. It mixes people, friendships, products, purchases, and reviews — enough to learn recommendations, fraud-style patterns, and paths. Paste it all into Neo4j Browser and run once.

// ---- Reset (optional): wipe everything first ----
MATCH (n) DETACH DELETE n;

// ---- People ----
CREATE
  (alice:Person {name:'Alice',  age:30, city:'London'}),
  (bob:Person   {name:'Bob',    age:35, city:'London'}),
  (carol:Person {name:'Carol',  age:28, city:'Paris'}),
  (dave:Person  {name:'Dave',   age:42, city:'Berlin'}),
  (erin:Person  {name:'Erin',   age:25, city:'Paris'}),
  (frank:Person {name:'Frank',  age:38, city:'London'}),

// ---- Products ----
  (laptop:Product {name:'Laptop',    price:1200, category:'Tech'}),
  (phone:Product  {name:'Phone',     price:800,  category:'Tech'}),
  (book:Product   {name:'Graph Book',price:40,   category:'Books'}),
  (coffee:Product {name:'Coffee',    price:15,   category:'Food'}),
  (mouse:Product  {name:'Mouse',     price:25,   category:'Tech'}),

// ---- Friendships (undirected idea, stored one way) ----
  (alice)-[:FRIENDS_WITH {since:2018}]->(bob),
  (alice)-[:FRIENDS_WITH {since:2020}]->(carol),
  (bob)-[:FRIENDS_WITH   {since:2019}]->(dave),
  (carol)-[:FRIENDS_WITH {since:2021}]->(erin),
  (dave)-[:FRIENDS_WITH  {since:2017}]->(frank),
  (erin)-[:FRIENDS_WITH  {since:2022}]->(frank),

// ---- Purchases ----
  (alice)-[:BOUGHT {on:'2023-01-10'}]->(laptop),
  (alice)-[:BOUGHT {on:'2023-02-02'}]->(book),
  (bob)-[:BOUGHT   {on:'2023-01-15'}]->(laptop),
  (bob)-[:BOUGHT   {on:'2023-03-01'}]->(mouse),
  (carol)-[:BOUGHT {on:'2023-02-20'}]->(phone),
  (carol)-[:BOUGHT {on:'2023-02-21'}]->(book),
  (dave)-[:BOUGHT  {on:'2023-01-30'}]->(coffee),
  (erin)-[:BOUGHT  {on:'2023-04-05'}]->(book),
  (frank)-[:BOUGHT {on:'2023-03-12'}]->(phone),

// ---- Reviews (rating 1-5) ----
  (alice)-[:REVIEWED {rating:5}]->(laptop),
  (bob)-[:REVIEWED   {rating:4}]->(laptop),
  (carol)-[:REVIEWED {rating:5}]->(book),
  (erin)-[:REVIEWED  {rating:3}]->(book);
One CREATE, many rows: note the whole thing is a single statement — commas separate the patterns, and earlier variables (like alice) are reused in later lines.

People connected to people (FRIENDS_WITH) and to products (BOUGHT / REVIEWED). This shape powers every example ahead.

Confirm it loaded

// Count nodes by label
MATCH (n) RETURN labels(n) AS label, count(*) AS count;

// See the whole graph visually (small datasets only!)
MATCH (n)-[r]->(m) RETURN n, r, m;

You should see 6 Person and 5 Product nodes. If you see doubles, you ran the CREATE twice — run the reset line and load once.

Loading big data later (CSV)

For real datasets you'll import CSVs. The pattern (for when you're ready):

LOAD CSV WITH HEADERS FROM 'file:///people.csv' AS row
MERGE (p:Person {id: row.id})
SET p.name = row.name, p.age = toInteger(row.age);
Heads-up: LOAD CSV reads from Neo4j's import/ folder by default. We'll stick to the pasted dataset so you can focus on Cypher, not file paths.
