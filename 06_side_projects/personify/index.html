What is this service?

Personify-Service is a contacts / personal-CRM style REST API. A user can sign upsign in and then createlistupdatedelete their personal contacts. It is deliberately built like a "real" backend so it can demonstrate clean architecture, not just CRUD.

The tech stack at a glance

Concern Choice Why it's there
Web framework Tornado (async) Non-blocking HTTP server & routing
Relational store PostgreSQL + SQLAlchemy + Alembic Users (strong schema, migrations)
Document store MongoDB + PyMongo Contacts (flexible, per-user documents)
Object storage MinIO (S3-compatible) Files / avatars
Validation / DTOs marshmallow Request & response schemas
Auth JWT bearer + pbkdf2 hashing Stateless tokens, hashed passwords
Quality gates pytest · mypy · ruff Tests, type-checking, linting
Runtime Docker · docker-compose · nginx Reproducible local + prod environments
