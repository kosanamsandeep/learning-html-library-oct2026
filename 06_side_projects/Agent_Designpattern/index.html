How to use this hub

  1. Open any chapter card to read a simple explanation, see mermaid diagrams, study a 2026 real-time scenario, and review the framework comparison table.
  2. Each chapter has a project/ folder — a small, production-grade Python OOP implementation that demonstrates the pattern using GoF / architectural design patterns.
  3. Run any project: cd NN_chapter/project && pip install -r requirements.txt && python main.py. All projects use a mock LLM by default — no API keys needed.

Interview cheat-sheet — all 21 patterns (2026)

One-line elevator pitch + the question most likely to be asked. Open the chapter card for full depth.

#PatternOne-line answerLikely interview question
01Prompt Chaining Pipeline of prompts where each step's output is the next step's input — solves complex tasks by decomposition. "How is prompt chaining different from a single big prompt? When does each step need its own LLM call?"
02Routing Classify the request, then dispatch to the right handler/agent/model — cheaper and more accurate than one giant prompt. "Design a router for a support bot with billing / technical / sales intents. How do you handle ambiguous inputs?"
03Parallelization Run independent sub-tasks concurrently (asyncio / fan-out-fan-in) to cut latency. "You have 5 sub-queries to answer. How do you parallelize them safely with rate limits and partial failures?"
04Reflection Generator + Critic loop — the agent reviews its own draft and revises until quality criteria are met. "How do you stop a reflection loop from going on forever? What's a good stopping criterion?"
05Tool Use (Function Calling) LLM emits a structured call (JSON schema) for an external function; runtime validates, executes, returns the result. "How do you validate tool arguments and handle a tool that fails or returns garbage?"
06Planning Generate an explicit multi-step plan from a goal, then execute and replan on failure. "When should the planner be a separate LLM call vs inlined into the agent? Show a re-plan trigger."
07Multi-Agent Collaboration Specialist agents (researcher / critic / synthesizer / coder) cooperating, usually under an orchestrator. "Orchestrator-worker vs autonomous swarm — when do you pick which?"
08Memory Management Short-term context window + long-term episodic / vector memory + summarization to bridge them. "How do you keep a 6-month chat history accessible without blowing the context window?"
09Learning & Adaptation Improve from feedback — RLHF, supervised fine-tuning, few-shot updates, bandits. "Online vs offline learning for an agent. How do you avoid catastrophic forgetting?"
10Model Context Protocol (MCP) Open standard ("USB-C for LLMs") for tools / resources / prompts so any client and any server can talk. "Why MCP instead of bespoke function calling? What does an MCP server expose?"
11Goal Setting & Monitoring Make the agent's objective explicit (SMART) and measure progress against success criteria. "How does an agent know it's done? Difference between completion and success."
12Exception Handling & Recovery Retries with backoff, circuit breakers, fallbacks, dead-letter queues — keep the agent useful when tools fail. "Walk through your retry policy for a flaky third-party API. When do you open a circuit breaker?"
13Human-in-the-Loop Approval gates for high-impact / irreversible actions; escalation when confidence is low. "Design a HITL gate for a bot that can refund money. What state machine and audit trail do you need?"
14Knowledge Retrieval (RAG) Retrieve relevant chunks from an external store, then generate a grounded, citeable answer. "RAG vs fine-tuning — pick one and defend it. How do you evaluate retrieval quality (recall@k, MRR)?"
15Inter-Agent Communication (A2A) Open protocol for cross-framework agent collaboration — message bus, capabilities, identity. "Why a wire protocol instead of just shared Python objects? When is A2A overkill?"
16Resource-Aware Optimization Pick the cheapest model / strategy that meets the quality, latency, and cost budget — tier picker per request. "How do you decide between gpt-5-nano and a frontier model for a given query? Show a routing rule."
17Reasoning Techniques Explicit thinking — Chain-of-Thought, Tree-of-Thoughts, ReAct, Self-Consistency. "When does ReAct beat plain CoT? What's a real example where Self-Consistency matters?"
18Guardrails / Safety Input filters (PII, prompt injection) + output filters (toxicity, policy) + behavioral constraints. "How do you defend against prompt injection from a retrieved document? Layered defenses."
19Evaluation & Monitoring Offline golden sets + online metrics (latency, cost, success-rate) + traces + drift detection + A/B tests. "How do you evaluate a non-deterministic agent? Build me a golden set + scoring rubric."
20Prioritization Rank tasks / candidates by urgency, importance, expected value, dependencies — classic example: WSJF. "Inbox of 50 incidents — what scoring function picks the next one to work on?"
21Exploration & Discovery Curiosity-driven search for unknown unknowns — epsilon-greedy, UCB1, Thompson sampling, novelty bonuses. "Exploit-vs-explore in an agent that recommends content. Pick a strategy and justify it."
