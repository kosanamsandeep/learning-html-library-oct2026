Chapter 19 — Evaluation & Monitoring

Offline evals before launch. Online metrics + traces after launch. Both are non-negotiable.

ObserverDecoratorTelemetry

What is it?

Two halves:

  • Offline eval — run a curated test set through the agent, score with metrics or LLM-as-judge.
  • Online monitoring — record latency, cost, success rate, user feedback, traces of every step in production.
Mental model: unit tests + APM (Datadog / Grafana) for agents.

2026 real-time scenario — Sales-AI rollout

A 2026 sales SaaS ships a v2 outreach agent. Before deploy: 200-prompt eval set with response-rate / tone scores. Post-deploy: every send is traced (LangSmith / Phoenix), with latency, cost, and reply-rate dashboards. Auto-rollback rule: if reply-rate drops > 15% week-on-week, revert.

Interview Q&A

What's an eval set?
A curated set of (input, expected_output_or_criteria) pairs that exercises the agent's surface. Grow it with every production failure — that's the only way the set stays representative.
LLM-as-judge — pitfalls?
Position bias, length bias, self-preference. Mitigate with paired comparisons, randomized order, and judge ensembles. Always anchor with at least a small human-labeled subset.
