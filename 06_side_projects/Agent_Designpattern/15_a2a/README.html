Chapter 15 — Inter-Agent Communication (A2A)

Open standard so agents from different vendors / frameworks can collaborate.

MediatorPub-SubOpen standard

What is it?

Where MCP is LLM ↔ tool, A2A is agent ↔ agent. Each agent advertises an Agent Card (skills, endpoints, auth). Tasks are exchanged via JSON-RPC over HTTP/SSE; messages, parts (text/file/structured), and artifacts give a uniform vocabulary.

Mental model: SMTP for agents — different mail servers but the same envelope.

Interview Q&A

Why A2A vs just HTTP?
A2A standardizes the semantics: agent cards, task lifecycle, parts/artifacts, auth, streaming updates. Plain HTTP gives you transport but no shared vocabulary.
Security in A2A?
OAuth / API keys per agent card; signed tokens for tasks; allow-list of skills; redact PII before broadcasting.
