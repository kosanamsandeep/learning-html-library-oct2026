Chapter 02 — Routing

Conditional dispatch. Classify the request, then send it to the right specialist.

StrategyFactoryDispatch

What is it?

Where chaining is a fixed path, routing is a chosen path. A classifier (LLM, embedding similarity, or rules) reads the input and picks one of several downstream handlers.

Mental model: the receptionist at a hospital — looks at your problem, sends you to cardiology, dermatology, or the pharmacy.

2026 real-time scenario — Telecom support copilot

A telecom rolls out an in-app copilot in 2026. ~70% of tickets are repetitive (data balance, plan info), 25% need account access, 5% are billing disputes that legally require a human. Routing decides the path within ~150ms so the LLM never even sees a refund-dispute ticket — it goes straight to a human queue with context attached.

Interview Q&A

LLM router vs embedding router?
LLM router = highest accuracy, ~500ms, costs tokens. Embedding router (semantic-router) = ~50ms, free after embedding cache, slightly less accurate. Hybrid: embedding first, fallback to LLM on low confidence.
How do you handle "no match"?
Always include a default / fallback route. Log the input for offline review and either ask the user to clarify or hand off to a human.
