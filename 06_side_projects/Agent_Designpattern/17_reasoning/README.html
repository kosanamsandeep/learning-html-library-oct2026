Chapter 17 — Reasoning Techniques

CoT, ToT, Self-Consistency, ReAct, Reflexion — make the model's thinking explicit.

What is it?

Spend more inference compute to get better answers on hard questions. Five canonical techniques:

  • Chain-of-Thought (CoT): "think step by step." One linear chain.
  • Tree-of-Thoughts (ToT): branch into multiple thoughts, prune by self-evaluation.
  • Self-Consistency: sample N CoTs and majority-vote.
  • ReAct: interleave Thought / Action (tool) / Observation steps.
  • Reflexion: after failure, write a verbal lesson and retry.

2026 real-time scenario — Math tutoring app

A 2026 K-12 math app uses CoT for routine problems, samples 5 CoTs and votes for word problems (self-consistency), and switches to ReAct + a Python tool for ones that need numerical solving. Result: 96% accuracy on JEE-level questions vs 78% with single-shot.

Interview Q&A

When does CoT actually help?
For multi-step arithmetic, logic, code reasoning. For trivia / classification it adds tokens with no gain. Always measure on a held-out set first.
Reasoning models (o1 / Gemini-Thinking) vs prompted CoT?
Reasoning models do CoT internally and aren't shown to the user. They're more accurate on hard problems but slower / pricier. Prompted CoT gives you visibility and control; reasoning models trade that for raw quality.
