Chapter 05 — Tool Use (Function Calling)

The LLM picks an external function to invoke with typed arguments. Then a runtime executes it and feeds the result back.

CommandAdapterFunction calling

What is it?

An LLM alone is read-only. Tool use makes it actuating: it can call get_weather(city), place_order(sku, qty), search_docs(query). The LLM emits a structured call (JSON) which the runtime validates and executes.

Mental model: a manager who never lifts a finger but knows exactly which specialist to call and how to brief them.

2026 real-time scenario — Smart-home command

"Hey assistant, if rain is forecast for Bengaluru tonight, close the balcony awning and tell my partner." The agent calls get_forecast("Bengaluru", "tonight"), then conditionally calls set_device("awning", "close") and send_message("partner", ...). The LLM never closes the awning — it asks the runtime to.

Interview Q&A

How do you stop the LLM from making up tools?
Validate the function name against the registry, validate args against a Pydantic / JSON-Schema, and refuse silently with a structured error fed back into the next LLM turn.
Tool use vs MCP?
Tool use is the capability. MCP is a standard protocol for exposing tools so any LLM can discover and use them without custom integration.
