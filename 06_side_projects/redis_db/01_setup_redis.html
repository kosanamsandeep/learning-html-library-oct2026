Chapter 01 · Setup

Install Redis on your machine — free, in minutes

Redis is open-source and free. Pick the path that matches your OS. The fastest and most reproducible is Docker; on Windows the cleanest native route is WSL2. You'll finish with a running server and a redis-cli prompt.

Option A · Docker (recommended, any OS)

One command gives you a clean, isolated Redis server. Requires Docker Desktop.

# Pull and run Redis, mapping the default port 6379
docker run --name redis -p 6379:6379 -d redis:7

# Open an interactive redis-cli inside the container
docker exec -it redis redis-cli

You'll see the prompt 127.0.0.1:6379>. Type PING — Redis replies PONG. That's a working database.

Want persistence + a UI? The official redis/redis-stack image bundles Redis plus RedisInsight (a GUI at http://localhost:8001) and modules like JSON & Search: 
docker run -d --name redis-stack -p 6379:6379 -p 8001:8001 redis/redis-stack:latest

Option B · Windows (WSL2 or Memurai)

Redis doesn't ship an official native Windows build, so use one of these:

WSL2 (recommended on Windows)

Install a Linux distro, then install Redis inside it:

# In PowerShell (admin), once:
wsl --install

# Then inside Ubuntu:
sudo apt update && sudo apt install -y redis-server
sudo service redis-server start
redis-cli ping   # → PONG

Memurai (native Windows service)

Memurai is a Redis-compatible server packaged for Windows. Download the free Developer edition, install it as a service, and connect with its bundled memurai-cli (same commands as redis-cli).

Honestly? On Windows, Docker (Option A) or WSL2 give the most authentic, up-to-date Redis. Prefer those over old native ports.

Option C · Native Linux / macOS

# macOS (Homebrew)
brew install redis
brew services start redis

# Debian / Ubuntu
sudo apt update && sudo apt install -y redis-server
sudo systemctl enable --now redis-server

# Verify
redis-cli ping   # → PONG

Option D · Redis Cloud (free tier, no install)

If you can't run anything locally, the managed Redis Cloud free tier gives a small hosted database. Create a database, copy its host/port/password, and connect:

redis-cli -h your-endpoint.redislabs.com -p 12345 -a 'your-password'
Security: never commit the password. Use an environment variable (REDISCLI_AUTH) or a secrets manager, and don't expose Redis to the public internet without auth + TLS.

Meet redis-cli (your main tool)

The CLI is a REPL: type a command, get a reply instantly. Try these now:

PING                       # → PONG (server is alive)
SET greeting "hello redis"   # → OK
GET greeting              # → "hello redis"
INCR visits               # → (integer) 1
INCR visits               # → (integer) 2
DBSIZE                     # → number of keys
KEYS *                     # → list keys (dev only — see ch.04)
FLUSHALL                   # → wipe everything (careful!)
Handy CLI thing What it does
redis-cli Connect to localhost:6379
redis-cli -n 1 Use logical database #1 (0–15 by default)
redis-cli MONITOR Live-stream every command the server runs
redis-cli --stat Live throughput/memory stats
INFO Server stats: memory, clients, persistence
HELP @string List commands in a group

Connect from Python (optional, for later)

# pip install redis
import redis

r = redis.Redis(host="localhost", port=6379, db=0, decode_responses=True)
r.set("greeting", "hello from python")
print(r.get("greeting"))   # hello from python

decode_responses=True returns Python str instead of raw bytes — convenient while learning.

Sanity checklist before moving on

✅ redis-cli ping returns PONG
✅ SET then GET round-trips a value
✅ INCR returns an incrementing integer
✅ You know how to open the CLI again tomorrow
