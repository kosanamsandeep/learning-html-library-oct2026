📦 Dependencies, supply chain & safe requests

Most of your app is code you didn't write. A vulnerable package or a typo-squatted install can compromise everything — and the requests calls you make to other services are an attack surface of their own (SSRF). This page hardens both.

Your real attack surface includes every dependency

You audit your 5%. Attackers target the 95% you imported. Supply-chain security is about trusting that code deliberately.

Pin, lock, and scan

# Run these in CI so a vulnerable or insecure change fails the build:
pip-audit                 # known CVEs in installed packages
bandit -r app/            # insecure code patterns (eval, shell=True, etc.)
pip install --require-hashes -r requirements.txt   # verified, pinned installs
Typosquatting watch: double-check package names before installing (requests vs request, python-jose vs lookalikes). Prefer well-maintained, widely-used packages; review new/obscure ones before adding.

SSRF: when your own requests call is the weapon

Server-Side Request Forgery happens when an attacker controls (even partially) a URL your server fetches. They point it at internal services or the cloud metadata endpoint to steal credentials. It's OWASP A10 — and the requests library is the usual vehicle.

❌ Vulnerable — fetch a user-supplied URL as-is

import requests

@app.post("/fetch-preview")
def preview(url: str):
    # attacker sends url=http://169.254.169.254/latest/meta-data/  (cloud creds!)
    return requests.get(url).text

✅ Hardened — allow-list + block internal ranges + safe options

import ipaddress, socket
from urllib.parse import urlparse
import requests

ALLOWED_SCHEMES = {"https"}
ALLOWED_HOSTS = {"api.partner.com", "cdn.example.com"}

def is_public_ip(host: str) -> bool:
    ip = ipaddress.ip_address(socket.gethostbyname(host))
    return not (ip.is_private or ip.is_loopback or ip.is_link_local or ip.is_reserved)

def safe_get(url: str) -> requests.Response:
    p = urlparse(url)
    if p.scheme not in ALLOWED_SCHEMES or p.hostname not in ALLOWED_HOSTS:
        raise ValueError("url not allowed")
    if not is_public_ip(p.hostname):       # block internal/metadata targets
        raise ValueError("refusing internal address")
    return requests.get(
        url,
        timeout=(3, 10),               # (connect, read) — NEVER omit timeout
        allow_redirects=False,         # redirects can bypass your allow-list
        verify=True,                  # always verify TLS certs
        headers={"User-Agent": "my-api/1.0"},
    )
SSRF defenses, layered: allow-list destinations; resolve & block private/loopback/link-local/metadata IPs; disable auto-redirects (or re-validate each hop); run outbound calls through an egress proxy; and deny the app network access to the cloud metadata endpoint at the infra level.

requests hygiene — small flags, big safety

Option Set it to Why
timeout always (e.g. (3, 10)) Without it, a hung peer ties up a worker forever → DoS
verify True (default) Never disable cert checks; verify=False = MITM open door
allow_redirects False for fetches of user URLs Stops redirect-based allow-list bypass
Session + retries Session with bounded Retry Connection reuse; controlled, capped retries
Secrets in headers From settings, not literals Avoid leaking API keys in code/logs 
from requests.adapters import HTTPAdapter, Retry

session = requests.Session()
retries = Retry(total=3, backoff_factor=0.5,
                status_forcelist=[502, 503, 504], allowed_methods=["GET"])
session.mount("https://", HTTPAdapter(max_retries=retries))
resp = session.get("https://api.partner.com/v1/x", timeout=(3, 10))
Tip: for high-concurrency FastAPI, prefer an async client like httpx.AsyncClient so outbound calls don't block the event loop. The same hardening rules (timeouts, verify, allow-list, no blind redirects) apply.

Container & runtime supply chain

  • Build from minimal, pinned base images; scan images (trivy, grype).
  • Run as a non-root user; drop capabilities; read-only filesystem where possible.
  • Don't bake secrets into images or layers.
  • Keep base images and the Python runtime patched.

Supply-chain & requests checklist

  • Dependencies pinned with a hash-locked lockfile.
  • pip-audit + bandit (or semgrep) run in CI and gate merges.
  • Dependabot/Renovate keeps deps current; SBOM generated.
  • Every outbound requests/httpx call sets a timeout and keeps verify=True.
  • User-influenced URLs are allow-listed and blocked from internal/metadata IPs.
  • Redirects disabled (or re-validated) for fetches of untrusted URLs.
  • Container images scanned, non-root, no embedded secrets.
