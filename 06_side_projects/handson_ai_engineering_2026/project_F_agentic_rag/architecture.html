🧠 Agentic RAG · LangGraph state machine

Project F — Self-Reflective Agentic RAG

Inspired by C-RAG / Self-RAG. The graph grades retrieval relevance, generation groundedness and final answer quality, looping back through query rewriting when any check fails.

flowchart TD ST([START]) --> R[retrieve] R --> GR[grade_rel] GR -- relevant --> G[generate] GR -- not relevant --> RW[rewrite_query] RW --> R G --> GG[grade_groundedness] GG -- grounded --> GQ[grade_quality] GG -- hallucinated --> G GQ -- quality_ok --> END([END]) GQ -- weak --> RW GR -- max iters --> END GQ -- max iters --> END
