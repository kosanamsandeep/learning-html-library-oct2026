📚 RAG · Hybrid · RRF · Cross-encoder

Project C — Hybrid RAG

Combines dense vector search, BM25 sparse search and Reciprocal-Rank-Fusion, then re-ranks the fused list with a cross-encoder before generation.

1 · Pipeline

flowchart LR Q[Query] --> EMB[BGE-Large embedder] EMB --> DEN[Qdrant Dense Search
top-20] Q --> BM[BM25 Sparse Search
top-20] DEN --> RRF[RRF Fusion] BM --> RRF RRF --> RR[BGE-Reranker-v2-m3
cross-encoder] RR --> CTX[top-k context] CTX --> GEN[GPT-5 grounded answer
with citations]
