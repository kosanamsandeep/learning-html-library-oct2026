🧩 MCP Registration Examples

Same MCP server, different platforms — how to register it on each.

CL

Claude Code

CLI command

Run the claude mcp add command — it writes the config to ~/.claude.json automatically.

claude mcp add docs-search -- python /path/to/server.py

Or manually create ~/.claude.json:

{
  "projects": {
    "/home/you/your-project": {
      "mcpServers": {
        "docs-search": {
          "type": "stdio",
          "command": "/path/to/.venv/bin/python",
          "args": ["/path/to/server.py"]
        }
      }
    }
  }
}
CX

Codex CLI

TOML file

No CLI command — edit the config file directly.

~/.codex/config.toml 
[mcp_servers.docs-search]
transport = "stdio"
command = "/path/to/.venv/bin/python"
args = ["/path/to/server.py"]
tool_timeout_sec = 300

[mcp_servers.mcp-examples]
transport = "stdio"
command = "/path/to/.venv/bin/python"
args = ["/path/to/examples_server.py"]
tool_timeout_sec = 300
Py

Custom Python Client

Programmatic

No config file at all — you write a Python script that spawns and controls the server directly.

# pip install mcp

import asyncio
from mcp import ClientSession
from mcp.client.stdio import stdio_client, StdioServerParameters


async def main():
    # Point to your MCP server (same command as Claude Code)
    server_params = StdioServerParameters(
        command="/path/to/.venv/bin/python",
        args=["/path/to/server.py"],
    )

    # Spawn the server as a subprocess and connect via stdio
    async with stdio_client(server_params) as (read, write):
        async with ClientSession(read, write) as session:
            await session.initialize()

            # Discover tools
            tools = await session.list_tools()
            for tool in tools.tools:
                print(f"Tool: {tool.name}")

            # Call a tool
            result = await session.call_tool(
                "search_docs",
                arguments={"query": "FastAPI CORS"}
            )
            print(result.content)


asyncio.run(main())
