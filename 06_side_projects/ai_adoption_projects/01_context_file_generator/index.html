Project 01

Context File Generator

A CLI script that reads a canonical CLAUDE.md and auto-generates .cursorrules, copilot-instructions.md, and CODEX.md — keeping every AI tool in your ecosystem singing from the same songsheet.

OVERVIEW

Why generate context files?

Modern developers work with multiple AI coding assistants: Claude Code for architecture-level work, Cursor for inline editing, GitHub Copilot for autocomplete, and custom agents that need a CODEX. Each tool reads its own context file with a different format, location, and scope.

Without a single source of truth, teams drift: conventions fixed in CLAUDE.md never make it to .cursorrules, Copilot gets different instructions, and new hires are confused about which file to trust. The generator solves this by treating CLAUDE.md as the canonical file and rendering every tool-specific format from it on every change.

Core principle: One canonical context file, many tool-specific renderings. Never repeat your project conventions again.

CLAUDE.md passes through template rendering to produce every tool-specific context file.

The generator is a Python CLI that:

  1. Parses CLAUDE.md, extracting sections like "Project Overview", "Tech Stack", "Conventions", "Architecture Decisions", and "Testing Patterns".
  2. Maps each section to the target file format — for example, architecture decisions become a tree-sitter context comment in .cursorrules, while they become a bullet list in copilot-instructions.md.
  3. Renders each target file through a Jinja2 template that respects the exact file format, comment style, and structure expected by each tool.
  4. Writes the rendered files to the project root, with a summary of what changed.
STARTER CODE

Python CLI — context_file_generator.py

The script below reads CLAUDE.md, loads Jinja2 templates from a templates/ folder, and writes out all target context files. Run it with python generate.py or as a pre-commit hook to keep files in sync.

#!/usr/bin/env python3
"""context_file_generator.py — Read CLAUDE.md, write every tool context file."""

import pathlib
import re
import argparse
from datetime import date
from jinja2 import Environment, FileSystemLoader

# ---------- canonical source ----------
ROOT = pathlib.Path(__file__).resolve().parent
CLAUDEMD = ROOT / "CLAUDE.md"
TEMPLATES = ROOT / "templates"
OUTPUTS = {
    ".cursorrules":           TEMPLATES / "cursorrules.j2",
    "copilot-instructions.md": TEMPLATES / "copilot.j2",
    "CODEX.md":                TEMPLATES / "codex.j2",
    "cline.md":                TEMPLATES / "cline.j2",
    ".windsurfrules":          TEMPLATES / "windsurf.j2",
}


def parse_claude_md(text: str) -> dict:
    """Extract structured sections from CLAUDE.md into a dict."""
    sections = {}
    current_heading = "_meta"
    sections[current_heading] = []
    for line in text.splitlines():
        if line.startswith("## "):
            current_heading = line.strip("# ")
            sections[current_heading] = []
        else:
            sections.setdefault(current_heading, []).append(line)
    # Flatten each section to a single string
    return {k: "\n".join(v).strip() for k, v in sections.items()}


def render_all(ctx: dict) -> list[tuple[str, str]]:
    """Render each target file from Jinja2 templates."""
    env = Environment(loader=FileSystemLoader(str(TEMPLATES)))
    ctx["generated_at"] = date.today().isoformat()
    results = []
    for out_path, tmpl_rel in OUTPUTS.items():
        tmpl_name = tmpl_rel.name
        template = env.get_template(tmpl_name)
        rendered = template.render(ctx)
        out_file = ROOT / out_path
        out_file.write_text(rendered)
        results.append((out_path, len(rendered)))
    return results


def main():
    parser = argparse.ArgumentParser(description="Generate all AI context files")
    parser.add_argument("--source", default=CLAUDEMD, help="Path to CLAUDE.md")
    parser.add_argument("--check", action="store_true",
                        help="Exit 1 if any generated file is stale")
    args = parser.parse_args()

    source_text = pathlib.Path(args.source).read_text()
    ctx = parse_claude_md(source_text)
    ctx["project_name"] = ROOT.name

    results = render_all(ctx)
    for path, size in results:
        print(f"  ✓ {path}  ({size} chars)")
    print(f"\nGenerated {len(results)} context files.")


if __name__ == "__main__":
    main()

WHAT EACH TOOL NEEDS

Context file format differences

Each AI coding tool has a different context file format, location, and scope. Here is what you need to know to write templates for each one:

Tool File Format Location Scope
Claude Code CLAUDE.md Markdown, with ## sections as instructions Project root Global agent context, project-level
Cursor .cursorrules Markdown, no YAML frontmatter Project root Inline editing, Ctrl+K, chat
Copilot copilot-instructions.md Markdown with <!-- HTML comments --> for metadata .github/ or root Autocomplete and Copilot Chat
CODEX CODEX.md Markdown with structured metadata header Project root Custom agent systems, multi-agent orchestration
Windsurf .windsurfrules Plain text with rule-based syntax Project root Windsurf IDE agent
Cline / Continue cline.md Markdown Project root or .cline/ VSCode extension agent context
Tip: Keep a templates/ directory in your repo so the mapping is explicit and version-controlled. Add a pre-commit hook that re-runs the generator whenever CLAUDE.md changes.
STEP-BY-STEP

How to adopt this project

1
Write your canonical CLAUDE.md — include Project Overview, Tech Stack, Conventions, Architecture Decisions, Testing Patterns, Deployment, and any domain-specific rules.
2
Create Jinja2 templates for each target tool (see the starter above). Each template maps the sections from your canonical file into the format that tool expects.
3
Run the generator — python generate.py reads CLAUDE.md and writes every output file. Use --check in CI to fail if outputs are stale.
4
Commit all generated files — reviewers can see exactly what each tool sees. When CLAUDE.md changes, re-run the generator and commit the diff.
5
Add a pre-commit hook that auto-generates on git commit if CLAUDE.md has changed, so nobody forgets.
