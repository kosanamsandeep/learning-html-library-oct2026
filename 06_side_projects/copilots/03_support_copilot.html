🎧 Customer Support Copilot

A copilot that answers customer questions from your knowledge base, takes real actions through tools (check an order, start a refund), and escalates to a human when it's unsure or the stakes are high.

The story — why this copilot exists

Support teams drown in repetitive tickets: "Where's my order?", "How do I reset my password?", "What's your refund policy?". Customers hate waiting; agents burn out on the same questions.

This copilot deflects the repetitive 70%, resolves them instantly and correctly (with real data, not guesses), and routes the genuinely hard or sensitive cases to a human with full context — the perfect division of labour.

Inspired by: chatwoot/chatwoot agent bots and langgenius/dify support assistants — popular open platforms for AI-assisted support.

The copilot picks between knowledge (RAG) and action (tools), and a risk gate decides when a human must step in.

The code — tools the copilot can use

from langchain_core.tools import tool

@tool
def order_status(order_id: str) -> str:
    """Look up the shipping status of an order by its ID."""
    return db.get_order(order_id).status      # real system call

@tool
def start_refund(order_id: str, reason: str) -> str:
    """Begin a refund for an order. Requires human approval before finalising."""
    return billing.create_refund_request(order_id, reason)

@tool
def search_kb(query: str) -> str:
    """Search help-centre articles for policies and how-tos."""
    return retriever.invoke(query)            # the RAG store from project 01

The code — agent with an escalation gate

from langgraph.prebuilt import create_react_agent
from langgraph.checkpoint.memory import InMemorySaver

SYSTEM = (
    "You are a support copilot. Use search_kb for policy questions and "
    "tools for account actions. If you are unsure, the request is sensitive "
    "(refunds over $100, account closure, legal), or a tool fails, reply with "
    "'ESCALATE:' followed by a short summary for a human agent."
)

copilot = create_react_agent(
    "openai:gpt-4o",
    tools=[order_status, start_refund, search_kb],
    prompt=SYSTEM,
    checkpointer=InMemorySaver(),     # remembers the conversation per customer
)

def handle(msg: str, thread: str):
    cfg = {"configurable": {"thread_id": thread}}
    out = copilot.invoke({"messages": [("user", msg)]}, cfg)
    reply = out["messages"][-1].content
    if reply.startswith("ESCALATE:"):
        ticketing.create(reply, thread)          # hand off to a human
    return reply
Escalation is a first-class outcome. A great support copilot is measured not only by what it answers, but by how reliably it hands off what it shouldn't — protecting customers and the brand.

Human-in-the-loop for risky actions

For irreversible actions (refunds, cancellations), pause for approval instead of escalating the whole ticket — using the same interrupt pattern from the MCP/LangGraph projects:

from langgraph.types import interrupt

@tool
def start_refund(order_id: str, amount: float) -> str:
    """Refund an order; large amounts need an agent's OK."""
    if amount > 100:
        ok = interrupt({"action": "refund", "order": order_id, "amount": amount})
        if ok != "approve":
            return "Refund declined by agent."
    return billing.refund(order_id, amount)

Advantages this copilot brings

Advantage Why it matters
24/7 instant answers No queue for common questions; happier customers.
Acts, not just chats Resolves "where's my order" with real data via tools.
Safe escalation Hard/sensitive cases reach humans with full context.
Deflection & cost Frees agents for high-value work; lowers cost per ticket.
Consistent + on-policy Answers grounded in the current KB, not folklore.

Best practices

  • Ground answers in the KB (RAG) — never let it invent policy.
  • Gate irreversible actions behind approval or escalation thresholds.
  • Persist conversation state so context survives across messages.
  • Log every action for audit, and measure deflection + CSAT to prove value.
  • Give a graceful "talk to a human" exit at any time.
