HTTP · gRPC · curl · Auth

Everything you actually need to know about sending requests and getting responses

A practical, comparison-driven tour. Start with the Python requests library, then learn what's really flying over the wire, then learn the modern alternatives (gRPC), the universal debug tool (curl), and how to secure those calls (cookies, JWT, OAuth, client certs).

How requests.get/post/put/... work end-to-end, what a payload is, and the payload types (JSON, form, multipart, raw, query).

A memory trick for every family plus the codes you will actually see in production.

02b · Implement 1xx → 5xx in FastAPI

REST/HTTP vs gRPC side-by-side, with code, wire format, and a decision table.

04 · curl ↔ requests ↔ browser

The same request expressed three ways, so you can copy-paste between terminal, code, and DevTools.

05 · Parallel essentials you must learn

Headers, timeouts, retries, connection pools, TLS, redirects, streaming, idempotency, content negotiation, CORS, observability.

06 · Auth: cookies, JWT, Basic, OAuth, mTLS

What each method actually means, what a developer hands the server, and the security trade-offs.

07 · Real-time protocols & WebRTC (voice)

REST vs SSE vs WebSocket vs gRPC vs WebRTC, why talk-back voice apps (e.g. ChatGPT voice mode) use WebRTC, and how hard it is to implement.
