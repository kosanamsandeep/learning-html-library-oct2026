Chapter 04 · Translation guide

curl ↔ requests ↔ Browser DevTools

curl is the universal HTTP CLI. Every backend dev uses it for sanity checks. Learn to translate between curl, Python, and the browser's "Copy as curl" feature and you can debug anything.

The translation table

What you want curl requests
GET curl https://api.com/users requests.get("https://api.com/users")
GET with query curl "https://api.com/users?page=2" requests.get(url, params={"page": 2})
POST JSON curl -X POST -H "Content-Type: application/json" -d '{"name":"Aria"}' https://api.com/users requests.post(url, json={"name": "Aria"})
POST form curl -X POST -d "name=Aria&age=30" https://api.com/users requests.post(url, data={"name":"Aria","age":30})
Upload file curl -F "avatar=@a.png" -F "name=Aria" https://api.com/users requests.post(url, files={"avatar": open("a.png","rb")}, data={"name":"Aria"})
Header (auth) curl -H "Authorization: Bearer abc" https://api.com/me requests.get(url, headers={"Authorization": "Bearer abc"})
Basic auth curl -u user:pass https://api.com/private requests.get(url, auth=("user", "pass"))
Save body to file curl -o out.json https://api.com/data open("out.json","wb").write(requests.get(url).content)
Follow redirects curl -L https://api.com/r Default ON. Disable with allow_redirects=False
Show headers only curl -I https://api.com requests.head(url)
Verbose / debug curl -v https://api.com Enable urllib3 logging or use --trace-ascii in curl
Skip TLS verify (dev only!) curl -k https://localhost requests.get(url, verify=False)
Send cookies curl -b "sess=abc" https://api.com requests.get(url, cookies={"sess": "abc"})

The one curl flag combo to remember

curl -i -L -sS -X POST \
     -H "Content-Type: application/json" \
     -H "Authorization: Bearer $TOKEN" \
     -d '{"name":"Aria"}' \
     https://api.com/users
Flag Meaning
-i Include response headers in the output.
-L Follow redirects.
-sS Silent except for errors (good for scripts).
-X HTTP method.
-H Header — repeat the flag for each header.
-d Request body (auto-sets Content-Type to form unless you override).
-v Verbose — shows the TLS handshake, headers, everything. Your best debug friend.

The DevTools trick — copy the exact browser request

  1. Open the browser, open DevTools → Network tab.
  2. Reproduce the failing action.
  3. Right-click the failing request → Copy → Copy as cURL.
  4. Paste in your terminal. Reproducible bug in 10 seconds.
  5. To turn it into Python: paste into curlconverter.com and out comes requests code.
This is the single fastest debug loop a backend engineer can learn. "It works in Postman but not in code" almost always means a missing header or cookie — the curl copy reveals what the browser actually sent.

How the three relate

flowchart LR
    Browser -- "Copy as cURL" --> curl
    curl -- "curlconverter.com" --> Python[requests code]
    Python -- "logging / -v output" --> curl
    curl -- "same bytes on the wire" --> Server
    Browser -- "same bytes on the wire" --> Server
    Python -- "same bytes on the wire" --> Server

All three produce the same HTTP request on the wire. Picking one is just ergonomics.
