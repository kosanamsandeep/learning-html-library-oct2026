FastAPI implementations · 1xx → 5xx

How to actually return every status family in FastAPI

The companion to 02 · Status codes theory. There you learned what each family means; here you get copy-pasteable from fastapi import FastAPI, HTTPException code that returns them correctly — with the right headers, response models, and error handlers.

The three ways FastAPI sets a status code

Mechanism Use it for Example
@app.get(..., status_code=201) The default success code for an endpoint 201 on create, 202 on accept, 204 on delete
raise HTTPException(status_code=..., detail=...) Error paths (4xx / 5xx) — short-circuits the request 404 not found, 409 conflict, 403 forbidden
Response(...) / response.status_code = ... Dynamic codes decided at runtime, or custom headers/body 304 not modified, 206 partial, 503 + Retry-After
Rule of thumb: success codes go in the decorator, error codes are raised, and anything that needs a custom header or a runtime decision uses an explicit Response object.

One app that demonstrates every family

Each chapter expands a slice of this skeleton. Here is the shape of the whole thing:

from fastapi import FastAPI, HTTPException, Response, status
from fastapi.responses import RedirectResponse, JSONResponse
from pydantic import BaseModel

app = FastAPI(title="Status code playground")

class Item(BaseModel):
    id: int
    name: str

DB: dict[int, Item] = {}

# 2xx — create returns 201 + Location
@app.post("/items", status_code=status.HTTP_201_CREATED)
def create_item(item: Item, response: Response):
    if item.id in DB:
        # 4xx — conflict
        raise HTTPException(status.HTTP_409_CONFLICT, "id already exists")
    DB[item.id] = item
    response.headers["Location"] = f"/items/{item.id}"
    return item

# 4xx — not found
@app.get("/items/{item_id}")
def get_item(item_id: int):
    item = DB.get(item_id)
    if item is None:
        raise HTTPException(status.HTTP_404_NOT_FOUND, "item not found")
    return item

# 2xx — delete returns 204 (no body)
@app.delete("/items/{item_id}", status_code=status.HTTP_204_NO_CONTENT)
def delete_item(item_id: int):
    DB.pop(item_id, None)
    return Response(status_code=status.HTTP_204_NO_CONTENT)

# 3xx — redirect
@app.get("/old")
def old():
    return RedirectResponse("/items", status_code=status.HTTP_308_PERMANENT_REDIRECT)
Use the status module. from fastapi import status gives you readable names like status.HTTP_404_NOT_FOUND instead of magic numbers — self-documenting and typo-proof.
