A production MCP-powered LangGraph agent

Tie it together: a stateful agent with persistent memory, authenticated remote servers, robust error handling, human approval for risky tools, and observability.

The production architecture

flowchart TD
    U["User"] --> AG["LangGraph StateGraph
+ checkpointer (memory)"]
    AG --> GATE{"risky tool?"}
    GATE -->|"yes"| HITL["human approval
(interrupt)"]
    GATE -->|"no"| EXEC["ToolNode"]
    HITL -->|approved| EXEC

    CL -->|stdio| LOCAL["local MCP servers"]
    EXEC --> AG
    AG -.traces.-> OBS["LangSmith / OTEL"]

Memory persists threads, a gate pauses for approval on dangerous tools, and every step is traced.

1 · Stateful agent with persistent memory

Add a checkpointer so the agent remembers across turns and survives restarts. Each conversation is a thread_id.

from langchain_mcp_adapters.client import MultiServerMCPClient
from langgraph.prebuilt import create_react_agent
from langgraph.checkpoint.memory import InMemorySaver
# production: from langgraph.checkpoint.postgres import PostgresSaver

client = MultiServerMCPClient({...})
tools = await client.get_tools()

agent = create_react_agent(
    "openai:gpt-4o",
    tools,
    checkpointer=InMemorySaver(),          # swap for Postgres in prod
)

config = {"configurable": {"thread_id": "user-42"}}
await agent.ainvoke({"messages": [{"role": "user", "content": "Remember my name is Sam."}]}, config)
await agent.ainvoke({"messages": [{"role": "user", "content": "What's my name?"}]}, config)  # -> Sam

2 · Authenticating to remote servers

Hosted MCP servers use bearer tokens or OAuth. Pass headers per server and keep secrets in env vars.

import os

client = MultiServerMCPClient({
    "github": {
        "url": "https://api.githubcopilot.com/mcp/",
        "transport": "streamable_http",
        "headers": {"Authorization": f"Bearer {os.environ['GITHUB_TOKEN']}"},
    },
})
FastMCP servers can require auth too. FastMCP 2.0 supports bearer-token and OAuth providers on the server side, so the tools you publish can verify callers — not just the ones you consume.

3 · Human-in-the-loop for risky tools

Don't let an agent delete files or send money unattended. LangGraph's interrupt pauses the graph so a human can approve. 

from langgraph.types import interrupt, Command

def approval_gate(state):
    last = state["messages"][-1]
    for call in getattr(last, "tool_calls", []):
        if call["name"] in RISKY_TOOLS:        # e.g. {"delete_file", "send_email"}
            decision = interrupt({"tool": call["name"], "args": call["args"]})
            if decision != "approve":
                return Command(goto="model")     # reject -> back to the LLM
    return Command(goto="tools")              # approved -> execute

Resume after the human responds:

await agent.ainvoke(Command(resume="approve"), config)

4 · Error handling & resilience

  • Tool errors don't crash the agent — ToolNode returns the error as an observation so the model can retry or apologise. Keep server errors descriptive.
  • Connection failures: wrap get_tools() in retry/backoff; a remote server may be cold-starting.
  • Time-box tool calls so one slow MCP server can't hang the whole turn.
  • Validate inputs inside each tool — never trust LLM-supplied arguments for filesystem, shell, or DB access.

5 · Observability

# Enable LangSmith tracing — see every reasoning step and MCP tool call
import os
os.environ["LANGSMITH_TRACING"] = "true"
os.environ["LANGSMITH_API_KEY"] = "ls-..."
# Now every agent.ainvoke is captured: prompts, tool inputs/outputs, latency, cost.

MCP servers can also emit OpenTelemetry; pair both to trace a request from the agent down into the tool implementation.

Where to discover & publish servers

Platform Use it to…
modelcontextprotocol/servers Grab official reference servers (filesystem, fetch, git, memory).
MCP Registry Search the official catalog of published servers.

FastMCP Cloud / your infra Deploy and host the servers you build for others to consume.

Production checklist

  • Persist state with a real checkpointer (Postgres), keyed by thread_id.
  • Authenticate every remote server; keep tokens in a secret store.
  • Gate risky tools behind human approval via interrupt.
  • Trace everything (LangSmith + OTEL) before shipping.
  • Pin server versions and only connect trusted, scoped servers.
  • Cache get_tools() and reconnect with backoff on failure.

What you can now build

You can write MCP tools with FastMCP, consume them in LangGraph via langchain-mcp-adapters, expose resources & prompts, connect many local and remote servers, pull in public/pre-built servers from the registry and Smithery, and harden it all with memory, auth, approvals, and tracing. That's a complete, portable agent tooling stack.
