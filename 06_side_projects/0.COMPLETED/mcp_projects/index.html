Model Context Protocol · FastMCP · LangGraph

🔌 MCP — give your agents a universal tool port

MCP is the "USB-C for AI tools": one open protocol so any agent can use any tool, data source, or prompt — no custom glue. Five incremental builds: write a FastMCP server, plug its tools into a LangGraph agent, add resources & prompts, connect multiple/remote servers, and ship a production agent that also consumes public, ready-made MCP servers.

Why MCP exists — the M×N problem

Before MCP, wiring M agents to N tools meant writing M×N custom integrations. MCP turns it into M+N: every tool exposes one standard server, every agent speaks one standard client.

flowchart LR
    subgraph Before["❌ Before MCP — M×N glue"]
        a1["Agent A"] --- t1["GitHub"]
        a1 --- t2["Postgres"]
        a2["Agent B"] --- t1
        a2 --- t2
    end
    subgraph After["✅ With MCP — M+N"]
        A1["Agent A"] --> H{{"MCP"}}
        A2["Agent B"] --> H
        H --> T1["GitHub MCP server"]
        H --> T2["Postgres MCP server"]
    end

Each tool is written once as an MCP server; each agent connects once as an MCP client.

The three things an MCP server can expose

🛠️ Tools

Functions the model can call to take action (query a DB, send an email, do math). Model-controlled.

📄 Resources

Read-only data the app can load into context (files, rows, docs), addressed by URI. App-controlled.

💬 Prompts

Reusable, parameterised prompt templates the user can invoke (e.g. "summarise this PR"). User-controlled.

For agents, tools are 90% of the story. These projects focus on building and consuming tools, then layer in resources and prompts in build 03.

langchain-mcp-adapters converts MCP tools into LangChain tools so a LangGraph agent can call them like any other tool.

Install

# FastMCP — the fastest way to build MCP servers/clients (now part of the official SDK)
pip install fastmcp

# LangGraph + the adapter that turns MCP tools into LangChain tools
pip install langgraph langchain-mcp-adapters "langchain[openai]"
FastMCP vs the SDK: FastMCP is the high-level, decorator-based framework (@mcp.tool). FastMCP 1.0 was merged into the official mcp Python SDK; FastMCP 2.0 (the fastmcp package) adds clients, auth, deployment, testing and more. We use FastMCP throughout.
