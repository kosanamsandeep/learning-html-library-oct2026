Side Projects · Asyncio track

Asyncio from beginner to advanced — five projects that make concurrency feel practical

Asyncio is Python's built-in way to run many waiting tasks without using one thread per task. It shines when your program spends time waiting for network, disk, queues, timers, APIs, or sockets. These projects start with async/await and end with a real TCP chat server.

What asyncio is

Asyncio is cooperative concurrency. A task runs until it reaches an await. At that point it politely gives control back to the event loop, and the event loop lets another task run. This is different from preemptive threading, where the operating system interrupts threads whenever it wants.

Task starts
->
Hits await
->
Event loop runs another task
->
First task resumes later
Memory aid: asyncio does not make waiting faster. It makes waiting useful by letting other tasks run while one task is paused.

When asyncio helps and when it does not

Great fit

  • Calling many APIs at the same time.
  • WebSocket or chat servers with many idle clients.
  • Background workers reading from queues.
  • Polling, timers, retries, cancellation, timeouts.
  • FastAPI endpoints that call async databases or HTTP clients.

Not the right tool by itself

  • Heavy CPU work such as image processing or model training.
  • Blocking libraries that do not provide async APIs.
  • Code that never reaches await.
  • Simple scripts where sequential code is easier and fast enough.

Core vocabulary

Word Meaning Simple example
Coroutine An async function call that can be paused and resumed. fetch_order(10)
Event loop The scheduler that decides which coroutine resumes next. asyncio.run(main())
Task A scheduled coroutine running under the event loop. asyncio.create_task(fetch())
Await Pause here until the awaited thing is ready. await asyncio.sleep(1)
Gather Run many awaitables concurrently and collect results. await asyncio.gather(a(), b())
Queue Async handoff point between producers and workers. await queue.put(job)
Semaphore Limit how many tasks may enter a section at once. async with semaphore:
Cancellation Ask a task to stop because it is no longer needed. task.cancel()
