Task 7

Tool Integration — Real-World Power

Your agent reaches beyond itself — searching the web, calling APIs

🧩 What This Task Teaches

An agent that can only "think" isn't very useful. Task 7 shows how to give your workflow hands — the ability to interact with the real world through tools. Here, a DuckDuckGo search node fetches live information from the internet.

Core Concept: A "tool node" is just a regular node that calls an external service (web search, database, API) instead of just transforming state internally. The tool's results become part of the state, available to all downstream nodes.

🔧 The Tool-Integrated Pipeline

🎯
Enhance Query Node (LLM-powered)
Takes user query → LLM makes it more specific and searchable
🦆
Search Tool Node (DuckDuckGo — EXTERNAL TOOL)
Takes enhanced query → Calls DuckDuckGo API → Returns real web results
📝
Summarize Node (LLM-powered)
Takes search results → LLM creates a concise, useful summary
📤
Format Output Node
Presents everything in a clean, readable format

🌐 Without vs With Tools

❌ Without Tools (Tasks 2-6)

  • • LLM can only use its training data
  • • Information is static and may be outdated
  • • Can't access real-time information
  • • Can't interact with external systems
  • • Limited to text transformation

✅ With Tools (Task 7+)

  • • Agent searches the live internet
  • • Gets current, real-time information
  • • Can query databases, APIs, files
  • • Acts on the world (send emails, etc.)
  • • Truly useful for real tasks

💻 The Tool Node Pattern

from ddgs import DDGS def search_tool_node(state: ToolState): """This node calls an EXTERNAL tool — DuckDuckGo""" query = state["enhanced_query"] # Call the external tool ddgs = DDGS() results = ddgs.text(query, max_results=3) # Extract and store results in state search_results = [] for result in results: title = result.get('title', '') body = result.get('body', '') search_results.append(f"{title}: {body}") # Results now available to ALL downstream nodes return {"search_results": search_results}

Notice: A tool node looks exactly like any other node. It receives state, does work, returns state updates. The only difference is that its "work" involves calling an external service.

✅ Advantages of This Task

  • Real-world data — agent gets live, current information from the internet
  • LLM + Tools synergy — LLM enhances queries AND summarizes results
  • Error handling — demonstrates graceful degradation when tools fail
  • Extensible pattern — same approach works for any tool (SQL, APIs, file systems)

💡 Key Insight

Tools transform your workflow from a "thinking machine" into an "acting machine". The LLM provides intelligence (query enhancement, summarization), and tools provide information and action capabilities. Together, they form a complete agent.
