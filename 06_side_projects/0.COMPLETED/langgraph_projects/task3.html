Task 3

StateGraph — State Accumulation

State doesn't just persist — it GROWS

🧩 What This Task Teaches

Task 2 showed that state persists. Task 3 takes it further: state accumulates. Each node doesn't just read state — it adds to it. Think of it like building a shopping cart: each step adds items, and the final checkout sees everything that was collected.

Key Concept: State accumulation means nodes BUILD on previous results. Node 2 sees what Node 1 added. Node 3 sees what Nodes 1 AND 2 both added. Information grows, never shrinks.

💻 The Accumulation Pattern

# Each node ADDS to existing state, never replaces it def add_apple(state): new_items = state["items"] + ["apple"] # Read old + add new new_total = state["total"] + 5 return {"items": new_items, "total": new_total} def add_banana(state): new_items = state["items"] + ["banana"] # Sees ["apple"] from previous step! new_total = state["total"] + 3 # Sees $5 from previous step! return {"items": new_items, "total": new_total}

🔀 How Task 3 Differs from Task 2

Task 2 → Task 3 Evolution

Task 2 proved that state persists (name stays accessible).
Task 3 shows that nodes build upon state — lists grow, counters increment, data enriches. This is the pattern that makes complex AI workflows possible: each step contributes to a growing understanding.

Aspect Task 2 Task 3

💡 Key Insight

The accumulation pattern is what makes AI agents actually learn during a workflow. Without this, every step would start with zero context. With it, each step builds on all previous work — exactly like a human researcher who takes notes as they go.
