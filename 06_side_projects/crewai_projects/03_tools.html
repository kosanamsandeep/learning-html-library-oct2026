Build 03 · Intermediate

Give agents real abilities

Agents become useful when they can act: search the web with a prebuilt SerperDevTool, or run your own logic via the @tool decorator.

What this build does

We attach a web-search tool to a researcher and add a custom tool that the agent can call. Tools are assigned per-agent and the LLM decides when to use them.

Intermediate crewai_tools SerperDevTool @tool

Tools are listed on the agent; the model chooses which to invoke per step.

Built-in tools from crewai_tools

from crewai import Agent, Task, Crew, Process
from crewai_tools import SerperDevTool, ScrapeWebsiteTool

search = SerperDevTool()          # needs SERPER_API_KEY in env
scrape = ScrapeWebsiteTool()      # fetch + read a page

researcher = Agent(
    role="Web Researcher",
    goal="Find up-to-date facts about {topic}",
    backstory="You verify claims against live sources.",
    tools=[search, scrape],       # ← abilities attached here
    llm="gpt-4o",
)
crewai[tools] ships dozens of ready tools: web search/scrape, file & directory read, code interpreter, RAG over PDFs/CSVs, database queries, and more. Import and drop them into tools=[...].

Custom tools with the @tool decorator

Any Python function becomes a tool. The name and docstring tell the LLM what it does.

from crewai.tools import tool

@tool("Word Counter")
def word_count(text: str) -> int:
    """Count the number of words in the given text."""
    return len(text.split())

writer = Agent(
    role="Editor",
    goal="Ensure the article is under 300 words",
    backstory="A precise editor who checks length with tools, not guesses.",
    tools=[word_count],
    llm="gpt-4o",
)

For richer tools (validation, typed args) subclass BaseTool:

from crewai.tools import BaseTool
from pydantic import BaseModel, Field

class CountInput(BaseModel):
    text: str = Field(..., description="Text to measure")

class WordCountTool(BaseTool):
    name: str = "Word Counter"
    description: str = "Count words in text."
    args_schema: type[BaseModel] = CountInput

    def _run(self, text: str) -> int:
        return len(text.split())

Tool assignment: agent vs task

Attach on… Effect
Agent(tools=[...]) Agent can use the tool for any of its tasks.
Task(tools=[...]) Overrides the agent's tools just for that task.

Best practices

  • Name and document tools clearly — the LLM chooses based on the name and docstring.
  • Prefer built-ins from crewai_tools before writing your own.
  • Validate & sandbox anything touching the filesystem, network, or shell.
  • Keep tool results compact — huge outputs bloat context and cost.
