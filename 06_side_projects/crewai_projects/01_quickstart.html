Build 01 · Beginner

Your first crew

One Agent, one Task, one Crew. Learn the three nouns that everything in CrewAI is built from.

What this build does

We hire a single agent (a senior researcher), give it one task with a clear expected_output, put it in a crew, and call kickoff().

Beginner Agent Task Crew kickoff()

The three building blocks

Agent = who. Task = what. Crew = the team that runs it.

The code

from crewai import Agent, Task, Crew

# 1) The Agent — a persona drives better LLM behaviour.
researcher = Agent(
    role="Senior AI Researcher",
    goal="Find and explain the latest trends in {topic}",
    backstory="You are a meticulous analyst who values accuracy over hype.",
    llm="gpt-4o",            # model string; reads OPENAI_API_KEY from env
    verbose=True,
)

# 2) The Task — expected_output is what makes results consistent.
research_task = Task(
    description="Research the 3 most important developments in {topic} this year.",
    expected_output="A bullet list of 3 developments, each with a one-line why-it-matters.",
    agent=researcher,
)

# 3) The Crew — assemble and run.
crew = Crew(agents=[researcher], tasks=[research_task], verbose=True)

result = crew.kickoff(inputs={"topic": "agentic AI frameworks"})
print(result)

Why role, goal, backstory matter

Field Purpose Tip
role The agent's job title / identity. Be specific: "Senior Python Reviewer", not "Helper".
goal What success looks like for this agent. One clear objective; supports {placeholders}.
backstory Context/personality that shapes tone & rigor. This is your biggest quality lever — invest here.
Inputs are templated. Any {topic} in a role, goal, or task description is filled from kickoff(inputs={...}), so the same crew is reusable across topics.

expected_output is not optional in practice

It's technically required and it's the single biggest driver of consistent results. Vague → rambling answers. Precise → structured, reliable output you can parse downstream.

Best practices

  • Write rich backstories. CrewAI leans on persona; a good backstory beats extra prompt engineering.
  • Make expected_output concrete ("a JSON list of…", "a 200-word summary…").
  • Keep API keys in env vars (OPENAI_API_KEY, SERPER_API_KEY).
  • Start with verbose=True to watch the agent's reasoning while learning.
