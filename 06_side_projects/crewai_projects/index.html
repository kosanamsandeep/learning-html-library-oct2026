CrewAI · role-based agent crews

🚀 CrewAI — agents as a team of coworkers

CrewAI models AI work like a company: each agent has a role, goal, and backstory; they complete tasks as a crew. Four incremental builds: a single agent, a sequential crew, tools, and Flows with memory.

The CrewAI mental model

The vocabulary is the framework. An Agent is a worker with a persona. A Task is a unit of work with a clear expected_output. A Crew assembles agents + tasks and runs them in a Process (sequential or hierarchical). It's the fastest way to get a believable multi-agent team running.

Two layers: Crews (autonomous, role-playing teams — this folder's focus) and Flows (event-driven, precise orchestration that can wrap crews). Build 04 shows Flows.

Install

pip install crewai
# tools package (web search, file/RAG tools, etc.)
pip install 'crewai[tools]'

# scaffold a full project (recommended for real work)
crewai create crew my_crew
crewai create crew generates a project with agents.yaml and tasks.yaml config files — the recommended structure once you go beyond a script.
