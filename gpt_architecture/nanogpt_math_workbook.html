1 Vector Spaces, Matrices & Operations

Why in nanoGPT: Every word starts as a token ID. That ID is mapped to a continuous vector via the token embedding table (wte). A position vector (wpe) is added to it to tell the model where the token sits in the sequence. Then matrix multiplications project these vectors into Query, Key, and Value spaces.

flowchart LR subgraph Embed["Token → Vector"] T["Token ID: 24"] --> TE["Token Embedding (wte)
lookup row 24"] TE --> TV["e = [0.5, -1.2, 0.8]"] end subgraph Pos["Position"] P["Pos: 2"] --> PE["Position Embedding (wpe)
lookup row 2"] PE --> PV["p = [0.1, 0.4, -0.2]"] end TV --> Add["✚ Element-wise Add"] PV --> Add Add --> X["x = e + p
= [0.6, -0.8, 0.6]"] X --> Proj["Linear Projection
q = x · W_q"] style Embed fill:#1e293b,stroke:#38bdf8 style Pos fill:#1e293b,stroke:#a78bfa style Add fill:#1e293b,stroke:#fbbf24 style Proj fill:#1e293b,stroke:#4ade80

Key Ideas

  • Vector: A list of numbers. In nanoGPT, every token is represented as a vector in high-dimensional space (e.g., 384 dimensions).
  • Element-wise addition: Add corresponding positions: [a, b] + [c, d] = [a+c, b+d]. This is how token embedding + position embedding combine.
  • Dot product: u · v = u₁v₁ + u₂v₂ + .... Measures how aligned two vectors are. Core of the attention mechanism.
  • Matrix × vector: Each output element is a dot product between a row of the matrix and the vector. This is how we project embeddings into Q/K/V space.

Tip: When reading matrix shapes in nanoGPT, you'll see (B, T, C) — Batch, Time/sequence position, Channels/embedding dimension. Matrix multiply "contracts" the last dimension of the first with the second-to-last of the second.

📝 Practice Problems

Problem 1.1 — Embedding Addition

Given token vector e = [0.5, -1.2, 0.8] and position vector p = [0.1, 0.4, -0.2], compute the input vector x = e + p.

Answer: x = [0.5+0.1, -1.2+0.4, 0.8+(-0.2)] = [0.6, -0.8, 0.6]

Problem 1.2 — Linear Projection

Given input vector x = [1, 2] and projection matrix Wq = [[1, 0], [-1, 2]], compute the query vector q = x · Wq.

Answer: q₁ = 1·1 + 2·(-1) = -1, q₂ = 1·0 + 2·2 = 4 → q = [-1, 4]

Problem 1.3 — Dot Product Similarity

Given q = [2, 1] and two key vectors k₁ = [1, 3], k₂ = [-1, 0], calculate dot products q·k₁ᵀ and q·k₂ᵀ.

Answer: q·k₁ = 2·1 + 1·3 = 5. q·k₂ = 2·(-1) + 1·0 = -2. Token 1 is more "relevant" to the query.

2 Dynamic Score Scaling & Variance Control

Why in nanoGPT: The dot product Q · Kᵀ grows with the dimension of the vectors. If keys and queries have dimension dk = 64, the dot product has variance ≈ 64. Large values push Softmax into "one-hot" territory — every token attends to just one other token. The fix: scale by 1/√dk to keep variance ≈ 1.

flowchart TB subgraph Before["Without Scaling: dₖ = 64"] B1["q, k ~ 0 mean, 1 variance
per component"] B2["dot = Σ qᵢ·kᵢ"] B3["variance of dot = dₖ = 64"] B4["standard deviation = 8"] B5["Softmax becomes near
one-hot ← BAD"] end subgraph After["With Scaling: ÷√dₖ"] A1["same q, k"] A2["dot = (Σ qᵢ·kᵢ) / √64"] A3["variance = 64/64 = 1"] A4["standard deviation = 1"] A5["Softmax stays diffuse ← GOOD"] end Before --> After style Before fill:#1e293b,stroke:#f87171 style After fill:#1e293b,stroke:#4ade80

Key Ideas

  • Variance of a sum: If you add n independent random variables each with variance σ², the sum has variance n·σ².
  • Dot product variance: Each of the dk products contributes variance 1 (assuming unit variance inputs), so total variance = dk.
  • Scaling: Dividing by √dk brings variance back to 1, keeping attention weights diffuse at initialization.
Attention(Q, K, V) = Softmax( QKᵀ / √dₖ ) · V
📝 Practice Problems

Problem 2.1 — Variance Growth

Suppose components of q and k in ℝ64 are independent with mean 0 and variance 1. What is the expected variance of their dot product q · k before scaling?

Answer: Each of the 64 terms contributes variance 1. Variance = 64. The standard deviation is √64 = 8, meaning typical dot products are ≈ ±8 (range ~16).

Problem 2.2 — The Scaling Factor

Calculate the scaling factor 1/√dₖ when dₖ = 64. If an unscaled dot product score is 16.0, what is the scaled score?

Answer: 1/√64 = 1/8 = 0.125. Scaled score = 16.0 × 0.125 = 2.0. The scaled scores now have reasonable magnitude for Softmax to produce a diffuse distribution.

Problem 2.3 — Compare Distributions

Take raw scores [4.0, 2.0]. Before scaling (dₖ=1, no change), Softmax gives very concentrated weights. After scaling with dₖ=64 (divide by 8 → [0.5, 0.25]), compute both Softmax outputs and compare how "peaky" they are. Hint: Softmax formula is in the next tab if you need it.

Answer: Unscaled: e⁴/(e⁴+e²) = 54.6/61.0 = 0.88 vs 0.12 — very peaky.
Scaled: e⁰·⁵/(e⁰·⁵+e⁰·²⁵) = 1.65/2.93 = 0.56 vs 0.44 — much more balanced.

3 Probability Distributions & Softmax

Why in nanoGPT: After computing attention scores (how much should token t listen to token t′?), we need a proper probability distribution that sums to 1. Softmax converts raw scores into probabilities. It also converts the final output logits into a probability over the next character.

flowchart LR subgraph SoftmaxOp["Softmax in Attention"] direction TB IN["Raw scores z = [2.0, 0.0]"] --> EXP["Exponentiate
e² = 7.39, e⁰ = 1.0"] EXP --> SUM["Sum = 7.39 + 1.0 = 8.39"] SUM --> DIV["Divide each by sum
7.39/8.39 = 0.88
1.0/8.39 = 0.12"] DIV --> OUT["Attention weights
sum to 1.00"] end style SoftmaxOp fill:#1e293b,stroke:#38bdf8 style IN fill:#1e293b,stroke:#fbbf24 style OUT fill:#1e293b,stroke:#4ade80

Key Ideas

  • Softmax formula: P(zᵢ) = e^zᵢ / Σⱼ e^zⱼ. Always positive, always sums to 1.
  • Exponentiation amplifies differences: Score 2.0 vs 0.0 becomes probability 0.88 vs 0.12 — the gap widens.
  • Temperature scaling: Dividing scores by T > 1 flattens the distribution (more random). T → 0 makes it deterministic (one-hot).
Softmax(zᵢ) = ezᵢ / Σⱼ ezⱼ
📝 Practice Problems

Problem 3.1 — Basic 2-Way Softmax

Calculate Softmax for scores s = [2.0, 0.0].

Answer: e² = 7.39, e⁰ = 1.0, sum = 8.39. P₁ = 7.39/8.39 = 0.88, P₂ = 1.0/8.39 = 0.12.

Problem 3.2 — Temperature Effect

Raw scores [4.0, 2.0]. Apply temperature T = 2.0 (divide both by 2 → [2.0, 1.0]), then compute Softmax.

Answer: e² = 7.39, e¹ = 2.72, sum = 10.11. P₁ = 7.39/10.11 = 0.73, P₂ = 2.72/10.11 = 0.27. Compare to without temperature: e⁴/(e⁴+e²) = 0.88. Temperature flattens the distribution.

Problem 3.3 — 3-Way Softmax

Compute Softmax for scores [1.0, 2.0, 3.0].

Answer: e¹=2.72, e²=7.39, e³=20.09, sum=30.20. P = [2.72/30.20, 7.39/30.20, 20.09/30.20] = [0.09, 0.24, 0.67].

4 Triangular Causal Masking

Why in nanoGPT: Language models must be autoregressive — token at position t can only see tokens at positions ≤ t. To enforce this, we set the upper-triangular entries of the attention matrix to −∞ before Softmax. Since e−∞ = 0, future tokens get 0% attention weight.

Token₀→Token₃ all visible"] --> M["Apply mask:
upper triangle → -∞"] M --> O["Row 0: only token₀
Row 1: only token₀, token₁
Row 2: token₀, token₁, token₂"] end subgraph Detail["3×3 Example"] D1["[ 2.0, -∞, -∞ ]
[ 0.5, 2.5, -∞ ]
[ 1.0, 0.0, 2.0 ]"] end Masking --> Detail style Masking fill:#1e293b,stroke:#38bdf8 style Detail fill:#1e293b,stroke:#fbbf24

Key Ideas

  • Triangular matrix: Entries below the diagonal = allowed (past + current). Entries above = disallowed (future).
  • −∞ in Softmax: e−∞ → 0, so those positions contribute nothing to the weighted sum.
  • Row-wise operation: Each token row has its own attention distribution over ≤ t tokens.

Given 3×3 attention scores A = [[2.0, 1.0, 3.0], [0.5, 2.5, 1.5], [1.0, 0.0, 2.0]], apply causal mask (set upper-triangle entries where column > row to −∞).

Answer: Amasked = [[2.0, −∞, −∞], [0.5, 2.5, −∞], [1.0, 0.0, 2.0]]

Problem 4.2 — Masked Softmax

Compute row-wise Softmax for each row of the masked matrix above.

Answer: Row 0: e² = 7.39, e−∞ ≈ 0. P = [1.0, 0, 0].
Row 1: e0.5=1.65, e2.5=12.18, sum=13.83. P = [0.12, 0.88, 0].

5 Full Single-Head Self-Attention Assembly

Why in nanoGPT: This is the core operation of the Transformer. It combines everything you've learned: Q/K/V projections, scaled dot products, causal masking, Softmax, and weighted aggregation of values. One formula, five steps.

Attention(Q, K, V) = Softmax( QKᵀ / √dₖ + M ) · V

Problem 5.1 — Hand-Calculated Self-Attention

Consider 2 tokens (T=2), embedding dimension dₖ = 2.

Q = [[1, 0], [1, 1]]
K = [[1, 0], [0, 1]]
V = [[2, 4], [6, 8]]

Follow steps A through E.

Step A: Raw scores S = Q·Kᵀ
Row 0: [1,0]·[1,0]ᵀ = 1, [1,0]·[0,1]ᵀ = 0
Row 1: [1,1]·[1,0]ᵀ = 1, [1,1]·[0,1]ᵀ = 1
S = [[1, 0], [1, 1]]
Step B: Scale by 1/√dₖ
√2 ≈ 1.414. Divide each entry: [[1/1.414, 0/1.414], [1/1.414, 1/1.414]]
Sscaled ≈ [[0.707, 0], [0.707, 0.707]]
Step C: Causal mask
Set entry (0,1) to −∞ (future token for row 0). Row 1 is fine (both positions ≤ 1).
Smasked = [[0.707, −∞], [0.707, 0.707]]
Step D: Row-wise Softmax
Row 0: e0.707 = 2.03, e−∞ = 0. Sum = 2.03. W = [1.0, 0]
Row 1: e0.707 = 2.03, e0.707 = 2.03. Sum = 4.06. W = [0.5, 0.5]
Step E: O = W · V
Row 0: 1.0 × [2, 4] + 0 × [6, 8] = [2, 4]
Row 1: 0.5 × [2, 4] + 0.5 × [6, 8] = [4, 6]
O = [[2, 4], [4, 6]] ✅

Notice token₀ only sees itself (output = V₀). Token₁ sees both equally (average of V₀ and V₁) — exactly what causal attention should do.

6 Layer Normalization & Feed-Forward Networks

Why in nanoGPT: After tokens communicate via attention, each token needs to think independently (FFN). But deep networks suffer from activation magnitudes growing uncontrollably. LayerNorm fixes this by normalizing each token's features to zero mean and unit variance. Then the FFN applies a non-linear transformation.

Layer Normalization

For each token independently: compute μ and σ² across all its features, then normalize: (x − μ) / √(σ² + ε). Then scale and shift with learnable γ, β.

Feed-Forward Network

Two linear layers with a ReLU in between: FFN(x) = W₂ · ReLU(W₁ · x + b₁) + b₂. First layer expands 4×, second compresses back. Each token processes independently.

flowchart LR subgraph LN["LayerNorm"] direction TB IN1["x = [2, 4, 6, 8]
features of one token"] --> MU["μ = (2+4+6+8)/4 = 5"] IN1 --> VAR["σ² = ((2-5)² + ...)/4 = 5"] MU & VAR --> NORM["normalized = (x-μ)/√(σ²+ε)
= [-3, -1, 1, 3] / √5
= [-1.34, -0.45, 0.45, 1.34]"] NORM --> SCALE["γ · norm + β
(learned affine)"] end subgraph FFN["Feed-Forward"] direction TB IN2["x = 1.0"] --> L1["W₁x + b₁ = (2)(1) + (-0.5) = 1.5"] L1 --> RELU["ReLU(1.5) = max(0, 1.5) = 1.5"] RELU --> L2["W₂ · ReLU + b₂ = (1.5)(1.5) + 0 = 2.25"] end style LN fill:#1e293b,stroke:#38bdf8 style FFN fill:#1e293b,stroke:#fbbf24

Key Ideas

  • LayerNorm is per-token, per-batch: Unlike BatchNorm which normalizes across examples, LayerNorm normalizes across features for each individual token.
  • ReLU = max(0, x): Simple non-linearity. Negative values become 0, positive values pass through. This lets the model learn non-linear patterns.
  • 4× expansion: The inner FFN dimension is typically 4× the embedding dimension (e.g., 384 → 1536 → 384). This gives the model room to compute.
📝 Practice Problems

Problem 6.1 — Token Normalization

Given token vector x = [2, 4, 6, 8] (dimension C=4), compute μ, σ², and the normalized vector (ε=0).

Answer: μ = (2+4+6+8)/4 = 5. σ² = ((2-5)²+(4-5)²+(6-5)²+(8-5)²)/4 = (9+1+1+9)/4 = 5. Normalized: [(2-5)/√5, (4-5)/√5, (6-5)/√5, (8-5)/√5] = [-1.34, -0.45, 0.45, 1.34]. Zero mean, unit variance.

Problem 6.2 — FFN Forward Pass

Input x = 1.0. Linear layer: w₁ = 2.0, b₁ = -0.5. ReLU. Linear layer: w₂ = 1.5, b₂ = 0.0. Compute the output.

Answer: W₁x + b₁ = 2(1.0) + (-0.5) = 1.5. ReLU(1.5) = max(0, 1.5) = 1.5. W₂·(1.5) + 0 = 1.5 × 1.5 = 2.25.

Problem 6.3 — FFN with Negative Input

Same FFN as above, but input x = -0.5. Trace through.

Answer: W₁x + b₁ = 2(-0.5) + (-0.5) = -1.0 + (-0.5) = -1.5. ReLU(-1.5) = max(0, -1.5) = 0 (dead neuron). W₂·0 + 0 = 0. The ReLU killed the signal because the neuron wasn't activated.

7 Optimization & Loss Metrics

Why in nanoGPT: How do we know if the model is learning? Cross-Entropy Loss measures how surprised the model is by the actual next token. Lower loss = better predictions. Then gradients flow backward through the network to update parameters — and residual connections make this possible even with 100+ layers.

Cross-Entropy Loss

L = −ln(ptarget)
If the model assigns p = 0.25 to the correct next character, L = −ln(0.25) = 1.39.
Random baseline for 65 chars: L = ln(65) = 4.17.

Residual Gradient Flow

y = x + f(x) → dy/dx = 1 + f′(x)
The "+1" guarantees gradient can always flow backward, even if f′(x) = 0. This is why Transformers can be 100+ layers deep.

Key Ideas

  • Lower loss = better model: Loss of 4.17 = random guessing. Loss of 1.48 = scaled nanoGPT on Shakespeare. Loss of 0.0 = perfect prediction (overfitting).
  • Residual shortcut: The derivative of y = x + f(x) is 1 + f′(x). The "1" term means gradients from the loss can skip all the nonlinear layers and flow directly to the input. This is why deep Transformers train without vanishing gradients.
  • ln(65) = 4.17: This is the "is it learning?" sanity check. If loss is above 4.17, the model is worse than random.
📝 Practice Problems

Problem 7.1 — Random Baseline Loss

Tiny Shakespeare has 65 unique characters. Compute the random baseline cross-entropy loss: L = ln(65).

Answer: Lrandom = ln(65) ≈ 4.17. If your model's loss is above this, it's literally worse than random guessing.

Problem 7.2 — Model Loss

If the model assigns probability p = 0.25 to the correct next character, what is the cross-entropy loss? Compare to the bigram model's loss of ~2.5 from nanoGPT.

Answer: L = −ln(0.25) = −(−1.386) = 1.39. The bigram model at 2.5 corresponds to p ≈ e−2.5 = 0.082. The scaled nanoGPT at 1.48 corresponds to p ≈ e−1.48 = 0.23 — much more confident.

Problem 7.3 — Residual Gradient Shortcut

Given y = x + x², calculate dy/dx at x = 2. Notice that the gradient has a "1" component separate from the non-linear part.

Answer: dy/dx = 1 + 2x = 1 + 4 = 5. The "1" is the residual shortcut. Even if the non-linear part 2x were zero (e.g., if x=0 in a ReLU), the gradient would still be 1 — not zero. This is the Gradient Super Highway.

Problem 7.4 — Gradient Flow Through Residual Stack

A Transformer has 6 residual blocks. The loss gradient entering the final block has magnitude 1.0. Each block's non-linear path has derivative 0.5. What gradient reaches the input?

Answer: Through residual shortcut: 1 × 1 × 1 × 1 × 1 × 1 = 1.0 (unimpeded!). Through non-linear path only: 0.5⁶ = 0.016 (vanished!). The residual connection preserves gradient magnitude regardless of depth.
