🔄 Step 6: Multi-Head Attention

Step 6a

Why Multiple Heads?

A single attention head can only learn one notion of relevance. With multiple heads, the model learns diverse attention patterns in parallel.

Step 6b

Concatenate + Project

Each head produces output of size dk. With h heads, we concatenate them to get back to n_embd dimensions. Then a final projection matrix WO mixes information across heads.

// 2 heads, each d_k = 2, total = 4 = n_embd Concat = ⎡10.0   20.0   |   head₂_outs⎤ // "the" ⎢25.2   35.2   |   head₂_outc⎥ // "cat" ⎣32.6   42.6   |   head₂_outs⎦ // "sat" Shape: (3 × 4) — back to original embedding size! Output = Concat · WO WO: (4 × 4) — mixes information across heads
💡 WO is critical: It's not just a shape-converter. WO learns which heads to trust for which features. If Head 2 (proximity) is noisy for this token, WO can down-weight it. The projection fuses multi-perspective attention into a single coherent representation.

What Comes Next?

The attention output goes through:

  1. Residual connection — Add the original X back: Output = X + Attention(X). This preserves information and helps gradients flow.
  2. LayerNorm — Stabilize activations.
  3. Feed-Forward Network (FFN) — Each token independently processes its attended representation through MLP layers.
  4. Another residual + norm — Then on to the next layer.

A typical GPT has 12–96 such layers stacked. Each layer refines the representations further, with progressively more abstract attention patterns.

🔑 Key takeaway: The attention output (A·V) is a context-dependent blend of all previous tokens, weighted by learned relevance. Multiple heads capture different relationship types. The final projection fuses them back into a single rich representation — ready for the next layer or the final prediction.
