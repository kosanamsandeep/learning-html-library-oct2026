07 · From Attention to Next-Token Prediction

The full forward pass — how QKV attention in every layer ultimately produces a probability distribution over the vocabulary.

🏗️ The Full Architecture

1
Tokenization — Split text into tokens (subwords). "the cat sat" → ["the", "cat", "sat"]
2
Embedding — Map each token to a high-dimensional vector. Shape: (T × n_embd)
3
Positional Encoding — Add position information so the model knows token order.
4
For each of N layers (e.g. 12 for GPT-2, 96 for GPT-4):
a
QKV Self-Attention — Each token gathers context from all previous tokens (as detailed in files 01–05)
b
Residual connection — Add input back: output = x + Attention(x) — preserves gradient flow
c
Layer Normalization — Stabilize activations, reduce covariate shift
d
Feed-Forward Network (FFN) — MLP: expand → ReLU/GELU → project back. Each token processes independently
e
Residual + LayerNorm — Another residual and normalization before next layer
5
Unembedding (LM Head) — Project final hidden state → vocabulary logits. Shape: (T × vocab_size)
6
Softmax — Convert logits to probabilities over the vocabulary
7
Sample / Argmax — Pick the next token: highest probability (greedy) or sample from distribution (creative)

🔮 Concrete Example: "the cat sat"

Predicting the word after "the cat"

At position 2 (index 2, processing "sat" — wait, let's be precise):

We have 3 input tokens: ["the", "cat", "sat"]. The model needs to predict token 4 (which could be "on", ".", "down", etc. depending on the training distribution).

But during training, we know the actual fourth token. For this example, let's say the full sentence is: "the cat sat on the mat" and the model is trying to predict "on" after "sat".

Input: the   cat   sat → ?

After passing through all N layers (each applying QKV attention + FFN), the final hidden state at position 2 (the last token) is projected through the unembedding matrix:

🧠 How QKV Makes This Possible

Without QKV attention, the hidden state at position "sat" would only know about itself. With attention, it carries information from "the" and "cat" — gathered layer by layer, head by head.

LayerWhat Attention ContributesHow It Helps Prediction
Layer 1 Adjacent token patterns "sat" knows "cat" is right before it — syntactic chunking
Layer 2 Determiner-noun relationship "cat" knows "the" is its determiner — noun phrase formed
Layer 3 Subject-verb relationship "sat" attends to "cat" as its subject — predicts verb form
Layer 4+ Semantic role labeling "sat" expects a location preposition ("on") — predicts "on"
⭐ The core insight: Every layer's attention uses QKV. Every layer's QKV weights were shaped by the loss gradient. The entire system — from tokenization to the final softmax — is jointly optimized so that QKV projections in every layer cooperate to make the final prediction as accurate as possible. This is why scaling (more layers, more heads, more dimensions) works: more QKV heads can capture more relationship types.

🔄 Autoregressive Generation

At inference time, the model generates text one token at a time:

  1. Feed the prompt: "the cat sat"
  2. Predict next token: "on" (85%)
  3. Append to input: "the cat sat on"
  4. Predict next: "the"
  5. Append: "the cat sat on the"
  6. Predict next: "mat"
  7. Append: "the cat sat on the mat"
  8. Predict next: "." or "" (end token)

At each step, every token attends to all previous tokens via QKV. The key insight: position 0 ("the") never changes its representation across steps (because it only attends to itself), but later tokens get richer context each time.

⚡ Why QKV is revolutionary: Before Transformers, RNNs processed tokens sequentially — each token had to be "squeezed through" the hidden state one step at a time, creating a bottleneck. With QKV attention, every token can directly access any earlier token's representation in constant time (matrix multiply). This parallel access is what made training on massive datasets feasible.
