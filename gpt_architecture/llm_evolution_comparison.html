GPT Evolution: GPT-3 → GPT-5.6

timeline title GPT Evolution (2020–2026) section GPT-3 (2020) : 175B params, first API Few-shot in-context learning discovered section GPT-3.5 / ChatGPT (2022) : RLHF, conversational ChatGPT launch → 100M users in 2 months section GPT-4 (2023) : Multimodal (text+vision) 90th percentile bar exam, 32K context section GPT-4 Turbo (2023) : 128K context, cheaper JSON mode, Assistants API section GPT-4o (2024) : Native omni (text+vision+audio) Real-time voice, 232ms response section o1 / o3 (2024–2025) : Reasoning models Chain-of-thought, scaled test-time compute section GPT-5 (2025) : Unified model with router Merged GPT + o-series, 400K context section GPT-5.4 (Mar 2026) : 1M context Native computer use, compaction section GPT-5.5 (Apr 2026) : From-scratch retrain ~4T params, agentic coding default section GPT-5.6 Sol/Terra/Luna (Jul 2026) Multi-agent orchestration, effort tiers
🧠 The Big Arc

GPT's journey is one of unification. GPT-3 was a pure text predictor. GPT-4 added vision. GPT-4o fused audio. o1 added reasoning chains. GPT-5 merged all lines into one router that decides per-query whether to think fast (Instant) or deliberate (Thinking/Pro). GPT-5.6 capped this with Sol/Terra/Luna — three capability tiers decoupled from the version number, plus multi-agent orchestration (Ultra Mode) that spawns sub-agents for complex tasks.

The difference is scale (10M → 175B → 4T parameters), training data (Shakespeare → the internet), and post-training (RLHF, reasoning fine-tuning). Every innovation from GPT-3 onward was built on that same core.

Claude Evolution: Claude 1 → Fable 5

timeline title Claude Evolution (2023–2026) section Claude 1 (2023) : Constitutional AI Helpful, Honest, Harmless framework section Claude 2 (2023) : 100K context Improved coding, safer outputs section Claude 3 Sonnet/Opus (2024) : Tiered models Opus for intelligence, Sonnet for speed, Haiku for cost section Claude 3.7 Sonnet (Feb 2025) : Hybrid reasoning Extended thinking — pause and think step-by-step section Claude 4 Opus/Sonnet (May 2025) : Generational leap 72.5% SWE-bench, Claude Code GA section Opus 4.5 (Nov 2025) : First to break 80% SWE-bench Infinite Chats, auto-summarization section Opus 4.8 (May 2026) : Effort controls Fast Mode, 2.5× speed, 3× cheaper section Fable 5 + Sonnet 5 (Jun 2026) : Mythos-class 80.3% SWE-Bench Pro, safety-routed
🧠 The Big Arc

Claude's journey is about safety-first excellence. Starting from Constitutional AI, Claude evolved through increasingly capable tiers (Haiku → Sonnet → Opus → Mythos). The breakthrough came with hybrid reasoning (Claude 3.7 Sonnet) — the ability to think step-by-step before answering. Claude Code (May 2025) turned Claude into an autonomous coding agent. Fable 5 represents the first "Mythos-class" model: more capable than any Opus, but with safety classifiers that route sensitive requests to Opus 4.8 rather than refusing outright. Sonnet 5 now rivals Opus 4.8 on knowledge work at 40% the list price.

DeepSeek Evolution: V1 → V4

timeline title DeepSeek Evolution (2024–2026) section V1 / LLM (Jan 2024) : 67B dense, 2T tokens Baseline: GQA, beat LLaMA-2 70B section V2 (May 2024) : MLA + MoE revolution KV cache -93.3%, training cost -42.5% DeepSeekMoE: fine-grained + shared experts section V3 (Dec 2024) : 671B MoE, $5.5M training FP8 training, Multi-Token Prediction Matched GPT-4o at 1/20th the cost section R1 (Jan 2025) : Pure RL reasoning "Aha moment" — spontaneous self-reflection GRPO: no value network needed section V3.1 (Aug 2025) : Hybrid reasoning Think/no-think modes in one model section V3.2 (Dec 2025) : Sparse Attention (DSA) O(L·k) long context, IMO/IOI gold section V4 (Apr 2026) : mHC + hybrid attention 1.6T params, 1M context, Muon optimizer
🧠 The Big Arc

DeepSeek's journey is about efficiency through architecture innovation. While others scaled by throwing more compute at dense transformers, DeepSeek rewrote the rules: Multi-Head Latent Attention (MLA) compressed KV cache by 93%. DeepSeekMoE made sparse activation practical at massive scale. FP8 training cut costs 10×. GRPO enabled reasoning without a critic network. The result: V3 trained for $5.5M matched GPT-4o. V4's manifold Hyper-Connections (mHC) solved the deep-network signal problem. DeepSeek is the cost-efficiency champion — proving you don't need billions in compute to compete at the frontier.

(2) Compressed Sparse Attention + Heavily Compressed Attention — KV cache at 10% of V3.2. 💡 The DeepSeek secret: Every major DeepSeek innovation was published as a paper first and validated in small-scale experiments before being deployed in the flagship model. MLA, GRPO, FP8 training, DSA, mHC — all followed this pattern. It's a research-lab approach to product development, and it lets them move faster than companies that keep everything behind closed doors.

Kimi Evolution: K1 → K2.7

🧠 The Big Arc

Kimi's journey is about rebuilding the stack from scratch. Founder Yang Zhilin made a bold bet: halt the K1 series entirely to redesign core AI components — optimizers, attention mechanisms, residual connections — rather than using off-the-shelf AdamW + Transformer. K2 introduced MuonClip (a better optimizer), Kimi Linear Attention (5-6× faster long-context decoding), and Attention Residuals (20% less training compute). K2.5 discovered that visual RL improves text ability — a counterintuitive breakthrough. K2.7 Code, open-sourced under a Modified MIT license, cuts thinking tokens by 30% and targets long-horizon coding agents. Kimi is the dark horse — smaller budget, younger team, but willing to question every assumption.

This is expensive in the short term but creates a differentiation moat — they aren't limited by someone else's design decisions. K3 (next gen) promises "abilities other models have not defined" with an entirely new architecture.

🧠 The Strategy Trade-Off

🟠 Dense (Claude / GPT)

Focus: deep reasoning coherence, logic consistency, enterprise agent stability. Trade-off: Higher compute per token, but avoids "router jitter" and VRAM allocation overheads of MoE. Every token gets the full model.

🟣 MoE (DeepSeek / Kimi)

Focus: maximum compute efficiency, lower API costs, high throughput. Trade-off: High total VRAM footprint (must keep all experts in GPU memory), but delivers frontier performance at a fraction of the training budget (V3: $5.5M).

⚡ Bottom-line insight: You are not paying for "intelligence" — you are paying for the architecture choice the company made years ago. Claude's density buys coherence but costs more. DeepSeek's MoE + MLA buys efficiency but needs more total GPU memory. Neither is "right" — they are different points on the cost-coherence curve. Your use case determines which matters more.

📈 What the Timeline Reveals
  1. 2020–2023 was the GPT era — one company dominated. Everyone else was catching up.
  2. 2024 was the architecture war — DeepSeek proved MoE + MLA could match dense models at a fraction of the cost. The entire industry pivoted to sparse architectures.
  3. 2025 was reasoning's breakout — R1's "Aha Moment" and Claude's hybrid thinking showed that how you use test-time compute matters as much as scale.
  4. 2026 is the agent era — Every model family now ships with some form of autonomous capability: multi-agent (GPT-5.6), long-horizon agents (Claude, Kimi K2.6), or agentic coding (all four). The question is no longer "can the model answer?" but "can the model do?"
  5. The gap is closing — Sonnet 5 rivals Opus 4.8. DeepSeek V4 matches frontier models at 1/10th the cost. Kimi beats GPT-5.4 on SWE-Bench. No single company has a commanding lead today.

🧬 What nanoGPT taught you applies everywhere: Every model above — GPT-5.6, Fable 5, V4, K2.7 — is still a decoder-only Transformer at its core. The innovations are in how the attention is computed (MLA, Linear, DSA), how the parameters are activated (dense vs MoE), how the model reasons (extended thinking, chain-of-thought, router), and how it's trained (GRPO, Muon, RLHF). But the fundamental architecture — token embedding → masked self-attention → feed-forward → residual connections → layer norm → next-token prediction — is the same design you saw in nanoGPT's 300 lines of code. The 300 lines scaled up 10,000× and wrapped in a decade of engineering ingenuity.
