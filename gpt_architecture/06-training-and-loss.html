06 · Training & Loss Minimization

How does the model learn to set WQ, WK, WV to useful values? The answer: backpropagation through the loss function.

⛓️ Step 1: The Forward Pass

During training, the model processes a sequence and produces probabilities for the next token at each position. Then it compares its predictions to the actual next tokens (from the training data).

The Loss Function: Cross-Entropy

Loss = -Σi log Pmodel(tokeni+1 | tokens≤i) // For each position i, the model predicted a probability distribution over the vocabulary. // We take the log of the probability assigned to the ACTUAL next token. // High probability → low loss. Low probability → high loss.
✅ Good Prediction (low loss)
"the cat ? " → model predicts "sat" at 85%
Actual: "sat"
Loss = -log(0.85) ≈ 0.16
❌ Bad Prediction (high loss)
"the cat ? " → model predicts "the" at 10%
Actual: "sat"
Loss = -log(0.10) ≈ 2.30

📉 Step 2: The Loss Signal

What the loss tells us:
  • Low loss (near 0): The model was confident and correct. No significant update needed.
  • Medium loss (~0.5–2): The model was somewhat uncertain or wrong. Small updates.
  • High loss (>2): The model was confidently wrong — big gradient signal. "I was very sure it was 'the', but it was 'sat'! — I need to change my weights significantly."
Training StageTypical LossWhat's Happening
Random init~2.3Predicting uniform random — no knowledge yet
Early training~1.5–2.0Learning word frequencies and common patterns
Mid training~0.5–1.5Syntactic patterns solidifying, attention heads specializing
Late training~0.1–0.5Fine-grained semantics, rare patterns, long-range dependencies
Overfit (memorized)~0.0Memorized training data — may not generalize

⚡ Step 3: Backpropagation — Gradients Flow Back Through QKV

The loss gradient flows backward through every operation in the forward pass, computing how much each weight contributed to the error.

// Chain rule applied to attention: ∂Loss / ∂WQ  =  ∂Loss / ∂Attn · ∂Attn / ∂Q · ∂Q / ∂WQ ∂Loss / ∂WK  =  ∂Loss / ∂Attn · ∂Attn / ∂K · ∂K / ∂WK ∂Loss / ∂WV  =  ∂Loss / ∂Attn · ∂Attn / ∂V · ∂V / ∂WV

What each gradient says:

WeightGradient Means:
WQ"Make the query of 'sat' look more like the key of 'cat', so attention goes up and the prediction improves"
WK"Make the key of 'cat' more distinctive (or more similar to the queries that need it)"
WV"Carry more useful information about 'cat' so that when attention blends it into other tokens, the prediction is better"

🔄 Step 4: Weight Update

Using an optimizer (AdamW, SGD), the weights are updated in the opposite direction of the gradient:

WQnew = WQold - η · ∇WQ // η = learning rate WKnew = WKold - η · ∇WK
WVnew = WVold - η · ∇WV

Over billions of tokens and thousands of gradient steps, the QKV projections gradually specialize:

IterationQ·K Score for (cat→sat)Attention to 'cat' from 'sat'Prediction for 'the cat ___'
Step 0Random (~0.0)~33% (uniform)"the" (random guess)
Step 100~0.3~38%"was" (common verb)
Step 1000~0.7~45%"sat" (40% confidence)
Step 10000~1.2~51%"sat" (85% confidence)
🎯 The critical insight: The model doesn't "know" about subjects and verbs. It simply discovers that when "sat" attends more to "cat", the loss decreases. The gradients automatically shape Q, K, V to produce this behavior. This is why attention is called learned content-based retrieval — the content (what to attend to) and the retrieval mechanism (QKV projections) are jointly optimized for one goal: predict the next token.
