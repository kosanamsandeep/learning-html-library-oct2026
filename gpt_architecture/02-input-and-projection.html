02 · Input Embeddings → Q, K, V Projection

How do we go from raw token embeddings to the three separate matrices that power attention? This file walks through the first mathematical transformation.

📐 Step 0: The Input Matrix X

Each token (word or subword) starts as a dense embedding vector of size n_embd. For our running example, we use n_embd = 4 (in real models it's 768–16000).

With T = 3 tokens ("the", "cat", "sat"), the input is a (3 × 4) matrix:

🔮 Step 1: Linear Projection → Q, K, V

Each of the three roles (Query, Key, Value) is computed by multiplying X by a learned weight matrix. These weight matrices — WQ, WK, WV — are the parameters the model learns during training.

The projection reduces dimensionality from n_embd (4) down to d_k (2) — the "head dimension". This creates an information bottleneck that forces each head to focus on specific features.

Step 1a

Matrix Multiplication

Q = X · WQ     X: (3×4), WQ: (4×2) → Q: (3×2)
K = X · WK     X: (3×4), WK: (4×2) → K: (3×2)
V = X · WV     X: (3×4), WV: (4×2) → V: (3×2)

Each row of Q, K, V corresponds to one token. Each column is a learned feature in the attention subspace.

Two things to notice:

  • The same X is projected through three different lenses — the three W matrices learn different patterns.
  • V contains larger values (10–60) compared to Q/K (0.1–1.2). This is realistic: Values carry the full semantic payload, while Q and K are optimized for matching.
  • All three matrices have the same shape (T × dk) — this is essential for the attention formula.

⚙️ Why Project to a Smaller Dimension?

ReasonExplanation
Information bottleneckForces each head to extract only the most important features from the full embedding. Prevents overfitting.
Computational efficiencyQ·KT is a (T×dk)·(dk×T) multiply. Smaller dk → much faster attention.
Multi-head factorizationIf n_embd = 768 and heads = 12, each head uses dk = 64. Each head learns a different projection, capturing different relationship types.
🔑 Key takeaway: Q, K, V are learned linear projections of the same input. The magic is that training shapes these projections so that Q·KT produces high scores for tokens that should attend to each other, and low scores for irrelevant pairs. V carries what gets blended — trained to contain useful information for downstream layers.
