Topics

01 · MULTIMODAL MODELSSpeech-to-Text (Whisper, Deepgram), Text-to-Speech (OpenAI TTS, ElevenLabs, Coqui), image models (CLIP, Stable Diffusion, SDXL, Flux), and true multimodal LLMs (GPT-4o, Gemini, Claude 3.5). Use cases that actually ship. 02 · SMALL LANGUAGE MODELS (SLM)Phi-3, Gemma 2, Qwen 2.5, Llama 3.2-1B/3B, SmolLM2. Why an SLM beats GPT-4 on cost, latency, and privacy for well-scoped tasks — and where it falls over. 03 · AGENTIC RAGWhy naive RAG breaks, what an agent loop adds (query rewriting, source routing, self-critique, multi-hop), and the production patterns from LlamaIndex, LangGraph, and Anthropic. 04 · WEBSOCKETS & WEBRTCThe two realtime transports every voice or collaborative product picks between. Latency budgets, NAT traversal, when each is the right answer. 05 · FINE-TUNING (FULL vs LORA)Full fine-tuning, LoRA, QLoRA, adapters, DPO. A working Hugging Face PEFT example you can copy. When fine-tuning is the right answer and when it absolutely isn't. 06 · VOICE BOTSEnd-to-end architecture for a sub-800 ms voice agent: streaming STT, interruption handling, LLM streaming, sentence-level TTS chunking, jitter buffers. 07 · PERFORMANCE OPTIMISATIONQuantisation (INT8, INT4, GPTQ, AWQ), continuous batching (vLLM, TGI), KV-cache reuse, paged attention, speculative decoding, prompt caching, CPU vs GPU trade-offs. 08 · EVALUATING LLM RESPONSESReference-based metrics (BLEU, ROUGE, BERTScore), reference-free judges (G-Eval, RAGAS, DeepEval), HumanEval / MMLU / MT-Bench benchmarks, and how to run a human-eval pass without going broke. 09 · LITSERVELightning AI's batteries-included model server. What it gives you over FastAPI (dynamic batching, GPU streaming, multi-model routing), and when plain FastAPI is still the right call.

How to read these pages

  • Each page opens with a plain-English definition and one mermaid diagram.
  • Then a side-by-side table of trade-offs (pros, cons, when to use).
  • Then a code or config example you can lift into your own repo.
  • Every claim is footnoted to an official source (vendor docs, foundational paper, or W3C spec).
Pro tip: these pages were written to pair with industry_standards (Anthropic / OpenAI / GitHub best-practice guides) and claude_workshops (CWC field notes). Use them together.
