Multimodal models — speech, vision, and true any-to-any LLMs

Multimodal means the model can read, write, see, hear or speak. In production this usually means one of three things: (1) STT — audio in, text out; (2) TTS — text in, audio out; (3) image / vision models — image in and/or image out; or, increasingly, (4) a single any-to-any LLM (GPT-4o, Gemini, Claude) that natively accepts and produces multiple modalities.

2 · Speech-to-Text (STT)

STT converts a waveform into a transcript. Modern STT models are encoder networks (often Conformer or Whisper-style Transformer encoders) trained on hundreds of thousands of hours of audio. They emit tokens (text + punctuation + sometimes diarisation / speaker tags).

OpenAI Whisper

Open-weight, multilingual, runs locally (whisper.cpp) or via API. large-v3 is the current strongest checkpoint.

Deepgram Nova-3

Hosted, <300 ms streaming, strong on noisy / call-centre audio. Used by Vapi, Retell, etc.

AssemblyAI Universal-2

Streaming + batch; strong PII redaction and speaker labels.

Azure / Google STT

Enterprise-grade streaming with phrase hints and custom vocabularies.

Streaming vs batch — pick on latency

Mode Latency Use for
Streaming (chunked WebSocket) 100–300 ms partials Voice agents, live captions
Batch (whole file) ~real-time × 0.1 of audio Meeting summaries, podcasts, archives

3 · Text-to-Speech (TTS)

TTS turns text into audio. Modern systems are neural (Tacotron 2, FastSpeech 2, VITS, and now diffusion / LM-based engines like ElevenLabs v3 and OpenAI tts-1-hd). The two dimensions that matter in production are quality / naturalness and first-byte latency.

ElevenLabs

Industry-leading naturalness, voice cloning, ~400 ms streaming. Pay-per-character.

OpenAI TTS (gpt-4o-mini-tts)

Streaming, 6 baked voices, "voice instructions" (whisper, calm, excited). Cheap.

Cartesia Sonic

~75 ms first-byte. Built for voice agents that interrupt.

Coqui XTTS / Piper

Open-weight, runs on a single GPU or even CPU. Use when you can't ship audio off-prem.

Streaming TTS trick: stream the LLM tokens into the TTS engine sentence-by-sentence, not whole-paragraph. The user hears the first sentence while the LLM is still generating the second.

5 · Any-to-any multimodal LLMs

The 2024–2026 shift: a single model with one tokeniser that handles text, images, audio (and increasingly video) natively in one forward pass — no glue between separate STT + LLM + TTS.

  • GPT-4o / GPT-4o-realtime — text + image + audio in and out, single model.
  • Gemini 2.0 / 2.5 — long-context multimodal (1M+ tokens of mixed video, image, text).
  • Claude 3.5 / 4 — text + image in, text out (excellent at documents and charts).
  • Llama 3.2 Vision, Qwen2-VL, Pixtral — open-weight VLMs you can self-host.

Why this matters

A pipelined system (STT → LLM → TTS) adds ~400–800 ms of latency and loses paralinguistic information (tone, hesitation, laughter). A native any-to-any model preserves all of it and runs in one round trip.

6 · Real-world use cases

Voice agents

STT + LLM + TTS (or GPT-4o-realtime) for support, scheduling, sales triage.

Document AI

VLM reads PDFs, invoices, statements — replaces OCR + layout + rules pipelines.

Accessibility

Real-time captions, alt-text, audio descriptions, sign-language transcription.

Creative / marketing

Brand-consistent image & short-video generation with ControlNet / LoRA.

Computer-use agents

VLM looks at a screenshot, decides the next click — Claude's "computer use" or Anthropic agent SDK.

Medical / industrial vision

Radiology triage, defect detection, satellite classification.

7 · A 20-line working example (OpenAI multimodal)

# pip install openai
from openai import OpenAI
import base64, pathlib

client = OpenAI()

# 1. STT — transcribe an audio file
with open("call.wav", "rb") as f:
    transcript = client.audio.transcriptions.create(
        model="whisper-1", file=f
    ).text

# 2. Vision — let the LLM read an image alongside text
img_b64 = base64.b64encode(pathlib.Path("invoice.png").read_bytes()).decode()
answer = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": [
        {"type": "text", "text": f"Transcript:\n{transcript}\nExtract invoice total."},
        {"type": "image_url",
         "image_url": {"url": f"data:image/png;base64,{img_b64}"}},
    ]}],
).choices[0].message.content

# 3. TTS — speak the answer back
speech = client.audio.speech.create(
    model="gpt-4o-mini-tts", voice="alloy", input=answer
)
speech.stream_to_file("reply.mp3")
