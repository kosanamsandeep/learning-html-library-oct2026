Memory types in agentic workflows

What kinds of memory does an agent need, and which library primitive maps to each?

📖 Story mode — Maya, the new barista at Café Cortex

The scene. It's Maya's first day at Café Cortex. The shop has been running for years and the owner says: “Don't worry, the café itself remembers everything — you just have to know where to look.” Maya quickly discovers the café has five different memories, and each one lives in a different place.
  1. Short-term memory = the cup in Maya's hand.
    A customer says “large latte, oat milk, extra hot.” Maya repeats it under her breath while she walks to the espresso machine. The moment the cup is handed over, the words evaporate. → This is the agent's scratchpad / ReAct trace for the current turn.
  2. Episodic memory = yesterday's receipts in the till drawer.
    At closing time Maya flips through receipts: “Ah, that grumpy man at 9 a.m. wanted a flat white, not a cappuccino.” She can replay specific past events. → This is ConversationBufferMemory / LangGraph MemorySaver: full transcripts of past turns, keyed by thread.
  3. Semantic memory = the recipe binder behind the counter.
    The binder has 500 laminated pages: how to pull a ristretto, milk-fat ratios, allergen tables, the WiFi password. Maya doesn't remember writing any of it — she just looks it up. → This is your vector database. Your 500 PDF chunks live here.
  4. Procedural memory = Maya's hands after week three.
    By day 20, she steams milk without thinking. Her fingers know the rhythm. There's no “lookup” — the skill is baked in. → This is the system prompt + tool definitions: the agent's how to behave wiring.
  5. Entity memory = the “Regulars” chalkboard near the till.
    “Tom — oat milk, no sugar. Priya — decaf after 4 pm. Raj — always pays cash.” One row per person, updated as facts change. → This is EntityMemory / a per-user profile table: structured facts about who you're talking to.
One-line recall trick: “The cup, the receipts, the binder, the hands, the chalkboard.” If you can picture Maya touching each of those five things, you've memorised all five memory types.

Common pitfalls

PitfallFix
Stuffing the whole chat history into the promptUse ConversationSummaryBufferMemory or summarise older turns
Mixing semantic memory with episodic (one big vector store)Separate namespaces; episodic is per-user, semantic is global
Forgetting to TTL entity facts ("Bob hates pizza" — said once 6 months ago)Score memories with recency + frequency + relevance (Mem0/Zep do this)
Storing PII in vector DBsHash or tokenise identifiers; keep raw PII in a controlled SQL store
