Intermediate 02 · Research Assistant (ReAct)

Search → Read → Summarise → Save. End-to-end autonomous research, served via async FastAPI.

📖 Story mode — the junior journalist on deadline

The scene. Your editor drops a sticky note on your desk: “Electric vehicles in India — 800-word piece, by 5 pm.” You’re a junior journalist with four habits: (1) make a list of leads, (2) run to the library for each, (3) take notes, (4) draft the article and file it. That’s exactly what the agent does.

What happens when you press “Research”

  1. You type: POST /research { "topic": "electric vehicles in India" }.
  2. Plan: the agent’s prompt tells the LLM to first emit a 3–5 step plan — e.g. “policy, top sellers, charging gaps, future outlook.”
  3. Search (per step): search_skill calls DuckDuckGo via asyncio.to_thread → gets a handful of URLs.
  4. Read (per URL): reader_skill uses httpx.AsyncClient (native async — many URLs in parallel) to fetch and strip HTML.
  5. Summarise: summarise_skill sends the cleaned text back to the LLM → a 2-sentence note per source.
  6. Write: the agent stitches all notes into a structured Markdown report with citations.
  7. Save: save_skill uses aiofiles to write data/output/<topic>.md → returns the file path in the response.

One-line recall trick: “Plan → search → read → summarise → write → save.” Six verbs, four skills, one Markdown file at the end.
