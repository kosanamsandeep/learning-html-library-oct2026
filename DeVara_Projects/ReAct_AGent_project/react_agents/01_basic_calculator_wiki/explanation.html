Basic 01 · Calculator + Wikipedia (ReAct)

The classic two-tool ReAct loop, packaged as a production-shaped Python project served via async FastAPI.

📖 Story mode — the Helper Friend with two pockets

The scene. You walk up to a friend who has exactly two things in his pockets: a little calculator in the left pocket and a tiny Wikipedia book in the right pocket. You ask him anything. He thinks out loud, decides which pocket to reach into, and gives you the answer. That “think out loud, pick a pocket, repeat” is the entire ReAct idea.

What happens when you press “Ask”

  1. You type: “Who wrote Hamlet, and what is 17 * 23?” in a browser → POST /ask.
  2. FastAPI wakes up the already-warmed ReactCalcWikiAgent (warmed at startup so the first user doesn’t wait).
  3. The LLM thinks: “This has two parts. Part 1 is a fact → wiki pocket. Part 2 is math → calculator pocket.”
  4. Action 1: calls wiki_summary("Hamlet") → asyncio.to_thread runs the blocking wikipedia lib without freezing the server.
  5. Observation: “Hamlet is a tragedy written by William Shakespeare…”
  6. Action 2: calls calculate("17 * 23") → numexpr runs safely (no eval) → 391.
  7. Final answer: “Shakespeare wrote Hamlet, and 17 × 23 = 391.” → JSON sent back to your browser.

One-line recall trick: “Two pockets, thinks out loud, picks one, answers.” That’s ReAct. The whole 01 project is just this loop wrapped in FastAPI.

Why this structure?

FolderResponsibilityWhy isolated
agents/The agent classes themselvesEasy to add a second agent without touching transport.
agents/skills/Reusable async tool functionsA skill can be reused across agents and projects.
core/Cross-cutting (config, logging)Single source of truth for env/model/limits.
models/LLM provider wrappersSwap OpenAI → Azure / Ollama in one file.
workflows/Orchestration glueFastAPI calls workflows, never agents directly — clean boundary.
data/prompts/Prompt templatesPrompts evolve faster than code — keep them as text.
tests/Unit testsCI-friendly; skills are mocked, network tests skipped by default.

Run it

cd react_agents/01_basic_calculator_wiki
pip install -r requirements.txt
copy .env.example .env       # set OPENAI_API_KEY
python main.py
# server up at http://127.0.0.1:8001
# try:  curl -X POST http://127.0.0.1:8001/ask -H "Content-Type: application/json" -d "{\"question\":\"23*45+1\"}"

Why async FastAPI here?

BenefitHow this project uses it
Non-blocking I/OLLM call & wiki HTTP run on the loop; CPU-bound numexpr offloaded with asyncio.to_thread.
ConcurrencyOne process serves many simultaneous /ask requests.
Lifespan hooklifespan warms the agent so the first request is fast.
ValidationPydantic AskRequest rejects empty / oversized prompts at the boundary.
Take-away: the same ReAct logic is now a real service — testable, configurable, and ready for Docker / k8s.
