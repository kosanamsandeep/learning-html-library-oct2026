Agentic Workflows — ReAct & LangGraph Portfolio

Six end-to-end projects (3 ReAct + 3 LangGraph mirrors), each scaffolded with the canonical Python agent folder layout and served via async FastAPI. Plus 4 concept deep-dives with mermaid diagrams.

Canonical project layout (every project uses this)

project_root/
├── agents/
│   ├── base_agent.py          # async ABC
│   ├── <agent>.py             # concrete agent
│   └── skills/                # reusable async skills
├── core/                       # config, logger, bootstrap
├── data/
│   ├── prompts/                # text templates
│   └── <artifacts>/            # csv, db, charts, reports
├── models/                     # LLM client wrapper
├── workflows/                  # orchestration glue (singleton agent + API entry)
├── tests/                      # pytest
├── main.py                     # async FastAPI (uvicorn)
├── requirements.txt
├── .env.example
└── explanation.html            # this design, visualised

One-shot install (any project)

cd <project_folder>
pip install -r requirements.txt
copy .env.example .env      # put your OPENAI_API_KEY
python main.py              # uvicorn binds to its port
# test:
curl -X POST http://127.0.0.1:<port>/ask -H "Content-Type: application/json" -d "{\"question\":\"hi\"}"

ReAct vs LangGraph (cheat sheet)

AspectReAct (LangChain AgentExecutor)LangGraph
Mental modelLoop: Thought → Action → ObservationState machine / DAG of nodes
Control flowImplicit, driven by LLM textExplicit, you draw the graph
Multi-agentManual orchestrationNative: supervisor / swarm patterns
Resumable conversationsAdd ConversationBufferMemoryBuilt-in: MemorySaver, SqliteSaver, PostgresSaver
Best forQuick prototypes, single-agent toolsProduction, long-running, multi-agent
