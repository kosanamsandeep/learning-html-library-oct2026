Chapter 03 — Parallelization

Run independent sub-tasks at the same time. Latency drops from sum-of-steps to max-of-steps.

Fork-JoinasyncioFuture

What is it?

Identify steps that don't depend on each other. Fire them concurrently. Join their results. Especially powerful when sub-tasks are I/O-bound (LLM calls, web search, database lookups).

Mental model: a kitchen brigade — sauces, vegetables, and meat cook in parallel; the chef plates everything at the end.

2026 real-time scenario — Travel meta-search

A user asks an in-app travel agent on a Friday in 2026: "Cheapest Bengaluru → Tokyo flight + 4★ hotel near Shinjuku for next week." A sequential agent (call flights → call hotels → call weather → call visa rules) takes 6 seconds. The parallel agent fans-out four async calls, joins in 1.4 seconds, and the synthesizer drafts the itinerary.

Interview Q&A

Threads vs asyncio for LLM calls?
LLM calls are I/O-bound — asyncio is preferred (no thread overhead, easy cancellation). Use threads only when wrapping a sync SDK without an async client.
What if one branch fails?
Use asyncio.gather(..., return_exceptions=True) and treat missing branches as partial results, or set per-call timeouts and supply a degraded fallback.
