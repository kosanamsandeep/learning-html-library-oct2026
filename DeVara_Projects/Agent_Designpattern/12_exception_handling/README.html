Chapter 12 — Exception Handling & Recovery

Production agents fail constantly. Retry, fall back, circuit-break, log, alert.

What is it?

Three layers protect agentic systems:

  1. Retry — transient failures (timeouts, 5xx). Use exponential backoff + jitter.
  2. Fallback — alternate path or cached / smaller model.
  3. Circuit Breaker — when failure rate spikes, stop calling the broken dependency for a cool-down window.
Mental model: a power grid — fuses trip, secondary lines kick in, the system stays up.

2026 real-time scenario — Shopping copilot vs flaky vendor API

A 2026 shopping copilot calls a small e-commerce vendor API. Vendor goes down for 4 minutes. With retries + circuit breaker, the copilot tries twice with backoff, then trips the breaker, falls back to a cached catalog snapshot, and the user still gets recommendations — slightly stale, but non-broken.

Interview Q&A

Why exponential backoff + jitter?
Backoff avoids hammering a recovering service; jitter prevents synchronized retries from clients all waking at the same moment (the "thundering herd").
When is retrying wrong?
Non-idempotent operations (e.g., charging a card). Either make it idempotent with an idempotency key or only retry on safe errors.
