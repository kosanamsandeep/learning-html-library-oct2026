Chapter 11 — Goal Setting & Monitoring

Crystal-clear objectives + measurable success criteria + continuous progress tracking.

StateObserverSMART

What is it?

An agent without a measurable goal is a wanderer. The pattern wraps any task with: (1) a SMART goal, (2) acceptance criteria, (3) milestones, (4) a monitor that checks progress against criteria each step.

Mental model: a fitness tracker — you set a target, log activity, and the device tells you "60% to go."

2026 real-time scenario — Personal fitness coach

A user sets: "Run 100 km in June 2026." The agent breaks it into weekly milestones (~25 km/week), logs each run from the watch, and on June 18 says "you're at 52 km / 100 km — pace = on-track" or escalates with a reminder if behind. The state machine drives reminders.

Interview Q&A

What makes a SMART goal for an agent?
Specific, Measurable, Achievable, Relevant, Time-bound. The "Measurable" part is essential — encode it as a number the agent can read each step.
How does monitoring relate to evaluation (Ch. 19)?
Monitoring = live, per-task progress. Evaluation = aggregate, cross-task quality. They share metrics but operate at different cadences.
