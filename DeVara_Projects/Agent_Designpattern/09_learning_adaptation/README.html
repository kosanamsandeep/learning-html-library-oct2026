What is it?

"Static" agents do exactly what their prompt says forever. Adaptive agents update some part of their behavior — prompts, retrieved examples, weights, or a policy — based on feedback signals.

Mental model: A new hire who keeps a notebook of "what worked" and looks at it before each new case.

2026 real-time scenario — Adaptive movie recommender

A 2026 streaming app shows the user 5 picks each evening. The user thumbs-up "Tamil action" and ignores "Korean drama." A simple bandit (epsilon-greedy) updates a per-user preference vector every night so tomorrow's picks are 60% action, 20% comedy, 20% exploration. No model retraining; only weights in a key-value store.

Interview Q&A

Few-shot vs fine-tuning vs RAG?
Few-shot — fastest, prompt-only, limited capacity. RAG — facts at runtime, no weight changes. Fine-tuning — style/format/edge cases baked in, slowest to iterate. Most production systems do RAG + few-shot first; fine-tune only when the same patterns recur for thousands of users.
Why epsilon-greedy?
Simplest exploration policy: explore with prob ε, exploit best-known with prob 1-ε. Easy to ship, easy to reason about, surprisingly competitive on small action spaces.
