Learning Path — 6 Modules

01

Agent Evolution: Frameworks → Harnesses

The single most important shift in the agent-tooling world (per LangChain's own founder). The 5 workflow patterns, the 4 loop types, nested subagents, and the orchestrator-worker multi-agent architecture Anthropic actually ships.

Learn: when to use a workflow vs an agent · loop taxonomy · context-managed delegation
02

Production Runtime: Why MCP Isn't Enough

MCP connects agents to tools — it does not give you identity, policy, observability, or control. The 12-item production control layer, the "agents behave like infrastructure" framework, and the AI Factory Stack analogy.

Learn: the control-plane checklist every production agent needs · tool-level auth · audit trails · cost controls
03

Advanced RAG + Verification Loops

The THINK / KNOW / ANSWER / JUDGE / LEARN architecture — an evaluator loop over RAG that retries or returns. Plus GraphRAG, codebase-memory-mcp (AST knowledge graphs, verified via arXiv), and the context-engineering tools that slash token spend.

Learn: evaluator-optimiser loops · graph databases · AST code indexing · token-efficient context
04

Inference & Serving at Scale

16 techniques for sub-second LLM responses (FlashAttention, PagedAttention, speculative decoding…). OpenAI's real Postgres architecture behind 800M users. Model routing economics from Vercel. VRAM tiering for local models.

Learn: vLLM internals · KV-cache tricks · one-primary-N-replica Postgres · routing for cost/quality
05

Fine-Tuning & Alignment Landscape

The full technique map — LoRA, QLoRA, prefix/P-tuning, adapters, BitFit, RLHF, RLAIF, DPO, GRPO (what DeepSeek uses), multi-task & federated tuning. Plus the model-substitution cost-arbitrage table.

Learn: PEFT vs full FT · preference optimisation (DPO/GRPO) · when a cheaper open model beats the frontier
06

Verified Tools & MCP Directory

A single, honest directory of the tools worth your time — MCP servers that genuinely exist, token-saving utilities, local model guides, and the reading list for graph theory / network science. With explicit "skip" entries for engagement bait.

Learn: what to install vs skip · the 20-minute MCP upgrades · a real reading list
