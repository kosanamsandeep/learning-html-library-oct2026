Interview Patterns — pattern-match new problems in 60 seconds

Two Pointers

Trigger phrase: "sorted array" + "find pair / triplet" + "with given sum / property".

Shape: two indices l, r at opposite ends; move inward based on comparison.

def two_sum_sorted(nums, target):
    l, r = 0, len(nums) - 1
    while l < r:
        s = nums[l] + nums[r]
        if s == target: return [l, r]
        if s < target:  l += 1
        else:            r -= 1

Examples: 3Sum, Container With Most Water, Valid Palindrome.

Sliding Window

Trigger: "contiguous subarray / substring" + "longest / shortest / sum equals K".

Shape: expand the right side; shrink the left side when condition breaks; track the best answer so far.

def longest_at_most_k_distinct(s, k):
    cnt = {}; left = 0; best = 0
    for right, c in enumerate(s):
        cnt[c] = cnt.get(c, 0) + 1
        while len(cnt) > k:
            cnt[s[left]] -= 1
            if cnt[s[left]] == 0: del cnt[s[left]]
            left += 1
        best = max(best, right - left + 1)
    return best

Examples: Longest Substring Without Repeating Chars, Minimum Window Substring, Permutation in String.

Fast / Slow Pointers (Floyd's)

Trigger: linked list + "cycle / middle / k-from-end".

Slow moves 1 step; fast moves 2. They meet inside a cycle; fast reaches end when slow is at the middle.

Examples: Linked List Cycle, Middle of Linked List, Happy Number (cycle in a transformation).

Merge Intervals

Trigger: array of intervals + "merge / overlap / insert".

Shape: sort by start; sweep left-to-right; merge overlapping pairs.

def merge(intervals):
    intervals.sort()
    out = [intervals[0]]
    for s, e in intervals[1:]:
        if s <= out[-1][1]:
            out[-1][1] = max(out[-1][1], e)
        else:
            out.append([s, e])
    return out

Examples: Merge Intervals, Insert Interval, Non-overlapping Intervals, Meeting Rooms.

Cyclic Sort

Trigger: array of n numbers in the range [1, n] (or [0, n-1]).

Shape: swap each number into its "right" index. O(n) time, O(1) extra space.

def cyclic_sort(nums):       # numbers in 1..n
    i = 0
    while i < len(nums):
        j = nums[i] - 1
        if nums[i] != nums[j]:
            nums[i], nums[j] = nums[j], nums[i]
        else:
            i += 1
    return nums

Examples: Missing Number, Find All Missing Numbers, Find Duplicate Number, First Missing Positive.

In-place Reversal

Trigger: "reverse linked list / sub-list / k-group" + "O(1) extra space".

Template: three pointers prev, cur, next; flip cur.next to prev, advance all three.

BFS & DFS — the templates

BFS trigger: "shortest path in unweighted graph", "level by level".

Greedy

Trigger: "maximize / minimize" + "at each step pick the best local choice".

Hard part: proving the greedy choice is correct. Heuristics:

  • Sort by some natural criterion (deadline, ratio, start time) and sweep.
  • Show that any other choice can be improved by switching to the greedy choice ("exchange argument").

Examples: Activity Selection, Jump Game, Gas Station, Task Scheduler, Huffman Coding.

Warning: greedy fails on most subset / pairing problems where DP is the right tool. If you're not sure, try DP first.

Bit Manipulation (bonus)

Tricks worth memorizing:

  • x & (x - 1) clears the lowest set bit.
  • x & -x isolates the lowest set bit.
  • x ^ x = 0, x ^ 0 = x → XOR cancels duplicates.
  • x | (1 << i) sets bit i; x & ~(1 << i) clears it.

Examples: Single Number, Counting Bits, Sum of Two Integers without using +.

How to read a new problem in 60 seconds

  1. Read the problem twice.
  2. Underline the keywords ("subarray", "sorted", "shortest path", "K largest").
  3. Match to a pattern above. State the pattern name out loud.
  4. State the complexity target you're aiming for.
  5. Write the brute force first, then optimize.

Interviewers reward narrating this process. The optimal answer with no narration loses to a brute-force-then-improved answer that's well explained.
