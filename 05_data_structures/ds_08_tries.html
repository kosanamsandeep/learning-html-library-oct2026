Specialized structures — know them by name

Tries & Advanced — the specialized power tools

You won't reach for these every day, but when the problem matches, nothing else comes close. Know each one's shape and signature problem; learn implementations on demand.

Trie (prefix tree)

A tree where each path from the root spells out a string. Used for autocomplete, prefix search, and word dictionaries.

class TrieNode:
    def __init__(self):
        self.children = {}        # char -> TrieNode
        self.is_word = False

class Trie:
    def __init__(self): self.root = TrieNode()

    def insert(self, word):
        node = self.root
        for c in word:
            node = node.children.setdefault(c, TrieNode())
        node.is_word = True

    def search(self, word):
        node = self._walk(word)
        return node is not None and node.is_word

    def starts_with(self, prefix):
        return self._walk(prefix) is not None

    def _walk(self, s):
        node = self.root
        for c in s:
            if c not in node.children: return None
            node = node.children[c]
        return node

Complexity: insert/search/prefix-check are O(L) where L is the word length — independent of how many words are stored.

Use trie when

Autocomplete, IP routing tables, spell check, longest common prefix, word-search puzzles.

Don't

For just storing strings → use a set or hash. Tries cost more memory; the win is in prefix queries.

Union-Find (Disjoint Set Union)

Tracks a partition of N elements into disjoint sets. Two operations:

  • find(x) — which set does x belong to?
  • union(x, y) — merge the sets containing x and y.

With path compression + union by rank, both are effectively O(1) (technically α(n), the inverse Ackermann — < 5 for any practical n).

class UF:
    def __init__(self, n):
        self.p = list(range(n))
        self.r = [0] * n

    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]   # path compression
            x = self.p[x]
        return x

    def union(self, x, y):
        rx, ry = self.find(x), self.find(y)
        if rx == ry: return False
        if self.r[rx] < self.r[ry]: rx, ry = ry, rx
        self.p[ry] = rx
        if self.r[rx] == self.r[ry]: self.r[rx] += 1
        return True

Signature problems: connected components, detecting cycles in an undirected graph, Kruskal's MST, "redundant connection", "accounts merge".

Segment Tree

Binary tree where each leaf is an array element and each internal node stores an aggregate (sum, min, max, gcd) of its range. Supports:

  • Range query (e.g., "sum of arr[l..r]") in O(log n).
  • Point update in O(log n).

Signature problems: "range sum query — mutable", "range min query", "count of smaller numbers after self".

Alternatives: Fenwick tree (BIT) — same use case, less code, prefix-sum based. Most interviewers accept Fenwick if you can implement it on the spot.

# Fenwick (binary indexed) tree — 1-indexed
class BIT:
    def __init__(self, n): self.t = [0] * (n + 1)
    def update(self, i, delta):
        while i < len(self.t):
            self.t[i] += delta; i += i & -i
    def query(self, i):
        s = 0
        while i > 0:
            s += self.t[i]; i -= i & -i
        return s
    def range_sum(self, l, r):
        return self.query(r) - self.query(l - 1)

Bloom filter

Space-efficient probabilistic membership test. "Is X in the set?" Answer: "definitely not" or "probably yes" (small false positive rate).

Use: avoiding expensive lookups (Cassandra uses bloom filters to skip SSTables that definitely don't contain a key). LinkedIn uses them to check if a username is taken before hitting the DB.

LRU / LFU cache structures

LRU = hash map + doubly linked list. LFU = hash map + frequency-bucketed doubly linked lists. Covered in Hash Tables.

When NOT to learn these too early

Segment trees and Fenwick come up in < 10% of FAANG interviews. Master arrays through graphs first; circle back here for the last 10%.
