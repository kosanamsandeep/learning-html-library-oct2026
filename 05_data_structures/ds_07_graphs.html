Nodes and edges — networks, maps, dependencies

Graphs — modeling "things and the connections between them"

A graph is a set of nodes (vertices) connected by edges. Almost any system of relationships is a graph: social networks, road maps, dependency chains, knowledge graphs, the internet, state machines.

Vocabulary

  • Directed — edges have direction (Twitter follow). Undirected — symmetric (Facebook friend).
  • Weighted — edges have a cost (road distance). Unweighted — all edges equal.
  • Cyclic — has loops. Acyclic — no loops. A directed acyclic graph is a DAG (think: course prerequisites, build pipelines).
  • Connected — every node reachable from every other. Disconnected — multiple components.

Representations

Representation Space Edge check Best for
Adjacency list O(V + E) O(degree) Sparse graphs (most real ones).
Adjacency matrix O(V²) O(1) Dense graphs, or when you check edge existence very often.
Edge list O(E) O(E) Algorithms like Kruskal's MST that process all edges.

BFS — shortest path in unweighted graphs

from collections import deque

def bfs(graph, start):
    visited = {start}; q = deque([start]); order = []
    while q:
        node = q.popleft(); order.append(node)
        for nei in graph[node]:
            if nei not in visited:
                visited.add(nei); q.append(nei)
    return order

BFS visits in layers: distance 1 first, then distance 2, etc. Returns shortest hop-count from start to any node.

DFS — explore deep before wide

# recursive
def dfs(graph, node, visited):
    visited.add(node)
    for nei in graph[node]:
        if nei not in visited:
            dfs(graph, nei, visited)

# iterative with explicit stack
def dfs_iter(graph, start):
    visited = set(); stk = [start]
    while stk:
        node = stk.pop()
        if node in visited: continue
        visited.add(node)
        stk.extend(graph[node])

DFS is what you want for: cycle detection, topological sort, connected components, backtracking, finding any path (not necessarily shortest).

Topological sort — for DAGs

Linear ordering of nodes such that for every edge u → v, u comes before v. Used for: build systems, course prerequisites, task scheduling.

def topo_sort(graph):
    # Kahn's algorithm: repeatedly pick nodes with in-degree 0
    in_deg = {u: 0 for u in graph}
    for u in graph:
        for v in graph[u]:
            in_deg[v] = in_deg.get(v, 0) + 1
    q = deque([u for u, d in in_deg.items() if d == 0])
    out = []
    while q:
        u = q.popleft(); out.append(u)
        for v in graph[u]:
            in_deg[v] -= 1
            if in_deg[v] == 0: q.append(v)
    return out if len(out) == len(in_deg) else []   # [] → cycle

Shortest path

Algorithm Use when Complexity
BFS Unweighted O(V + E)
Dijkstra (min-heap) Weighted, non-negative O((V + E) log V)
Bellman-Ford Weighted, possibly negative O(V × E)
Floyd-Warshall All-pairs shortest path, dense O(V³) 
import heapq

def dijkstra(graph, start):
    dist = {start: 0}
    pq = [(0, start)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]: continue
        for v, w in graph[u]:        # graph[u] = [(neighbor, weight), ...]
            nd = d + w
            if nd < dist.get(v, float('inf')):
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist

When to use vs when NOT

Use a graph algorithm when

  • The problem involves relationships, networks, paths, dependencies.
  • You're asked for "is X reachable from Y", "shortest path", "connected components".
  • You see "can we visit all X" / "is there a cycle" / "in what order…".

Don't

  • Reach for graphs when an array + index would do.
  • Use an adjacency matrix when E ≪ V² — wastes memory.
  • Use DFS to find shortest path on unweighted graphs (use BFS instead).
