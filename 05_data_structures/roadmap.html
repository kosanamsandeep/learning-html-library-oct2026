60-Day Data Structures & Algorithms Roadmap

Two months from "I know loops" to "I solve LeetCode Medium in 25 minutes". Each week focuses on one data structure family + the algorithms it enables. Adjust pace to your starting point.

Week 1 — Foundations

Day Topic Practice
1 Big-O & complexity Classify 10 functions by complexity.
2–4 Arrays & Strings Two Sum, Move Zeros, Best Time to Buy/Sell Stock, Valid Anagram, Reverse String.
5–6 Prefix sum + difference arrays Range Sum Query, Subarray Sum Equals K.
7 Review + 2 random easy problems Time them.

Week 2 — Linked Lists, Stacks, Queues

Day Topic Practice
8–10 Linked Lists Reverse Linked List, Detect Cycle, Merge Two Sorted Lists, Remove Nth from End.
11–13 Stacks & Queues Valid Parentheses, Min Stack, Next Greater Element, Implement Queue using Stacks.
14 Review Mix problems.

Week 3 — Hash Tables & Two-Pointer / Sliding Window

Day Topic Practice
15–17 Hash Tables Group Anagrams, LRU Cache, Longest Consecutive Sequence.
18–20 Two pointers & sliding window 3Sum, Container With Most Water, Longest Substring Without Repeating Chars, Min Window Substring.
21 Review Time-box: 3 mediums in 90 min.

Week 4 — Sorting & Binary Search

Day Topic Practice
22–24 Sorting & Binary Search Merge Intervals, Sort Colors, Kth Largest, Search in Rotated Sorted Array.
25–27 Binary search on answer Koko Eating Bananas, Capacity to Ship Packages, Find Min in Rotated.
28 Review Mock test.

Week 5 — Trees & BSTs

Day Topic Practice
29–32 Trees Inorder/Preorder/Postorder, Max Depth, Same Tree, Invert Tree, Diameter.
33–34 BST Validate BST, Kth Smallest in BST, Lowest Common Ancestor.
35 BFS on trees Level Order Traversal, Right Side View.

Week 6 — Heaps + Recursion

Day Topic Practice
36–38 Heaps Kth Largest in Stream, Top K Frequent, Median of Stream, K Closest Points.
39–41 Recursion & Backtracking Subsets, Permutations, Combinations Sum, N-Queens.
42 Review Mock test.

Week 7 — Graphs

Day Topic Practice
43–45 Graph BFS/DFS Number of Islands, Clone Graph, Course Schedule.
46–47 Topological sort Course Schedule II, Alien Dictionary.
48–49 Shortest paths (Dijkstra) Network Delay Time, Cheapest Flights Within K Stops.

Week 8 — Dynamic Programming

Day Topic Practice
50–52 DP — 1D Climbing Stairs, House Robber, Coin Change, Longest Increasing Subsequence.
53–55 DP — 2D Longest Common Subsequence, Edit Distance, Unique Paths.
56–57 DP on grids / knapsack 0/1 Knapsack, Partition Equal Subset Sum.

Week 9 — Advanced & Mocks

Day Topic Practice
58 Tries Implement Trie, Word Search II.
59 Union-Find Number of Connected Components, Redundant Connection.
60 Full mock interview 1 easy + 1 medium + 1 hard in 90 minutes.

Daily protocol

  1. Read the concept page slowly.
  2. Implement the data structure once from scratch.
  3. Solve 2–4 problems. Time-box each.
  4. If stuck for > 30 minutes: read the discussion, code along, then redo from scratch the next day.
  5. Keep a personal mistakes log — patterns you keep missing.
