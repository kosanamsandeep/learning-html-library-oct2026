The agent harness — the machinery between your prompt and the real world

If you've ever wondered what people mean by "the harness" — you've been using one every time you run Claude Code. A harness is the software scaffold wrapped around a language model: the agentic loop, tools, context management, permissions, and guardrails that turn raw intelligence into an agent that can read, write, run, and decide. This track unpacks that scaffold from first principles to a working build.

Why this matters right now. The models are commodity — Opus, Sonnet, GPT, Gemini all reason brilliantly. What separates products is increasingly how they're harnessed: what tools the model gets, what loop it runs, how much the operator is trusted. When you hear "X is just a thin wrapper over a model", the speaker is missing that the harness is the product. This track gives you the vocabulary and the mental model to see it clearly.

A note on sources

"Harness" is an informal term that has crystallised over 2024–2026. Definitions here are synthesised from Anthropic's engineering writing and Claude Code documentation, and cross-checked against how the word is used by NVIDIA, Docker, and the wider agent tooling ecosystem. Each page lists its source links at the bottom. Treat vendor docs as authoritative — this field moves fast.
