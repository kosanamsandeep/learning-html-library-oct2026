CWC · Workshop 5

Agent battle: configure a Managed Agent to mine diamonds in five minutes

Mineflayer drives a Minecraft bot; the bot is driven by a Claude Managed Agent. Your job is to configure the agent — system prompt, model, Skills, MCP servers — so it wins the five-minute run. Decision-probe evals (~30 seconds) let you iterate the config a dozen times before you ever pay for the full run.

1 · What you build

  • A configured Managed Agent that controls a Mineflayer bot. The bot starts at y=-40 with an iron pickaxe.
  • A system prompt tuned for "find diamonds, don't die, don't burn tokens."
  • Optional Skills the agent loads (e.g. crafting recipes).
  • Optional MCP servers (e.g. a Minecraft wiki MCP).
  • An --eval mode that fires fast decision probes at the agent: given a scenario, does it pick the right next move?
  • /cwc-setup and /cwc-fix slash commands to seed and reset the run.

2 · The stack

CMA configuration
→
Skills + MCP (optional)
→
Mineflayer bot
→
Decision-probe evals
→
5-min live run

Scoring: most diamonds wins; fewest tokens breaks ties. The dual metric is the whole point — it punishes bloated prompts even when they "work".

3 · Levers the workshop teaches

System prompt as the lever

You don't write Mineflayer code in the workshop — you write English. The prompt is the artifact you ship.

Model choice

Bigger model isn't automatically better. The tie-break is tokens, so a smaller model with a better prompt often wins.

Skills (optional but useful)

A Skill with crafting recipes loads on demand so the prompt stays small.

MCP servers (optional but risky)

A wiki MCP gives the agent encyclopedic knowledge — but the workshop shows that adding an MCP without a prompt nudge often leaves the tool unused.

Decision-probe evals

Tiny synthetic scenarios run in ~30s. They let you A/B configs an order of magnitude faster than the live game.

/cwc-setup / /cwc-fix

Slash commands so reset and recovery don't waste your iteration time.

4 · Use vs don't use — the trade-offs

Lever If you use it If you skip it
Configure CMA (don't write the loop) You spend the whole workshop on intent — prompt, skill, model, eval — not on Mineflayer plumbing. You re-implement the agent loop, the bot loses ten minutes per fix, and you ship a worse prompt because you ran out of time.
Decision-probe evals (--eval) You test ten config variants in the time one live run takes. The winning config is the one with the best probe score, not the one with the best vibes. Each tweak costs a 5-minute game. After three runs you're out of budget and you ship whatever the last attempt was.
Add a wiki MCP The bot can look up "what depth do diamonds spawn?" — but only if you also tell the prompt to consult the wiki when uncertain. You attach the MCP, the prompt never mentions it, the tool is silent, and your tokens still climb because the MCP descriptions are in the system context.
Start from the start_kit prompt The starter codifies hard-won lessons (don't dig straight down, return to base with the ore). You inherit them for free. You write from scratch, the bot mines into lava, and you re-discover the same lessons mid-run.
Skills (crafting recipes) The prompt stays focused on strategy; recipes load only when the agent needs to craft. You inline 40 recipes into the system prompt, the model can't find the verb "mine" behind the noise, and the bot stands still.
The lesson: the system prompt is the agent. Every other lever (model, Skill, MCP) only matters if the prompt knows when to reach for it.

5 · Adoption playbook for your repo

  1. For any agent you own, write down its tie-breaker metric (latency, tokens, $). Not just quality — quality has a ceiling.
  2. Build a "decision-probe" eval: a handful of synthetic scenarios that complete in under a minute.
  3. Treat the system prompt as a versioned artifact. PR it. Diff it. Tag the wins.
  4. Before attaching an MCP, write the sentence in the system prompt that tells the agent when to use it. If you can't write the sentence, you don't need the MCP yet.
  5. Keep recipes / lookup tables in Skills, not the system prompt. The prompt is for strategy.
