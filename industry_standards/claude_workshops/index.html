Claude Workshops · CWC 2026

Field notes from anthropics/cwc-workshops — every stack, every lever, every "use this when…"

Eight workshops, distilled into pro-creator playbooks. Each page lays out the stack (Claude Managed Agents, Skills, MCP, memory stores, Dreaming, Claude Code, evals), the levers the workshop teaches, and the trade-off of using vs. not using each lever — so you know what you gain, and what breaks when you skip it.

The shared stack across the eight workshops

Stack piece What it is Where it shows up
Claude Managed Agents (CMA) Cloud-managed agent loop with sandboxed code execution, sessions, environments, and tool-confirmation events. You configure, Anthropic runs. ship-your-first-managed-agent, agent-decomposition, agent-battle, agents-that-remember, production-ready-agent, eval-driven-agent-development

Sub-agents (multi-agent block) A coordinator agent with a roster of callable sub-agents. Parallel research, isolated contexts, synthesised result. production-ready-agent, agent-decomposition

The eight workshops

W1 · PICKING THE RIGHT MODELUse a Claude Code Skill to audit an LLM eval suite, then sweep it across models × thinking × effort to find the best quality-per-dollar configuration. Plotting + recommendation is the deliverable. W2 · AGENT DECOMPOSITION (STOCKPILOT)Take a 402-line legacy prompt with 12 tools and 3 hardcoded sub-agents, and decompose it into Skills + sandboxed code execution + one well-placed sub-agent on Claude Managed Agents. Score 71% → 92%. W3 · HOW WE CLAUDE CODEThe three-phase AI-assisted product workflow Anthropic uses internally: interview → spec, four divergent visual designs as static HTML, then a Vite + React app whose components carry a machine-readable DOM contract. W4 · SHIP YOUR FIRST MANAGED AGENTBuild an SRE incident agent by filling in seven small functions in agent.py: agent → environment → session → events. The agent greps a 70k-line log in its sandbox and names the bad commit. W5 · AGENT BATTLE (CLAUDE PLAYS MINECRAFT)Configure a Managed Agent — system prompt, model, skills, MCP — that drives a local Minecraft bot. Most diamonds wins, fewest tokens breaks ties. Decision-probe evals iterate the config in ~30 seconds before each 5-minute run. W6 · AGENTS THAT REMEMBERGoldfish → colleague in 45 minutes. Show the amnesiac baseline, attach a memory store across two sessions, then run Dreaming over historical transcripts to consolidate a better store. W7 · EVAL-DRIVEN AGENT DEVELOPMENTA PPTX-generating Managed Agent improved through six variants (naive → visual → typography → palette → density → QA-loop). Two-layer grader: structural pptx XML metrics + LLM judge on rendered slide images. W8 · DEAL DESK (PRODUCTION-READY AGENT)A chat-first M&A research desk over CMA: coordinator delegates to four parallel sub-agents, reads prior-deal lessons from a memory store, reaches Linear via MCP + Vault, emits a graded investment thesis. Streamed UI, gated tool calls, defined outcomes.

How to read these notes

Every page follows the same shape so you can compare designs:

  1. What you build — the artifact and its size in lines / functions / minutes.
  2. The stack — only the pieces actually used in this workshop.
  3. Levers — the configuration knobs Claude exposes (system prompt, model, skills, sub-agents, memory, MCP, evals).
  4. Use vs don't use — what each lever buys you, and what breaks if you skip it.
  5. Adoption playbook — how to take the lesson back to your own repo tonight.
Pro-creator stance: the lesson behind every workshop is the same — start with the smallest config that could possibly work, measure with an eval, and add a lever only when the measurement says it pays off.
