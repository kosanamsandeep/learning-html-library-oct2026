Track 1 · Fundamentals

The five building blocks every distributed system reuses

Rate limiting, consistent hashing, bloom filters, idempotency, and short IDs. They show up in API gateways, load balancers, caches, payment systems, and link shorteners. Each project here builds one from scratch with a story-style README and a small main.py demo.

Project order

P1 · RATE LIMITERToken bucket, sliding window log, fixed window. Compare burst vs steady traffic. P2 · CONSISTENT HASHINGHash ring with virtual nodes. See why adding a server only re-maps a small slice of keys. P3 · BLOOM FILTERBit array + multiple hashes. Trade a tiny false-positive rate for huge memory savings. P4 · IDEMPOTENT APIStripe-style idempotency keys. Safe POSTs even when the client retries. P5 · URL SHORTENERBase62 short codes, collision strategy, and the read-heavy lookup path.

How each project is structured

  • main.py — minimal but realistic implementation with docstrings.
  • README.html — story, mental model, code highlights, tradeoffs, interview answer.
  • requirements.txt — stdlib only.
