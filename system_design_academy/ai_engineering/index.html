Track 3 · AI Engineering

Five patterns the modern AI-system-design interview tests

Agentic loops, multi-agent collaboration, agent memory, context engineering, and knowledge Q&A with evaluation. Each project uses a tiny mock LLM so you can run everything offline and focus on the architecture, not the prompt engineering.

How the mock LLM works

Real LLMs are slow, expensive, and non-deterministic. Each project ships a MockLLM class that returns canned answers based on simple keyword matching. This makes the demos:

  • Free to run (no API keys).
  • Deterministic (same input → same output, so tests pass).
  • Fast (a full run in milliseconds).

The architecture is exactly the same as a real system — swap in OpenAI/Anthropic/local Llama at the boundary and the rest stays unchanged.
