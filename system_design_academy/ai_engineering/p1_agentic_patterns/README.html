Agentic patterns — the four building blocks

Frameworks like LangGraph, CrewAI, and AutoGen look complicated, but underneath they all reuse the same four patterns: router, planner, ReAct loop, reflector. Build them from scratch once and every framework feels obvious.

The four patterns

Pattern What it does When to use
Router LLM picks which path/tool handles this input. Multi-skill assistants; cheap classifier for tool selection.
Planner Decompose a goal into ordered subtasks. Complex tasks; lets you parallelise or pause-and-resume.
ReAct loop Reason → act (call tool) → observe → repeat. Any agent that needs to use tools.
Reflector Critique the draft answer; iterate when not good enough. Quality bar; combats hallucination; useful for code generation.

Mental model — combined

user goal
->
Router picks lane
->
Planner makes steps
->
ReAct loop executes
->
Reflector iterates if needed

Code skeleton (ReAct)

scratchpad = f"react: thought-1 goal={goal}"
for _ in range(self.max_steps):
    response = self.llm.complete(scratchpad)
    if "Action:" in response:
        observation = TOOLS[tool](arg)
        scratchpad = f"react: observation {observation}"
    elif "Final:" in response:
        return response.split("Final:")[1].strip()

This shape is everywhere: OpenAI function calling, LangChain agents, LlamaIndex agents — they all loop reason → act → observe.

Interview-ready answer

"For an agent I default to a router + ReAct loop. The router keeps the cheap LLM in control of which tool runs; ReAct gives the agent the loop it needs to use tools and observe results. I add a planner when goals are multi-step and a reflector when the cost of a bad answer is higher than the cost of one extra LLM call."
