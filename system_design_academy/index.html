System Design Academy — turn the reading list into working code

The public system-design-academy repo is a curated reading list. This folder is the hands-on companion: 15 small, runnable Python projects that implement the patterns the academy describes — fundamentals, real-world case studies, and modern AI engineering. Each project starts from a story, shows the smallest working code, and explains the tradeoffs you would actually discuss in an interview.

The three tracks

TRACK 1 · FUNDAMENTALS Rate limiter, consistent hashing, bloom filter, idempotent API, URL shortener. The building blocks every distributed system uses. TRACK 2 · CASE STUDIES Distributed counter, real-time leaderboard, presence service, saga orchestrator, geo nearby-drivers. Mini versions of patterns from Stripe, Uber, WhatsApp, and friends. TRACK 3 · AI ENGINEERING Agentic design patterns, multi-agent supervisor, agent memory, context engineering, knowledge Q&A with evaluation. The modern half of the academy curriculum.

Why builds, not articles: reading explains the idea. Implementing it forces you to make the small decisions that articles skip — collisions, retries, ordering, cancellation, hot keys, budgets. Those decisions are what interviewers actually probe.

Suggested learning order

  1. Start with Fundamentals P1 → P5. Each one is a self-contained algorithm.
  2. Move to Case Studies P1 → P5. These combine fundamentals into mini products.
  3. Finish with AI Engineering P1 → P5. These extend the existing RAG platform project with agent-era patterns.

How to run any project

cd system_design_academy/system_design_fundamentals/p1_rate_limiter
python main.py

All 15 projects use the Python standard library. Python 3.11+ recommended.
