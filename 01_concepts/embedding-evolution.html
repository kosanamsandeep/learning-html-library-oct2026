Representation learning

GloVe vs Word2Vec vs BERT-style contextual embeddings

These three methods represent three different stages in NLP representation learning. Word2Vec learns meaning from local context windows. GloVe learns from global word co-occurrence statistics. BERT-style embeddings are contextual, meaning the same word can produce different vectors in different sentences.

The key shift is from one vector per word type to different vectors for the same word depending on context.

Simple map

Word2Vec = local context learning GloVe = global co-occurrence learning BERT = contextual token representations

Why Word2Vec and GloVe were a big step

Bag-of-words methods could count tokens but could not learn that related words behave similarly. Word2Vec and GloVe gave dense semantic spaces where related words moved closer together.

Why transformers changed the game again

Static word embeddings still give one vector for each word in the vocabulary. That breaks when a word has multiple meanings. Contextual embeddings fix this by generating token representations after looking at surrounding words.

Stage 1

Word2Vec

How it works

Word2Vec trains a shallow neural objective. In Skip-Gram it predicts nearby context words from a target word. In CBOW it predicts a target word from surrounding context.

word -> predict context or context -> predict word

What it gets right

  • Learns useful semantic neighborhoods.
  • Compact dense vectors are efficient.
  • Often works well for similarity and clustering baselines.

Main limitation: Word2Vec is static. The word bank has one vector whether the sentence is about a river bank or a financial bank.

Stage 2

GloVe

How it works

GloVe stands for Global Vectors. Instead of only learning from small local prediction tasks, it factorizes information from the global word co-occurrence matrix. The training objective tries to preserve ratios of co-occurrence probabilities.

What it gets right

  • Uses corpus-wide statistics more directly than Word2Vec.
  • Often produces strong static embeddings with good global structure.
  • Historically popular for pretrained embeddings in classic NLP pipelines.

Main limitation: GloVe is still static. It is better understood as a different way to learn one vector per word, not a fix for contextual ambiguity.

Stage 3

BERT-style contextual embeddings

How they work

BERT processes the full sentence with a transformer encoder. Each token representation is updated by attention over surrounding tokens. So the vector for a word is produced after the model has seen its context.

token + context -> contextual token embedding

Why this matters

  • The same word can mean different things in different sentences.
  • Sentence-level and token-level meaning become much stronger.
  • These embeddings are usually far better for modern semantic search and downstream NLP tasks.

Most important difference

Word2Vec and GloVe store meaning in the vocabulary table itself. BERT computes meaning dynamically from context. That is why contextual embeddings usually beat static embeddings on ambiguity-heavy tasks.

Aspect Word2Vec GloVe BERT-style embeddings
Representation type Static dense word vectors Static dense word vectors Contextual token vectors
Training signal Local context prediction Global co-occurrence statistics Transformer pretraining over context
Handles ambiguity well? No No Yes
Compute cost Low Low to moderate Higher
Best fit Classic similarity baselines Pretrained static embedding pipelines Modern semantic retrieval and NLP tasks

Decision guide

Which one should you use?

Use Word2Vec or GloVe when

  • You need lightweight classic embeddings.
  • You are building older or resource-constrained pipelines.
  • You need a simple baseline before moving to transformers.

Use BERT-style embeddings when

  • Context changes meaning significantly.
  • You care about semantic search quality.
  • You are building modern retrieval, ranking, or classification systems.

Most honest answer: among these three, contextual embeddings are usually the strongest representation. Static embeddings are mainly useful today when cost, simplicity, or legacy compatibility matters more than peak semantic quality.

Interview readiness

Questionnaire and scenarios

Question

Why did NLP move from Word2Vec and GloVe to BERT-style embeddings?

Strong answer

Because static embeddings give one vector per word and cannot model context-specific meaning. Contextual embeddings produce different token vectors depending on the sentence, which improves ambiguity handling and downstream task quality.

Question

What is the real difference between Word2Vec and GloVe?

Strong answer

Both are static dense word embeddings, but Word2Vec learns mainly from local context prediction while GloVe uses global co-occurrence statistics. They differ in training signal more than in deployment behavior.

Scenario

You need a cheap baseline for clustering short product descriptions. What would you start with?

Expected reasoning

Start with TF-IDF or Word2Vec depending on whether exact wording or broader similarity matters more. Use BERT embeddings only if the semantic gain justifies the added cost.

Scenario

You need to distinguish "apple" the company from "apple" the fruit. Which representation helps most?

Expected reasoning

BERT-style contextual embeddings help most because the representation depends on sentence context, while Word2Vec and GloVe would use the same static vector for both meanings.
