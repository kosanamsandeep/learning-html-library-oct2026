Step 1

Transformer basics

Core mental model: a transformer repeatedly lets each token look at other tokens, then refines each token with a small neural network. After enough layers, each token vector contains rich contextual meaning.

Minimal block formula

h' = LayerNorm(h + Attention(h)) h'' = LayerNorm(h' + MLP(h'))

Intuition

The big idea

Before transformers

Older sequence models processed tokens one step at a time. That made long-range relationships hard to model and hard to parallelize.

With transformers

Every token can directly attend to every relevant token in the same layer. That makes dependencies easier to learn and training easier to scale.

Input pipeline

What goes in

1. Tokenization

Text is split into tokens such as whole words, subwords, or byte-pair fragments. GPT-style models usually work with subword tokens.

2. Token embedding

Each token id indexes a learned vector. This converts discrete symbols into dense numeric features.

3. Positional information

Because attention alone does not know sequence order, a positional signal is added so the model can distinguish "dog bites man" from "man bites dog".

X = E_token[token_ids] + E_pos[position_ids]

Main mechanism

Self-attention

Query, key, value

Each token is projected into three vectors. The query asks what this token needs. Keys describe what each token offers. Values carry the actual information to mix together.

Attention(Q, K, V) = softmax(QK^T / sqrt(d_k)) V

Why multi-head?

Different heads can focus on different relations at the same time: syntax, entity identity, long-range dependencies, or local phrase structure.

Key intuition: attention is a content-based routing rule. A token decides how much signal to pull from every other token.

Local refinement

The feed-forward block

What it does

After attention mixes information across tokens, the MLP transforms each token independently. This is where the model can create richer nonlinear features.

Why it matters

If you removed the activation function and used only linear layers, the two projections would collapse into a single linear map and capacity would drop sharply.

Worked example

Simple sentence walk-through

Sentence: "The animal did not cross the road because it was tired."

When the model processes the token "it", self-attention lets that token inspect earlier tokens. Some heads may focus on "animal", others on "tired", and others on the clause boundary. After several layers, the hidden state for "it" carries enough context to resolve the reference correctly.

Why this design

Why do transformers this way instead of older sequence models?

Why attention plus residual blocks works

  • Self-attention gives direct token-to-token interaction instead of forcing information through a long recurrent chain.
  • Parallel processing over tokens makes modern large-scale training practical.
  • Residual paths and normalization make very deep stacks trainable.
  • The MLP block adds nonlinear feature synthesis after information mixing.

What other approaches fail at

  • RNNs and LSTMs struggle with very long dependencies because information must travel step by step.
  • CNN-based sequence models capture local patterns well but need many layers or dilation tricks for global context.
  • Bag-of-words or average embedding methods ignore token interaction structure almost entirely.
  • Purely linear blocks cannot express the nonlinear distinctions needed for semantic reasoning.

Interview readiness

Questionnaire and scenario-based questions

Question

Why can attention replace recurrence for many NLP tasks?

Strong answer

Because attention gives each token direct access to every relevant token in a single layer. Recurrence serializes dependency flow, while attention shortens the path length between related tokens and is easier to parallelize at training time.

Question

Why are residual connections essential?

Strong answer

They preserve an identity path for gradients and features, which stabilizes optimization. Without residuals, deep transformer stacks become much harder to train and can lose useful earlier representations.

Scenario

Your model handles short phrases well but misses long-range dependencies in long documents. What architectural reason should you inspect first?

Expected reasoning

Check whether the attention pattern, context length, masking behavior, or positional handling is constraining long-range interactions. In transformers, long-range failure is usually not because recurrence is missing, but because the model cannot allocate enough attention or represent positions robustly across longer spans.

Scenario

An interviewer says: “Attention is enough, so why do we need the feed-forward block?”

Expected reasoning

Attention mixes information across tokens, but it is mostly a routing mechanism. The feed-forward network transforms each token state nonlinearly, allowing the model to build higher-level features after information has been gathered. Without it, representational power drops sharply.
