Task 8

Memory & Knowledge Building

Your agent builds a knowledge base — each step making it smarter

🧩 What This Task Teaches

Task 3 showed simple accumulation (adding items to a list). Task 8 scales this to knowledge building — generating questions, searching for answers, extracting key points, and synthesizing everything into a comprehensive knowledge base. Each node ENRICHES the state.

Core Concept: The "accumulator pattern" at scale. Each node reads existing knowledge, generates NEW knowledge, and COMBINES them. By the final node, the state contains everything discovered across ALL previous operations — a complete knowledge base.

📚 Knowledge Growth Across Nodes

❓ After Questions Node 3 questions generated
State now has: topic + 3 research questions
🔍 After Search Node 3 search results added
State now has: topic + questions + search results for each question
🎯 After Extract Node 5 key points extracted
State now has: topic + questions + results + 5 distilled key points
📚 After Synthesize Node Complete knowledge base
State now has: EVERYTHING above + a comprehensive synthesized knowledge base

🔄 The Accumulator Pattern

Each node: Read existing → Generate new → Combine both

existing_questions: [q1, q2] + new_questions: [q3, q4, q5] = all_questions: [q1, q2, q3, q4, q5]
def generate_questions_node(state): # 1. READ existing knowledge existing = state.get("questions", []) # 2. GENERATE new knowledge (using LLM) new_questions = llm.invoke(f"Generate 3 questions about {state['topic']}") # 3. COMBINE: append new to existing (never replace!) all_questions = existing + new_questions return { "questions": all_questions, # Accumulated! "operations_count": state["operations_count"] + 1 # Tracked! }

📊 State Structure — Rich & Accumulating

class MemoryState(TypedDict): topic: str # Fixed input questions: List[str] # Accumulates questions search_results: List[str] # Accumulates search findings key_points: List[str] # Accumulates distilled insights knowledge_base: str # Final synthesized knowledge operations_count: int # Tracks total operations

🔀 How Task 8 Differs from Task 7

Task 7 → Task 8 Evolution

Task 7 used tools to fetch external data but processed it in a single pass — search once, summarize once, done.
Task 8 shows how to BUILD KNOWLEDGE over multiple operations. Each node enriches the state. The final node doesn't just summarize search results — it synthesizes questions + results + key points into a comprehensive knowledge base. The state grows richer at every step, preserving ALL intermediate findings.

Aspect Task 7 Task 8
Processing style Single pass through pipeline Multi-layer enrichment
State after completion Final summary only Full audit trail (questions → results → points → synthesis)
Knowledge depth Surface-level (one search) Deep (multi-step analysis)
Analogy Quick Google search Research paper methodology

✅ Advantages of This Task

  • Knowledge building — state becomes a growing knowledge base, not just transient data
  • Full audit trail — you can see exactly what was asked, found, and concluded
  • Operations tracking — operations_count provides workflow telemetry
  • LLM at every layer — generates questions, extracts points, synthesizes knowledge
  • Scalable pattern — add more enrichment nodes without changing existing ones
  • Debuggability — if the final answer is wrong, inspect intermediate state to find where

💡 Key Insight

This is how real AI research agents work: they don't just search and summarize. They generate hypotheses (questions), gather evidence (search), extract insights (key points), and synthesize understanding (knowledge base). Each layer builds on the previous ones. Task 9 combines this with loops AND tools for the complete agent.
