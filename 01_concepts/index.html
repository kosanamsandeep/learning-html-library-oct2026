Fast revision

Interview-ready mental checkpoints

Statistics and metrics

Descriptive summarizes data. Inferential makes claims about a population. Accuracy misleads on imbalanced data. F1 balances precision and recall. Type 1 is a false positive. Type 2 is a miss.

Classical ML

Linear regression has five testable assumptions. Lasso selects features. Random forest reduces variance. XGBoost often wins on tabular data. K-Means assumes spherical clusters.

Training

Backpropagation computes gradients via the chain rule. SGD uses them to update parameters. They are not the same thing.

Architectures

CNNs exploit spatial locality with shared filters. RNNs carry state over time but struggle long-range. Transformers use attention to relate any two tokens directly.

NLP representations

CountVectorizer counts words. TF-IDF weights importance. Word2Vec learns semantics. BERT gives contextual embeddings where meaning changes with context.

Production systems

RAG quality depends on retrieval, reranking, grounding, and evaluation. MCP standardizes tool discovery. gRPC is contract-first RPC. LangGraph manages stateful agent workflows.
