Architecture evolution

ANN vs RNN vs LSTM vs Transformer

Understanding how neural network architectures evolved from simple feedforward networks to transformers reveals why each design exists and what problem it solves. Each architecture addresses limitations of its predecessor.

This page walks through the progression: ANN cannot handle sequences, RNN adds memory but suffers from vanishing gradients, LSTM gates information flow but is slow, and Transformers parallelize everything with attention.

Evolution timeline

  • ANN: Static input, no sequence awareness
  • RNN: Sequential processing with hidden state
  • LSTM: Gated memory to handle long dependencies
  • Transformer: Parallel attention over all positions

ANN: Artificial Neural Network (Feedforward)

How it works

A feedforward neural network passes input through layers of neurons. Each neuron applies a weighted sum followed by a nonlinear activation function. Data flows in one direction: input to hidden layers to output.

y = activation(W * x + b)

Strengths

  • Simple to implement and understand
  • Works well for tabular and fixed-size input
  • Universal approximation theorem guarantees expressive power
  • Fast training on structured data

Critical limitation

ANNs have no memory. They process each input independently. If you feed "The cat sat on the" one word at a time, the network has no idea what came before. It cannot model sequences, temporal patterns, or context-dependent meaning.

Fixed input size: The number of input neurons is fixed at design time. Variable-length sequences like sentences cannot be handled natively.

RNN: Recurrent Neural Network

How it works

RNN adds a feedback loop. The hidden state from the previous timestep is fed back as input alongside the current token. This gives the network a form of memory.

h_t = tanh(W_xh * x_t + W_hh * h_(t-1) + b_h) y_t = W_hy * h_t + b_y

What RNN solves over ANN

  • Handles variable-length sequences
  • Maintains temporal context via hidden state
  • Parameter sharing across timesteps (efficient)
  • Natural fit for text, speech, time-series

Critical limitations of RNN

  • Vanishing gradients: During backpropagation through time (BPTT), gradients are multiplied at each timestep. With tanh or sigmoid, repeated multiplication of values less than 1 causes gradients to shrink exponentially. After 10-20 steps, gradients are effectively zero.
  • Exploding gradients: Conversely, if weights are large, gradients can grow exponentially, causing unstable training.
  • Sequential processing: Each timestep depends on the previous one. Cannot be parallelized across the sequence dimension.
  • Short-term memory: In practice, RNNs struggle to remember information from more than 10-20 tokens ago.

Why vanishing gradient happens mathematically

∂L/∂h_0 = ∂L/∂h_T * ∏(t=1 to T) ∂h_t/∂h_(t-1)

Each ∂h_t/∂h_(t-1) = diag(tanh'(z_t)) * W_hh

Since |tanh'(x)| ≤ 1 and if ||W_hh|| < 1:
  The product shrinks exponentially → vanishing gradient

If ||W_hh|| > 1:
  The product grows exponentially → exploding gradient

LSTM: Long Short-Term Memory

How it works

LSTM introduces a cell state (long-term memory) and three gates that control information flow. The cell state runs like a conveyor belt with minimal transformations, allowing gradients to flow unchanged over many timesteps.

The three gates

  • Forget gate (f_t): Decides what to discard from cell state
  • Input gate (i_t): Decides what new information to store
  • Output gate (o_t): Decides what to output from cell state

LSTM equations

Forget gate:  f_t = σ(W_f · [h_(t-1), x_t] + b_f)
Input gate:   i_t = σ(W_i · [h_(t-1), x_t] + b_i)
Candidate:    C̃_t = tanh(W_C · [h_(t-1), x_t] + b_C)
Cell update:  C_t = f_t * C_(t-1) + i_t * C̃_t
Output gate:  o_t = σ(W_o · [h_(t-1), x_t] + b_o)
Hidden state: h_t = o_t * tanh(C_t)

What LSTM solves over RNN

  • Vanishing gradient: Cell state provides a highway for gradients. The forget gate can be close to 1, meaning gradients pass through unchanged.
  • Long-range dependencies: Can remember information over 100+ timesteps
  • Selective memory: Gates learn what to keep and what to forget

Remaining limitations of LSTM

  • Still sequential: Must process tokens one by one. Cannot parallelize.
  • Slow training: O(n) sequential steps for sequence length n
  • Complex architecture: 4x parameters compared to vanilla RNN
  • Information bottleneck: All past context must fit in hidden state vector
  • Finite context window: Even with gates, very long sequences (1000+) still degrade

GRU: A lighter alternative

GRU (Gated Recurrent Unit) combines forget and input gates into a single update gate, and merges cell state and hidden state. Fewer parameters, similar performance in most tasks, slightly faster training.

z_t = σ(W_z · [h_(t-1), x_t]) ← update gate r_t = σ(W_r · [h_(t-1), x_t]) ← reset gate h̃_t = tanh(W · [r_t * h_(t-1), x_t]) h_t = (1 - z_t) * h_(t-1) + z_t * h̃_t

Transformer: Attention Is All You Need

Core idea

Instead of processing tokens sequentially, the transformer attends to all positions simultaneously using self-attention. Every token can directly look at every other token, regardless of distance.

How self-attention works

Each token produces Query, Key, and Value vectors. Attention scores are computed as scaled dot-product between queries and keys, then used to weight values.

Attention(Q, K, V) = softmax(QK^T / √d_k) · V

What Transformer solves — every RNN/LSTM problem

Problem: Sequential processing (RNN/LSTM)
Solution: Self-attention processes all positions in parallel → O(1) sequential steps

Problem: Vanishing gradients over long sequences
Solution: Direct connections between any two positions via attention (path length = 1)

Problem: Information bottleneck (fixed-size hidden state)
Solution: Attention over all positions — no need to compress history into one vector

Problem: Long-range dependencies degrade
Solution: Attention score between positions 1 and 1000 is computed just as easily as between 1 and 2

Problem: Slow training
Solution: Full parallelization over sequence length → massive GPU utilization

Multi-head attention

Instead of one attention function, transformers use multiple heads in parallel. Each head learns different relationship patterns (syntax, semantics, coreference). Outputs are concatenated and projected.

MultiHead(Q,K,V) = Concat(head_1,...,head_h) · W_O where head_i = Attention(QW_i^Q, KW_i^K, VW_i^V)

Positional encoding

Since attention is permutation-invariant (order-agnostic), position information must be injected explicitly. Original paper uses sinusoidal encoding; modern models use learned or rotary positional embeddings (RoPE).

PE(pos, 2i) = sin(pos / 10000^(2i/d_model)) PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))

Transformer advantages summary

  • Parallelism: All tokens processed simultaneously during training
  • Constant path length: Any two tokens are one attention hop apart
  • Scalability: Scales to billions of parameters efficiently on GPUs/TPUs
  • Flexibility: Works for text, images, audio, code, proteins
  • No information bottleneck: Each token maintains its own representation

Transformer tradeoffs

  • Quadratic attention cost: O(n²) memory and compute for sequence length n
  • No inherent sequential bias: Must learn order from positional encodings
  • Large data/compute requirement: Needs more data than RNNs to train effectively
  • Context window limit: Fixed max sequence length (though much longer than RNNs)

How the Transformer addresses every prior limitation

Problem 1: Sequential bottleneck

RNN/LSTM must wait for h_(t-1) before computing h_t. Training time scales linearly with sequence length.

Transformer solution: Self-attention computes all pairwise relationships in one matrix multiplication. During training, all positions are processed simultaneously. GPUs excel at these parallel matrix operations.

Problem 2: Vanishing/exploding gradients

In BPTT, gradients must flow through T sequential multiplications, degrading signal.

Transformer solution: Residual connections (x + sublayer(x)) create gradient highways. Layer normalization stabilizes magnitudes. Attention provides direct gradient paths between any two positions regardless of distance.

Problem 3: Information compression into fixed-size state

RNN/LSTM must compress all past information into a single hidden state vector. Information inevitably gets lost for long sequences.

Transformer solution: Every token maintains its own representation vector throughout all layers. Attention allows any token to directly access any other token's full representation — no compression needed.

Problem 4: Distance-dependent forgetting

Even LSTM gradually forgets distant information. Token at position 1 is barely remembered at position 500.

Transformer solution: Attention weight between positions 1 and 500 is computed the same way as between positions 499 and 500. The model learns what's relevant, not what's recent.

Problem 5: Difficulty scaling

RNN training doesn't scale well on modern hardware (GPUs/TPUs optimize parallel ops).

Transformer solution: Matrix multiplications in attention and FFN layers map perfectly to GPU architecture. This enabled scaling from millions to trillions of parameters (GPT-4, Gemini, Claude).

Interview questions

Q

Why can't a standard feedforward network handle text classification of variable-length sentences?

A

Feedforward networks require fixed-size input. A sentence with 5 words and one with 50 words cannot use the same architecture without padding/truncation. More fundamentally, feedforward networks treat each input dimension independently — they have no mechanism to model the sequential relationship between words.

Q

Explain the vanishing gradient problem in RNNs with a concrete example.

A

Consider the sentence: "The cat, which was sitting on the mat near the window in the living room, was hungry." The RNN must remember "cat" (subject) across 12+ words to correctly predict "was hungry." During backpropagation, the gradient from "hungry" must flow through 12+ timestep multiplications. With tanh activation (max derivative = 1), even a 0.9 multiplicative factor gives 0.9^12 ≈ 0.28 — the gradient reaching "cat" is weak, so the model barely learns this dependency.

Q

How does LSTM solve the vanishing gradient problem specifically?

A

The cell state update is C_t = f_t * C_(t-1) + i_t * C̃_t. When the forget gate f_t is close to 1 and the input gate i_t is close to 0, C_t ≈ C_(t-1). The gradient ∂C_t/∂C_(t-1) = f_t, which can be near 1. This means the gradient flows through the cell state almost unchanged — like a highway with no tolls. The network learns when to keep the highway open (f_t → 1) for important long-range information.

Q

Why is the Transformer faster to train than LSTM despite higher theoretical complexity?

A

LSTM has O(n) complexity but the operations are sequential — each step must wait for the previous. Transformer has O(n²) complexity but all operations happen in parallel. On modern GPUs optimized for parallel matrix multiplications, n² parallel ops can be faster than n sequential ops. A sequence of length 512: LSTM needs 512 sequential steps; Transformer does one large matrix multiply. Wall-clock time favors parallelism on modern hardware.

Q

When might you still choose LSTM over a Transformer?

A

1) Edge/embedded devices with limited memory (LSTM is smaller). 2) Streaming/online inference where you process one token at a time (LSTM naturally processes sequentially). 3) Very small datasets where transformer may overfit. 4) Real-time applications with strict latency where lightweight models are needed. 5) Time-series forecasting where the sequential inductive bias helps with limited data.

Q

What is the attention mechanism doing that the hidden state cannot?

A

The hidden state is a fixed-size vector that must compress ALL sequential history into one representation. Attention instead creates a dynamic, weighted combination of ALL position representations specifically tailored for each query position. Token 50 can directly attend to token 3 without that information passing through tokens 4-49. It's the difference between passing a note down a line of people (RNN) vs. being able to look directly at anyone in the room (Transformer).
