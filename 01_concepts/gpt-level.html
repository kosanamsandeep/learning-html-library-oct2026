Step 4

From transformer basics to GPT-level behavior

GPT is a decoder-only transformer. It uses masked self-attention so each position can only look backward. The model is trained to predict the next token, and that simple objective scales into surprisingly broad behavior.

Architecture

GPT keeps the same core transformer block: embeddings, positional signal, multi-head attention, residual paths, normalization, and MLP layers. The critical change is the causal mask.

Causal mask

At position t, the model can only attend to positions up to t. This prevents it from cheating by reading future tokens during training.

mask(i, j) = 0 if j <= i, else -infinity

Objective

Why next-token prediction is enough

Training data

Large text corpora are tokenized into long sequences.

Target shift

For every position, the label is the token that comes next.

Loss

The model is optimized with cross-entropy over the predicted token distribution.

The model is never explicitly told grammar rules, facts, or reasoning strategies. Those emerge as useful internal structures because they help reduce next-token error.

Generation loop

What happens during inference

Prompt: "A transformer is useful because"

The prompt tokens enter the model. It predicts a distribution for the next token. One token is selected. That token is appended to the prompt, and the process repeats. This loop is autoregression.

prompt -> logits -> choose next token -> append -> repeat

In-context learning

GPT can adapt behavior from examples inside the prompt without parameter updates. The prompt acts as temporary task conditioning.

Scaling effects

Larger models with more data and compute usually learn better abstractions, stronger world knowledge, and more robust few-shot behavior.

Evaluation lens What to measure Example
Perplexity How well the model predicts held-out text. Lower is generally better for language modeling.
Task accuracy How well the model performs on benchmark tasks. Question answering, coding, translation, reasoning.
Behavioral quality Consistency, safety, factuality, robustness. Does the answer stay coherent and grounded?
Efficiency Latency, memory use, and context-window behavior. How expensive is long-context generation?

Final synthesis

Basic transformers become GPT-like systems when you combine decoder-only masked attention, large-scale next-token training, strong positional handling, stable residual pathways, and expressive MLP blocks with good activations. The architecture is simple in outline, but the behavior emerges from scale and training dynamics.

Design logic

Why does GPT use decoder-only next-token prediction?

Why this setup scales well

  • The training target is simple, dense, and available for virtually every token on the internet: predict the next token.
  • Decoder-only causal masking matches the inference-time generation process exactly.
  • The same architecture can absorb broad knowledge and act across many tasks through prompting.

What other approaches fail at

  • Task-specific supervised pipelines do not scale to open-domain general intelligence because they need labeled data for each task.
  • Encoder-only objectives produce strong understanding features but do not directly train the model for free-form generation.
  • Classical n-gram or recurrent language models do not scale as effectively in context handling and parameter sharing.

Interview readiness

Questionnaire and scenarios

Question

Why can next-token prediction produce reasoning-like behavior?

Strong answer

Because to predict the next token well across massive diverse text, the model benefits from internalizing syntax, facts, discourse structure, algorithmic patterns, and latent task formats. Reasoning behavior is an emergent strategy for reducing prediction loss.

Question

Why does training objective alignment matter?

Strong answer

If the architecture or objective differs too much from inference usage, training can optimize the wrong behavior. GPT’s causal masking makes training and generation structurally consistent.

Scenario

You observe low perplexity improvement but weak instruction-following. What distinction should you explain?

Expected reasoning

Perplexity measures next-token fit on text, not necessarily alignment with human intent. A model can be a good language model yet still need instruction tuning, preference optimization, or better prompting behavior for assistant-style use.

Scenario

An interviewer asks when you would not default to GPT. What is a good answer?

Expected reasoning

When the task is pure representation learning, low-latency embedding retrieval, or tightly structured source-to-target conversion with strong source grounding, encoder-only or encoder-decoder models may be more efficient and more natural.
