Classical ML

Regression algorithms and linear regression assumptions

Regression predicts a continuous numeric output. It is usually the first supervised learning topic tested in interviews. You need to know the math, the assumptions, what breaks when they are violated, and when to switch to a more complex model.

Core idea

y = f(X) + noise Find f that minimizes prediction error on unseen data

Regression vs classification

Regression outputs a continuous value such as price, temperature, or revenue. Classification outputs a discrete category. The loss functions, evaluation metrics, and model assumptions differ.

Why regression is foundational

Linear regression introduces concepts used everywhere: loss minimization, closed-form solution, regularization, bias-variance tradeoff, and feature assumptions. Almost every ML interview visits it.

Starting point

Linear regression

How it works

Linear regression fits a hyperplane to the data by minimizing the sum of squared residuals between predictions and targets.

y = w1*x1 + w2*x2 + ... + wn*xn + b

How parameters are found

  • Closed-form (normal equation): direct matrix solution. Fast for small data.
  • Gradient descent: iterative optimization. Scales better for large data.

Critical for interviews

The five key assumptions of linear regression

1. Linearity

The relationship between features and target is linear. If the true relationship is curved, a linear model will systematically misfit. Check with: residual plots, partial regression plots.

2. Independence of errors

The residuals from one observation should not be correlated with residuals from another. This often fails in time-series data. Check with: Durbin-Watson test, autocorrelation plots.

3. Homoscedasticity

The variance of residuals should be roughly constant across all levels of the independent variable. If variance fans out or contracts, standard errors become unreliable. Check with: residual vs fitted plot, Breusch-Pagan test.

4. Normality of residuals

The residuals should be approximately normally distributed. This matters most for inference such as confidence intervals and hypothesis tests on coefficients. Check with: Q-Q plot, Shapiro-Wilk test.

5. No severe multicollinearity

Features should not be too highly correlated with each other. If they are, coefficient estimates become unstable and hard to interpret. Check with: VIF (variance inflation factor), correlation matrix.

What goes wrong

When assumptions are violated

Violation What breaks Common fix
Nonlinear relationship Systematic misfit, biased predictions. Add polynomial terms, use a nonlinear model, or transform features.
Correlated errors Standard errors are wrong, p-values unreliable. Use time-series models, add lagged features, or use robust standard errors.
Heteroscedasticity Coefficient estimates still unbiased but standard errors are inefficient. Transform the target, use weighted least squares, or robust standard errors.
Non-normal residuals Inference on coefficients becomes less reliable for small samples. Transform the target, use bootstrap methods, or increase sample size.
Multicollinearity Coefficients become unstable and interpretability drops. Drop correlated features, use PCA, or use regularization.

Regularization

Ridge and Lasso regression

Ridge regression (L2)

Adds a penalty proportional to the sum of squared weights. It shrinks coefficients toward zero but rarely makes them exactly zero.

loss = MSE + lambda * sum(w_i^2)

Best for: multicollinearity, when you want to keep all features but reduce overfitting.

Lasso regression (L1)

Adds a penalty proportional to the sum of absolute weights. It can shrink some coefficients all the way to zero, performing feature selection.

loss = MSE + lambda * sum(|w_i|)

Best for: when you suspect many features are irrelevant and want automatic selection.

Elastic Net combines both L1 and L2 penalties. It is useful when there are many correlated features and you want both shrinkage and selection.

Polynomial regression

Extends linear regression by adding squared or higher-order terms as new features. The model is still linear in parameters even though the decision boundary is curved.

When to move beyond linear

If residual plots show clear patterns, the true relationship is nonlinear. You can try polynomial features, splines, or switch to decision trees, random forests, or gradient boosting.

Decision tree regression

Splits the feature space into regions and predicts the mean target value in each region. No linearity assumption, but prone to overfitting on deep trees.

Random forest and gradient boosting regression

Random Forest averages many decorrelated trees. Gradient Boosting builds trees sequentially, each correcting errors of the previous. Both handle nonlinearity and interactions well.

Fundamental tradeoff

Bias-variance tradeoff

Bias

Error from wrong assumptions in the model. A model that is too simple underfits and has high bias. It cannot capture the real relationship.

Variance

Error from sensitivity to small fluctuations in the training set. A model that is too complex overfits and has high variance. It memorizes noise.

The goal

Find the sweet spot where total error (bias squared plus variance plus irreducible noise) is minimized. Regularization, cross-validation, and ensemble methods are practical tools for managing this balance.

Interview readiness

Questionnaire and scenarios

Question

What are the key assumptions of linear regression?

Strong answer

Linearity, independence of errors, homoscedasticity, normality of residuals, and no severe multicollinearity. Each has specific diagnostic checks and fixes.

Question

Why would you pick Lasso over Ridge?

Strong answer

When I expect many features to be irrelevant and want automatic feature selection. Lasso can push coefficients to exactly zero. Ridge shrinks but keeps all features.

Scenario

Your linear regression has a high training score but a much lower test score. What do you suspect?

Expected reasoning

Overfitting. I would check for too many features, add regularization, use cross-validation, or try a simpler model.

Scenario

Your residual plot shows a funnel shape. What does it tell you?

Expected reasoning

That is heteroscedasticity. The variance of errors changes with the predicted value. I would consider a log transform on the target, weighted least squares, or robust errors.

Regression interviews test whether you know the assumptions, not just the formula.
